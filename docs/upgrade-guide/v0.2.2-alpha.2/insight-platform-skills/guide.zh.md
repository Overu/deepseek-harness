# Insight 平台技能安装

English | [中文](guide.md)

## 变更

Insight Desktop 不再随应用分发 `bundled-skills` 目录中的技能。平台技能现在通过技能中心安装到当前账号的本地数据中，并显示在“专家技能 → 平台预置”。仍然存在的旧目录会作为用户技能只读发现；应用更新仍可能替换该目录。安装管理与专家技能选择器均由技能中心负责。

## 迁移

1. 登录后打开技能中心，为需要的平台技能选择**安装**。目录提供新版本时选择**更新**。
2. 确认已安装技能出现在“专家技能 → 平台预置”。在技能中心选择**移除**可将其从当前账号中删除。
3. 将旧应用目录中用户自行维护的文件复制到 `$DSH_HOME/skills`；只读兼容发现无法恢复已被更新器替换的文件。账号本地的平台技能会在同一设备上的应用更新和重新安装后保留。
4. 在 `insight-skill-center` 插件的 `presetSkillIds` 中配置目录 `skill_id` 中的技术名，例如 `activity-search`。Insight 包选择了十六个技术名。缺失技能会在账号界面就绪后安装，整个队列使用一个可取消的进度浮层，结束时仅通知一次；单个技能失败不影响后续安装，在本次 Host 生命周期内不自动重试失败项；取消会停止队列。之前已安装或主动移除的技能不会自动重装或升级。
5. 使用 `installed/<technical-name>.json` 记录，包含 `id`（技术名）、`version` 和 `payload`；移除历史仅包含 `id`。忽略 OSS 数字标识。如果开发阶段记录包含 UUID 键和 `skillName`，应退出客户端，备份并删除 `$DSH_HOME/platform-skills`，再重启以重新安装。不提供自动记录迁移。
