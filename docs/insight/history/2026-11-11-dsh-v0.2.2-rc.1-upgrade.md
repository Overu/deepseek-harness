# Insight 升级 DSH 0.2.2-rc.1 的问题记录

2026-11-11，`upgrade/dsh-v0.2.2-rc.1` 将 Insight 的 DSH 基线从 `dsh-v0.2.2-alpha.2` 升到 `dsh-v0.2.2-rc.1`。合并提交 `26e48067e8` 解决了 30 个 Git 内容冲突。以下记录适配结果、复核发现和当时的验证范围。

## 待处理

| 问题 | 观察与后续检查 |
| --- | --- |
| Canvas 正文链接无法打开画布 | RC 让历史回复正文里的画布地址显示为链接，页脚也保留同一画布的链接。原测试点击页脚可打开侧栏。复核在同一浏览器回放中点击正文链接，侧栏未打开。修复后应验证正文和页脚两个入口。[回放用例](../../../apps/web/tests/canvas-history.e2e.ts) |
| 文件修改保护默认关闭 | RC 默认禁用 `fs-observation-policy`，Insight 沿用该配置。原先由工具强制的修改前先读、读取后文件变化时拒绝修改不再生效。Insight 是否通过产品配置恢复这两项保护待确认。[上游升级指南](../../upgrade-guide/v0.2.2-alpha.2/fs-observation-policy-default-off/guide.zh.md) |
| 正式版显示开发者工具入口 | 合并保留了 Insight 的菜单操作，同时采用 RC 的可见开发者工具命令。Insight 正式包是否保留可见入口待确认。[基线台账](../baseline-changes.zh.md#baseline-synchronization) |

## 已解决的适配

- Pi AI 保留 Insight 托管网关依赖的三个根导出，并接入 RC 的请求头扩展。下一次升级仍需同时验证网关的请求头和凭据路径。
- RC 改动了客户端右键菜单和插槽入参。合并保留技能切换和 Canvas 历史引用适配，更新了测试夹具及回放预期。Canvas 的原始会话记录保持原样。
- 预先存在的 React 18 与 React DOM 19 混用让会话导出菜单测试渲染为空。根测试依赖对齐到 18.3.1 后通过。真实 Loader 也验证了五个 Insight 必需组件的加载和保护。

## 验证范围

产物构建、Host 与 Client 聚合类型检查、四组录制会话回放和五项 Web 浏览器测试通过。隔离 Electron 启动覆盖官方工作区和 Insight 登录页。Canvas 正文链接回归由后续复核单独复现。文档同步 42 项通过、1 项受既有术语问题影响。真实账号登录、签名安装包和覆盖升级尚未验收。
