# 因赛AI v1.0.0

因赛AI首个正式开源版本，面向 macOS Apple Silicon、macOS Intel 与 Windows x64。

## 主要变化

- 全新的深色登录界面，使用轻量 Dot Grid 动效，并保留完整品牌文案与短信、密码登录能力。
- 内置因赛技能选择器，只展示随客户端交付且明确允许展示的技能。
- 生产 Gateway、Core Runtime、默认 Profile 与桌面更新链路统一锁定，用户无需配置模型 API Key。
- 完善 macOS 签名、公证与更新包校验，以及 Windows 安装、升级和隐藏控制台兼容性。
- 使用自有 OSS/CDN 提供签名更新清单、断点续传与同源完整安装包兜底。

## 发布门禁

正式 tag 仅在三平台构建、安装、升级与分发验证全部通过后创建。本文件随发布提交进入 `main`，不代表尚未完成的远端构建已经通过。
