# 因赛AI v1.0.3

本版本将阿里云 Codeup `insight-desktop-skills` 的 12 个内置技能完整展示在「专家技能」菜单中，并启用批量构建与发布流程。

## 主要变化

- 「多媒体创作」（`media-generator`）不再被客户端默认隐藏；本机额外安装的技能仍不进入产品菜单。
- `bundled-skills/` 与 Codeup `master` 提交 `dcc054102fe735956f755504883afe982b0db3a0` 的 `skills/` Git tree 完全一致，共 12 个目录、240 个文件。
- 构建工作流支持一次运行构建 macOS Apple Silicon、macOS Intel 与 Windows x64。Candidate 投放和 Stable 转正各有一次批量操作；保留单目标故障补救命令。
- Core Runtime 仍为 `insight-runtime-v0.1.6-alpha.2-insight.4`，兼容声明及用户数据格式不变。

## 验收与发布状态

本地 macOS Apple Silicon DEV 包已由操作者验收。三平台签名安装包构建与 Candidate 投放结果待记录；全部 Candidate 安装与升级验收通过后，才能转为 Stable。
