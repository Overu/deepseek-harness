- Core Runtime 保持 `insight-runtime-v0.2.1-alpha.1-insight.1`，提交 `25a49c53c4e0c003a8469ee243aa5d1365df80cd`。

- 不把 Candidate 转为 Stable。本轮仅投放三个 `candidate-v2/<target>/current.json`；Stable 保持 1.0.4。
