## Candidate 安装包手动验收

三个 Candidate 指针均已指向 1.0.7，可开始以下验收。安装包使用生产账号服务和正式用户目录 `insight-desktop`；dev 的测试环境、临时登录会话及其数据目录不能替代这里的验证。

1. 在现有 1.0.6 中先记录当前账号、一个可继续的旧会话、工作区、关键设置和自装插件版本。退出其他同身份实例，不清空用户数据或卸载插件来获得通过结果。
2. 打开更新窗口，在 3 秒内点击 Logo 五次，确认检查内测更新。确认显示 1.0.7 后下载并安装。也可使用已验签的对应架构完整安装器覆盖安装；macOS 应从 `/Applications` 中启动，不能从 DMG 挂载目录运行来验收更新。
3. 确认“关于”显示 1.0.7，连续完整退出并重新启动三次；检查已登录账号、旧会话续写、工作区、设置和自装插件均保留。正式包使用系统安全存储，登录行为与 dev 的进程内会话不同。
4. 使用受控生产账号验证白名单放行、非白名单发码拒绝、发码后撤销资格的登录拒绝，以及恢复资格后的重试；与服务端配合操作生产白名单，不变更无关账号。异常文案应显示服务端原因，拒绝时不能进入工作区。
5. 验证新建会话、真实模型请求、文件预览和常用插件；按[构建 Runbook](../client-build-runbook.md)验证当前 Stable 完整安装包的覆盖恢复和数据保留。记录平台/架构、安装方式、源版本、结果及脱敏证据，不把自动检查写成人工已通过。

三平台安装、升级与恢复人工结果尚待记录；发现问题应暂停转正并保留日志。Stable 推广使用同一批已验证字节，需要操作者另行明确确认。
