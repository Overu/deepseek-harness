# 因赛AI v1.0.0-rc.20 桥接候选

rc.20 用于在首个正式版前验收 legacy Candidate 到 Desktop Update v2 的桥接。 rc.19 保留为历史 Draft，不覆盖其 tag、Release 或 OSS 不可变资产。

## 本次变更

- 恢复简洁的“关于因赛AI”界面，保留独立的单文件沙箱 preload，避免打包后空白。
- 在更新窗口连续点击 Logo 五次并二次确认后手动检查内测更新；不显示内测开关或额外说明。
- 对临时网络与更新查询错误增加有限重试，终态提示保持简洁；签名和语义错误不重试。
- v2 首个正式版的恢复基线锁定为通过验收的 rc.20 桥接包。

## 发布门禁

- 从 rc.17 在 macOS arm64、macOS x64、Windows x64 验证自动发现、下载、安装、重启 和 userData 连续性；rc.18/rc.19 到 rc.20 的路径另行记录。
- 三平台验证 About 窗口、更新窗口、内测入口、明暗主题和重试行为。
- Stage 后验证 OSS/CDN 对版本资产的 HEAD、Range、长度、SHA-512 与压缩响应。 `insight-update.json` 允许 gzip/Brotli，但 `identity` 表示必须与原始对象一致，压缩表示解码后 必须通过相同摘要和签名验证；其他版本资产仍禁止传输压缩。门禁通过前不得 Promote。
- 三平台验收和 CDN 门禁通过后，才把 legacy Candidate 指针推广并冻结到 rc.20。 失败则使用更高版本修复，不替换已发布字节。
