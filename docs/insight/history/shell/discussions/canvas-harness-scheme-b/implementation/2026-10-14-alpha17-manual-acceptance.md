# alpha.17 普通用户手测

先安装 `insight-ai-desktop-canvas-plugin-0.3.0-alpha.17.tgz`，重启 Harness。此次只验成果展示和打开体验；现有成果优先，不必为了验卡片重复生成。

## 1. 检查入口与原有成果

回到此前 alpha.16 已成功生成素材、出现“画布成果”卡片的对话。

目标：输入区的画布 ID 输入框及测试按钮消失；原成果变成画布真实名称、图片和唯一“打开画布”按钮；没有张数。重启/切换回来后仍在。普通附件卡片保持原样。

## 2. 验单图与方形预览

在只有一个画布产物的成果卡中点击“打开画布”。

目标：打开原画布并自动聚焦来源节点。图片在方形框内等比完整显示，横图/竖图允许留白，不应拉伸或截断。外框紧贴标题、按钮和图片，不占满整行。名称略长时外框可适当扩宽；特别长的名称可悬停查看全名。

如果暂无现成单图，可直接复制：

> 创建一个叫“新品推广”的画布，生成一张简单的商品展示图，完成后告诉我结果，不用打开画布。

## 3. 验四图、三图和换行

优先找同一轮次中已生成三张/四张素材的成果卡。若没有，可在新对话复制以下一条（只需选所缺的数量执行）：

> 创建一个叫“商品展示方案”的画布，为同一件商品生成四张不同背景的展示图。一次完成，不用打开画布。

或：

> 创建一个叫“商品展示方案”的画布，为同一件商品生成三张不同背景的展示图。一次完成，不用打开画布。

目标：每个画布只有一个卡片和一个打开按钮。拉宽窗口或收起右侧面板，四张一排；缩窄可用对话宽度后四张2+2，三张2+1。外框跟着内容宽度收缩，图片仍为方形、不拉伸。点击按钮打开原画布，不指定其中某个节点。若已有超过四项的卡片，只展示前四项，仍按多项打开画布。

## 4. 验普通附件与未打开画布的 Agent

新建对话，上传普通图片，只让 Agent 描述图片。

目标：不出现画布成果卡。

关闭所有画布标签，再复制：

> 创建一个叫“正式入口检查”的空画布，加一个文本节点，内容是“画布未打开也能操作”。只保存，不生成素材，也不用打开画布。

目标：创建/保存成功，删除测试按钮没有影响 Agent 通信；这一步没有生成素材，因此不应出现成果宫格。

## 5. 可选视频与失败状态

已有视频成果可直接检查：方形预览不自动播放，点击唯一按钮打开正确画布。暂时没有视频则无需为此额外生成。

遇到“预览不可用”或标题以 ID 保底时，记录真实截图：画布入口应仍可点击。来源节点已删除时应打开原画布并提示节点不存在，不新建或再生成。

反馈请带：步骤、你的原始消息、是否重启过 Harness、卡片截图，以及点击后是否打开正确画布/节点。无需复制函数名或工具参数。
