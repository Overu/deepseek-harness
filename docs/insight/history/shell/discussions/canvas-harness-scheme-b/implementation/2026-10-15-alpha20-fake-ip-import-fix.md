# alpha.20：修复已生成图片不能导入画布

日期：2026-10-15。对应用户alpha.19真实账号第2步失败；保留原图和已创建画布，不重复生成或导入。本版不改Core、后端、原生Store/保存/生成，也不扩工具数量。

## 实际根因

核对本次失败会话：media-generator已经成功返回 `code:0 / status:success / data.image_list:[URL字符串]`；canvas_assets成功返回1个generatedImages引用，canvas_create创建103334且runtime ready。canvas_asset_import拒绝发生在远端图片下载，未触达OSS上传或画布节点新增。

系统DNS将原图域名解析为198.18.0.119。该Fake-IP处于基准测试保留网段，alpha.19的公网地址检查因此拒绝；而curl通过本机网络代理可正常读取。错误被合并成ASSET_NOT_FOUND，使Agent又提出重传/重生选项。此前公开PNG烟测没有覆盖这个真实素材域名与Fake-IP组合，隔离夹具也未模拟它。

只读复现结果：原图HTTP200、image/jpeg、135059字节；固定HTTPS DNS返回真实公网地址后，同一读取器可以正常读取。最终修复版自动完成此回退，并与用户已有本地原图SHA256一致。未调用生图、未提交OSS或新增节点。真实生成响应的字符串数组结构现已核实；alpha.19交接中“真实结构未知”已由这次证据补齐。

## 最小修复

- `src/host/remote-image-dns.ts`：仅域名的系统DNS全部为198.18/15时使用的独立HTTPS DNS。解析入口固定为Cloudflare，经固定公网bootstrap连接，保留Host、SNI和TLS证书校验，只发送域名/查询类型，不发送素材路径、签名或账号凭据。查询限8秒、32KiB，并受整个下载30秒总限约束。
- `src/host/remote-image-reader.ts`：触发受控回退后仍检查所有结果均为公网地址，实际图片连接固定IP并保留原域名。字面量198.18、其他私网及混合危险结果继续拒绝；没有放开保留网段、自动跟随跳转或用curl绕过检查。
- 读取错误保留兼容码，增加安全的阶段信息[dns]/[network]/[http]/[content]/[timeout]/[url]，不暴露完整签名URL。
- `guidance/desktop-canvas-workflow/references/recovery.md`：已确认来源时把下载故障与素材缺失区分；不推荐重传、重生或无意义重试。行为规则仍仅在中心维护。
- 两个网络测试文件新增Fake-IP真实故障类型与失败关闭回归；版本和开发文档同步。本轮没有新增工具或改动素材上传/节点保存代码。

取舍：命中Fake-IP时额外向固定公共DNS服务查询素材域名，不包含URL路径、query或身份；正常公网DNS不使用该服务。独立DNS不可达或仍返回危险地址时明确失败，不降级连接Fake-IP。原图仅在本地已有文件并不自动构成任意文件读取授权，本轮不新增全盘路径导入。
