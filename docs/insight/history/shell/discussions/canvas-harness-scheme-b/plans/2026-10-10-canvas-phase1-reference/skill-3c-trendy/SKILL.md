# 头戴式耳机赛博潮流视频

本文件是方案 B 的设计草稿，工具尚未实现，模板尚未配齐姿势素材。正式接入后按下述流程工作；当前不要将本草稿当作可执行功能。

模板目录将本 Skill 映射到 `3c-trendy-headphones` 的指定 revision；结构参考[模板草稿](../template.json)。业务说明与 API / SSE 设计见[落地设计](../../2026-10-10-canvas-skill-3c-trendy-design.md)。不要直接将模板草稿作为 workflowData 提交。

## 何时使用

用户要求用头戴式耳机商品图与模特图制作赛博、霓虹、潮流视频；或通过明确画布 / 节点引用修改本模板的关键帧、分镜或人物风格素材。用户只是询问模板、参数或制作方式时，提供说明，不启动生成。

本版本的佩戴、拿取和舞动动作针对头戴式耳机。其他 3C 商品先判断是否有适配模板，不把“耳机”简单替换为商品名后执行。本模板采用生成式参考图和视频，不能以保持像素完全不变作为已满足条件。

## 取得业务输入

必需 `product_image` 和 `model_image`，使用用户附件或明确选定素材的引用，用户不必提供已上传 HTTPS URL。姿势图使用模板目录中经过验证的默认素材，允许用户覆盖 `pose_reference`；不能使用旧模板缓存的素材 URL。

结合图片和用户说明提取可见商品外观，不编造品牌、性能卖点。用户明确要求保留的颜色、logo、结构进入所有相关镜头约束。两张附件角色不明或关键输入缺失时合并成一次询问；技术参数采用模板有效默认，不逐项追问模型、分辨率和时长。

默认完整交付为21张生成图片（5关键帧、16人物风格变体）、5段视频、1个本地拼接无声成片。成片顺序为视频1至5；不要宣称16个变体都进入成片，也不要宣称已有音乐。

## 准备与启动

调用 `canvas_template_prepare`，输入目录规定的 templateId / revision 与业务槽位。工具负责参数、账号权限、依赖、输入顺序、素材绑定及规模校验；不自行构造节点 UUID、猜模型枚举或执行个人机器脚本。

- `missing_inputs`：一次说明必要缺失项，补齐后重新准备。
- `unsupported_product`：解释当前动作不适配，使用用户同意的适配场景。
- `unsupported_params`：解释可用的业务选择；不默默改变用户明确的画幅、时长或商品保留要求。
- `prepared`：使用返回的 planId 启动。用户已经请求生成、输入完整且未触发批量确认时，无需追加通用确认。

调用 `canvas_template_start(planId)`。超过30张生成图片或6条生成视频时，由工具 / 交互卡获取真实用户确认，确认绑定具体计划。不要传模型自拟的 `confirmed=true`；确认超时不等于批准。

## 结果与异常

按工具返回的真实阶段展示画布、可用关键帧、分段与成片。生成中不创建 cron，不周期调用 `canvas_run_get`，不处理 SSE 心跳；插件服务用 SSE 维护状态。仅在用户询问状态时读本地运行状态，或按工具提示做一次明确恢复。

`submission_unknown` 表示提交结果尚未确定，不重新提交生成。成片完成而人物变体失败时，分别说明成片已完成和素材包部分完成；生成完成通知不等于成片已经合成、上传并保存。

只有最终媒体可用、保存成功时展示完成结果。首期本地拼接需要 Web 执行端；画布关闭时可以等待重开续接，不宣称退出客户端后本地仍在合成。

## 修改指定节点

用户通过明确节点引用要求修改时，调用 `canvas_node_update`，带 canvasId、nodeId、选中时版本及业务修改；执行前工具重读当前状态并返回实际影响范围。

仅改视频3动作时复用M1/M2，重跑V3后本地重合成；改M3姿势时影响M3/V4/V5/成片；改某个人物变体时不影响视频链。更换商品图影响完整图。运行中修改先等待或停止旧任务，保留旧产物为历史，不自动重跑不相关分支。

局部计划共用批量确认与启动规则；不删除既有画布，不用同名节点标题猜目标，不让画布标签切换改变正在执行的对象。
