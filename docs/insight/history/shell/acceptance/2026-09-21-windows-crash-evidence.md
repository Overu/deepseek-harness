# RC16 Windows 闪退取证

目的：区分 renderer 卡死/退出、Harness 退出和外部控制台抢焦点。不要先清理数据、重装、改变权限或显卡设置。

## 当前 RC16 用户操作

1. 从客户端菜单 `Harness → 查看 Harness 日志` 打开日志所在目录，保持资源管理器窗口打开。
2. 使用无敏感内容的新会话；记下当前时间和权限。切换“完全权限”后输入简单文本（如 `你好`），注明是否尚未发送就卡住。
3. 只复现一次。若卡住但尚未退出，等待约 10 秒；若必须强制结束，记录强制结束时间，不将该退出当作自发闪退。
4. 立即复制 `harness.log`，保留故障时文件，避免继续反复重启混入新日志。提交时提供末尾约 300 行，先遮盖 token、密钥、手机号、敏感文件名和业务内容；不要上传整个用户数据目录。
5. 按 Win+R，输入 `eventvwr.msc`。打开“Windows 日志 → 应用程序”，按故障时间查找 Application Error、Application Hang 或 Windows Error Reporting（常见 ID 1000、1002、1001）。复制“常规”内容，保留进程名、故障模块、异常代码和时间；没有匹配事件也请说明。
6. 按 Win+R，输入 `winver`，记录 Windows 版本/内部版本号；附测试正常的 DSH Desktop 安装包版本和一段不含敏感内容的任务栏闪烁视频（可选）。

补充：Windows Terminal 是否设置为默认终端、是否使用中文输入法、是否在远程控制会话中发生，对定位有帮助。无需修改这些设置。
