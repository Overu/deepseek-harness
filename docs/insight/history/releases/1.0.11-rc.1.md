## 后续确认的更新检查缺陷

2026-11-03 用户报告已安装的 1.0.10 macOS arm64 五连击内测检查显示“更新暂时中断”。隔离诊断使用与已安装应用相同的 Electron 44.7.0 和 ASAR 内 electron-updater 6.8.9、原始 1.0.10 reader，确认第一份 V3 指针 HTTP 200、`redirected=false`，但 `response.url` 为空；严格 URL 校验在版本比较前拒绝响应。两个发布版本共用这处传输实现。前述 Node reader 验签没有覆盖 Electron，因此不能据此断言实际客户端可以发现更新。

源码修复在 Insight 专用 Electron adapter 中仅补齐 `redirect:error` 且未重定向响应的空 URL，保留原 URL、状态、签名和哈希校验。正式 helper 的真实 Electron/MacUpdater 隔离检查已返回 `isUpdateAvailable=true`、`1.0.11-rc.1`；未下载或安装。真实回环回归验证直达 200、404 和拒绝 302 且目标未被请求；Main 接线单测约束实际更新发现使用该 adapter。原用户目录未写入。原生回归已在 macOS 运行通过；无图形环境的 Linux 会跳过，不计为通过。

修复尚未打包或发布，当前 CDN 与旧渠道指针未改。已安装的 1.0.10 和 1.0.11-rc.1 不能仅靠调整目录或发布指针自愈，需要手动安装未来修复版本；交付事项见[后续清单](../../follow-ups.zh.md#update-check-fix-delivery)。
