# 关联与执行

由Agent结合用户要求、上下文和工具事实识别参考关系，不使用固定关键词规则代替意图判断。引用节点或上传文件本身不要求连线；只有用户要使用画布生成且某素材确实作为该次生成输入时，才将其转为真实依赖，无需用户额外说“连线”。规则适用于图片、音频、视频及文本输入。

同画布已有参考节点直接复用；外部附件先导入为对应素材节点，再连接生成目标。先读graph，已有来源→目标连线则保留，仅补缺失边，不重复加边。独立方案、分析对象或备用素材不因出现在对话中而相连；不要按坐标自动连附近节点。以参考图为基础做海报、参考音频生成类似音乐，都应保留真实来源→目标关系，不能只把名称或URL写进提示词便宣称已经参考。

先复用/导入本次实际使用的参考素材，再创建需要的文案与目标节点。canvas_node_edit使用ops[]，每项op为add/edit/remove/configure；新增标题、正文和提示词放在node.changes内。可合并独立修改；新增节点先取得保存回执中的真实ID，再建立引用它的连线，不猜ID或使用临时别名。canvas_models查询当前可用模式/模型与标量参数，用configure项保存；用户已指定的比例/模型/清晰度优先，其余按用途采用原生可用默认，不硬编码永远可用的模型。通常每个目标先产出一张，不自行扩大数量。

canvas_get(view:graph)确认真实端口和兼容输入，再canvas_edges用ops[]的add/edit/remove/reorder保存真实依赖；回读核对目标收到本次预期的文本、图片、音频或视频输入，并选择兼容模式；不兼容时查询其他可用模式，不能静默丢弃参考后独立生成。普通image节点有文本与图片输入，但以实际graph和原生校验为准，不能凭模型名称断言“文案不能连接”。文本只作旁注时，不宣称已用于生成。

每次写入用最新confirmed版本，saved回执的新版本可供下一步使用。同一画布写入顺序执行；ops的每项独立保存、顺传版本，失败即停且不回滚，恢复规则见恢复章。普通写前/后读取用refresh:false，不逐步强制重载。用户正在编辑时尊重EDITOR_BUSY，不绕过保护。

明确要成品时，对已保存、依赖就绪的目标调用canvas_run({canvasId,nodeIds:[真实目标ID],expectedVersion})，单目标也用数组，无需打开画布。多个独立且输入已就绪的目标可合为一次调用；不是整图执行或DAG调度器。若A生成后才供B使用，先生成A并确认新产物，再读取最新版本运行B；不能把输入未就绪的A、B一次提交。只运行用户当前目标，不自行执行模板或扩大范围；高清/分层/抠图等专用节点处理使用专用处理章节。

每批共用一个jobId，results列出各节点。submitted不是完成；用job_output收集同一Job的真实终态、results和outputs，Core会回传完成通知。旧outputs不是本次产物，实际数量不足时不能宣称全部完成。paused表示只受理当前容量内的前缀，续跑见恢复章。job_kill只停止跟踪，不等于取消云端生成。

## TTS配音

要求把文案念出来时，创建普通audio节点，canvas_models(nodeType:audio)查询当前TTS模型与seniorParamHints；原生新节点默认TTS。已有文案节点时建立文案→配音的真实文本输入，不把待朗读正文改成“请念出以下文字”或重复填入prompt造成双份内容。要求配音时将普通音频节点configure为tts；上传音频是素材，不能直接当生成节点运行。

用同一canvas_models的view:voices按需查询公共音色，voiceSource:my查询已有个人音色；voiceId可查详情。复用用户指定且当前可用的音色；未指定时优先选model_declared的中文自然音色，不要求用户填写枚举。列表不含合适音色时再问偏好，不编造ID，不自行克隆。compatibility:not_declared表示服务未声明完整模型映射，不能承诺所有音色均兼容；缺失/下架或明确不匹配会拒绝。

configure使用独立voiceId和seniorParams，语速、音调、音量、情绪等只填当前模型真实声明的字段/范围/step，不硬编码各模型共同支持。局部高级参数合并；换模型重置原生默认，之后核对所需音色与参数。saved后回读确认，再canvas_run运行该audio节点并等待新音频终态。完成后简洁交付可播放成果与画布入口，不打印模型/音色ID或计数表；用户明确问配置时才提供。音频计数audios与图片/视频分开；不要把已导入音频或旧产物当本次TTS结果。

## 文生音乐与音乐参考

根据用户目的选择模式：描述风格生成音乐使用text_to_audio；将已有音乐作为输入生成类似音乐使用audio_to_audio。向canvas_models明确传入对应modelType查询真实可用模型和参数，再configure保存；不要把音乐请求转换成TTS朗读。模式/模型不可用时如实说明，不自行换成配音或忽略参考。

text_to_audio只接受文本；audio_to_audio需要且仅接受一个已就绪的音频参考，可另接文本要求。引用画布音频时复用已有节点；外部音频附件先导入为audio素材节点；再创建/配置普通audio目标并建立audio_source→audio_target连线。多个候选音频无法判断时先明确来源，不擅自取第一条或删掉用户已有输入。先完成配置和连线再生成，无需打开画布或依赖参数面板自动切模式。

音乐模式不需要查询音色或设置voiceId。基础参数使用paramHints，高级字段使用seniorParamHints；标题、歌词遵循文本maxLength，其他参数依模型真实选项、数值范围和step，不猜枚举。开启customMode时提供标题，非纯音乐还需歌词；遵循用户指定的纯音乐、歌词等要求，未指定时选原生可用默认。模式/模型切换会重置参数，保留prompt后回读确认。参考音频来自真实连线，不填写uploadUrl绕过来源关系。

saved后回读目标模式、参考输入和参数，再canvas_run并等待新音频终态；按实际outputs数量交付，不能把来源音频、旧产物或仅提交的任务当作新成果。
