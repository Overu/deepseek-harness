# 异常恢复

rejected/effect:none代表本次未写入，不自动授权换模型、参数或来源重试。尊重用户失败即停要求。版本冲突先读取并核对用户新内容，不能机械替换expectedVersion覆盖。

批量编辑的saved表示各项均保存；partial表示仅completed中的前缀已保存，nextIndex仅定位未完成位置，不授权自动重试。保留成功项，不整批重发；逐项检查实际回执，只有确认未生效且仍符合用户目标的剩余项才可继续。未知项先核对，不能盲目从nextIndex续写。

生成paused时，results可能已有已提交节点，nextIndex是尚未提交的起点。先等同一job结束，再canvas_get(refresh:false)读取最新confirmed版本，只对仍需生成的剩余nodeIds发起新调用；paused.version是提交时版本，不当成任务结束后版本。零提交预检失败应准确报告检查故障，不称模型生成失败；保留原图和来源，不换来源重做。

submission_unknown/create_unknown/upload_unknown或monitoring_unknown不能当“未执行”；保留真实画布/节点/job标识，按现有回执读取核对，不重复提交、重建节点或重新生图。refresh:true只用于明确权威同步、冲突或未知恢复，可能重载可见画布。

转存完成但节点未保存时，素材工具保留同账号/会话的已确认上传；恢复由实际回执决定，不自动重加。节点saved但素材登记失败时保留节点，不因登记失败改报保存失败。

先区分来源缺失、读取失败和内容不合规。ASSET_NOT_FOUND表示可信来源不存在；ASSET_READ_REJECTED表示来源存在但读取/DNS/网络/长度或稳定性检查失败；ASSET_VALIDATION_REJECTED表示格式、轨道、大小或时长不合规。已经取得assets[].source后，不把502、过期链接、HTML、损坏文件当作用户没给素材。说明真实故障，保留原引用和已有画布，不推荐重新上传/生成或反复试同一导入；确实缺少来源或用户要换素材才补问。

侧栏关闭不是服务不可用。初始化失败后可按真实回执使用只读refresh:true恢复；Client服务模块未成功加载时，后续明确调用可重新加载，健康Runtime不重建。CONTEXT_INACTIVE或原生FRAME_INACTIVE可表示其他窗口持锁/旧版参与者，不能按FRAME前缀断言侧栏没打开。先完成/保存原窗口编辑，再关闭或重载相关窗口，不超时强抢。升级所有权协议后需完整重启客户端并重载所有相关画布窗口；握手不能证明不存在未登记的旧窗口。冻结窗口仍持锁时保留占用，不能自动打开侧栏绕过。EDITOR_BUSY、登录、版本及未知栅栏各按真实前提恢复，不借另一会话或接口规避。

Core Jobs跟踪取消、客户端完全退出、Host重启不承诺后台取消或跨进程恢复。已有可信产物只读检查，不以新一轮生成修复跟踪/标题/预览问题。
