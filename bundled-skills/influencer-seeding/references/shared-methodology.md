### 6.1 人性需求 7 大主分类 · 224 项子类别

**铁律**：严格使用标准名称，不得自创或改写。主分类与子类别的真值以随包的 [human-needs.json](human-needs.json) 为准（7 大主分类 224 项：生理 45 / 安全 20 / 情感 64 / 尊重 22 / 认知 18 / 审美 14 / 自我实现 41）。

| 主分类 | 项数 | 典型子类别 | 常见错误 → 正确 |
|--------|------|-----------|----------------|
| 生理需求 | 45 | 愉悦、玩耍、味道、解压、舒适、休息 | ❌感官满足 → ✅愉悦 |
| 安全需求 | 20 | 家庭和谐、信赖、食物安全、自然保护 | ❌安全感 → ✅信赖 |
| 情感需求 | 64 | 亲人陪伴、亲人关怀、友人相聚、组织 | ❌归属感 → ✅组织 |
| 尊重需求 | 22 | 被认同、被理解、被关注、地位、成就 | ❌被认可 → ✅被认同 |
| 认知需求 | 18 | 好奇、发现、乐趣、体验、效率 | ❌探索欲 → ✅好奇 |
| 审美需求 | 14 | 艺术美、时尚美、优雅、简洁 | ❌美感 → ✅艺术美 |
| 自我实现 | 41 | 激情、追寻自我、奉献、传承、精彩 | ❌追逐热爱 → ✅激情 |

**标注格式**：`人性需求 | 尊重需求 - 被认同`

### 7.4 创意手法选择决策树

```
产品功能明确？
  ├─ YES → 消费者投射（产品示范 / 产品体验 / 生活片段）
  └─ NO → 情感导向？
           ├─ YES → 电影型（感情羁绊 / 成长与逆袭）
           └─ NO → 品牌升级？
                    ├─ YES → 艺术化（意象化 / 插画）
                    └─ NO → 差异化竞争？
                             ├─ YES → 夸张（极致的夸张 / 比喻）
                             └─ NO → 新闻型（品牌主张 / 人性洞察）
```

## 创意方法基线（creative-generation-evaluation 与 influencer 两技能共用）

## 消费者洞察规范（四要素 / 三模式 + 长度与检查清单）

四要素公式：`[目标人群描述] + [痛点/现状] + [渴望/期待] + [产品角色]`；以下为 原包 50 案例历史整理（样本未随包核验）的三模式、长度约束与检查清单。

**标准公式（三模式灵活选择）：**

**模式 A：四要素完整（36% 案例使用）**
- **适用：** 高端品牌、复杂产品
- **长度：** 90-100 字
- **公式：** `[目标人群描述] + [痛点/现状] + [渴望/期待] + [产品角色]`
- **示例：** "消费者在享受高端餐厅、酒吧或 SPA 服务后，买单时的昂贵消费往往会冲淡先前的愉悦。The Entertainer 洞察到'省钱'本身就是一种极大的情绪价值，通过将优惠与庆祝活动挂钩，将沉重的账单转化为狂欢的惊喜。"（98 字）

**模式 B：三要素（44% 案例使用）**
- **适用：** 大多数情况
- **长度：** 70-80 字
- **公式：** `[目标人群] 渴望 [渴望/期待]，但 [痛点/现状] 让他们无法实现`
- **示例：** "人们常常会被一些微不足道、甚至有些荒诞的琐事困扰并陷入过度思考。通过咀嚼具有韧性的 Twizzlers，能给大脑一个缓冲空间，在'嚼一嚼'中化解那些无谓的内心冲突。"（75 字）

**模式 C：场景驱动（20% 案例使用）**
- **适用：** 快消品、情感导向
- **长度：** 55-65 字
- **公式：** `在 [具体场景] 中，[人群行为]，他们真正需要的是 [情感需求]`
- **示例：** "在极具压抑感的职场社交中，人们往往因为担忧社交距离和礼仪而不敢表达真实想法。口气清新不仅是生理舒适，更是卸下伪装、坦诚沟通的勇气来源。"（62 字）

**检查清单：**
- [ ] 人群描述是否具体？（❌ "消费者"→✅"身处职场漩涡的现代精英"）
- [ ] 痛点是否场景化？（❌ "压力大"→✅"无休止的打扰与琐事"）
- [ ] 渴望是否深层？（❌ "想要放松"→✅"找回自我掌控感"）
- [ ] 产品角色是否隐喻化？（❌ "提供舒适"→✅"通往宁静的屏障"）
- [ ] 长度是否在 55-100 字之间？（基于 原包 50 案例历史整理（样本未随包核验））
- [ ] 是否选择了适合的模式（A/B/C）？

**优秀示例（四要素完整）：**
> "对于身处职场漩涡的现代精英而言，办公室里的每一个角落都充满了无休止的打扰与琐事，他们急需一个能彻底隔绝噪音、找回自我掌控感的私人空间，而座驾可以成为一道通往宁静的屏障。"（88 字）

## 创意阐述三段式结构与长度

```
1. 核心策略说明（1-2 句）- 给手法起专业名称
2. 视觉/叙事手法描述（2-3 句）- 具体执行细节
3. 人性需求连接（1-2 句）- 如何满足深层需求
```

**优秀案例（哈雷戴维森）：**
> "这组作品采用了典型的'心理地图'式表现手法。它没有直接展示驾驶的快感，而是将'渴望'视觉化。插画中充满了拟人化的生物、变异的景观和丰富的色彩，营造出一种摇滚式的、迷幻的氛围，精准契合了哈雷品牌狂放不羁、挑战常规的文化内核。它传达出：当内心某种渴望萌发时，哈雷成为表达这份渴望的一种方式。"

## 视觉表现手法库

**在创意阐述和视觉 Prompt 中可运用的视觉表现手法：**

| 手法 | 描述 | 案例参考 | 执行要点 |
|------|------|----------|----------|
| **微缩艺术** | 巨大物品 + 微型人物，比例反差 | Goodwill"捐赠物品，创造职业" | 创造"物品=职业现场"的隐喻 |
| **超现实主义插画** | 拟人化生物、变异景观、迷幻色彩 | 哈雷戴维森"当召唤来临时" | 将"渴望"视觉化，营造摇滚迷幻氛围 |
| **视觉蒙太奇** | 核心符号与宏大意象融合 | PencilWings"铅笔 + 桥梁/灯塔/巨轮" | 铅笔=创意源泉，桥梁/灯塔/巨轮=执行力 |
| **场景错位** | 将日常场景置于异常环境 | 日产楼兰"办公室搬到高速公路" | 创造视觉反差，突显产品价值 |
| **长条插画叙事** | 装饰感插画，讲述完整故事 | 多芬滋养秘笈"全球远征" | 将获取过程夸张化，反衬产品便捷 |
