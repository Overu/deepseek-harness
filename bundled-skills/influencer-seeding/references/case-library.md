### 9.1 康师傅案例 · 8 大方法论（快消 + 明星代言）

**来源**：康师傅"好面自有好面相"郭麒麟代言全案（总曝光 2.4 亿+，总互动 225 万+）

| # | 方法论 | 核心逻辑 | 可复用要点 |
|---|--------|----------|-----------|
| 1 | 双话题驱动 | 娱乐话题（破圈）→ 品质话题（心智）→ 场景种草（转化） | 娱乐话题负责前期曝光，品质话题负责中期心智，场景种草负责后期转化；须有明星与品牌的天然契合点 |
| 2 | 人群分层沟通 | 忠粉（多维升级演绎）→ 流失人群（精准触达）→ 潜在人群（重构心智） | 按人群状态而非人口属性分层；分阶段先核心后泛人群 |
| 3 | 场景锚定 | 找不同人群的"共同场景" → 场景承载情感需求 → 场景化沟通 | 场景要具体有画面感（时间+地点+行为）；核心场景＋延展场景 |
| 4 | 娱乐营销事件设计 | 找契合点 → 悬念/爆料/官宣路径 → 借明星关系网增真实性 | 预热期媒体爆料、引爆期双官宣上热搜、延续期趣味物料＋粉丝互动 |
| 5 | 粉丝互动策略 | 设计互动机制 → 明确数字目标 → 分阶段解锁福利 | 超话盖楼（明确楼数解锁花絮）、点赞释放视频、抖音趣味共创 |
| 6 | KOL 内容抽屉 | 为不同类型 KOL 提供"内容抽屉"，核心信息统一、表达方式多样 | 四类抽屉：行业背书 / 大曝光 / 美食制作 / 场景演绎 |
| 7 | 三阶段传播节奏 | 预热&官宣 38% → 心智夯实 5.5% → 持续种草 56%（合计 99.5%，实际预算需归一） | 明星代言 2–3 周快节奏，重引爆＋种草（对比 Max Mara 的 20:60:20） |
| 8 | 金句海报创意 | 明星专业术语 × 产品卖点 → 朗朗上口的金句 | 用明星语言体系表达产品卖点 |

**人物关系网应用**：明星搭档/好友互动增加真实性；粉丝参与扩大传播；花絮内容提升传播性。

### 9.5 917 获奖案例核心要点

产品就是解药 18.8% 排第一、社会问题 13.1% 第二 → 可供参考的创意方向是「产品价值＋社会立场」的连接；公益慈善类获奖最多（12.2%），本质是让旁观者变成参与者；单一手法获奖少，组合手法获奖多。高频组合：产品就是解药＋幽默、社会问题＋感同身受、意象化＋价值认同。

**5 大可复用创意公式**：

| 公式 | 结构 | 案例 |
|------|------|------|
| 极端场景放大法 | 日常问题 → 极端场景 → 产品解决 | Specsavers |
| 身份标签焦虑法 | 身份标签 → 失去恐惧 → 品牌拯救 | StreetEasy、Nike |
| 自然权利对比法 | 自然权利 → 人权剥夺 → 品牌行动 | Amnesty International |
| 数据颠覆偏见法 | 既有偏见 → 真实数据 → 认知颠覆 | Orange 残奥 |
| 仪式感创造法 | 日常行为 → 仪式化 → 情感连接 | Heineken、Apple |

### 9.6 事件营销 3 要素

**社会话题性**（能引发讨论）· **参与门槛低**（易模仿）· **品牌关联强**（与品牌精神一致）。
