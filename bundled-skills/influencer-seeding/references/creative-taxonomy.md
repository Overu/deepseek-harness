# 创意手法分类体系（标准版）

> 本文件自 `SKILL.md` 拆分而来（2026-09-18），按需查阅；不要默认全量加载。


**当前维护口径：3 大主分类、98 项子类别。本包机器字典见 [creative-taxonomy.json](creative-taxonomy.json)，来源见 [taxonomy-provenance.json](taxonomy-provenance.json)；更新时同步二者并核验枚举计数。**

#### 一、广告型创意（5 大类，70 项子类）

**（一）消费者投射（13 项）**：将消费者本身的动机、情绪、价值观附加到产品/品牌上

| 编号 | 子类名称 | 说明 |
|------|---------|------|
| 1 | 价值认同 | 消费者对某类价值的认可和共识，形成共通理想和追求 |
| 2 | 生活片段 | 用日常生活短片段展现产品如何适合消费者生活方式 |
| 3 | 感同身受与共鸣 | 展示相似经历，使消费者产生身临其境的共情 |
| 4 | 产品体验 | 展示体验产品过程，建立消费者与产品互动关系 |
| 5 | 产品示范 | 演示产品使用场景、成效、后果，建立认知和认可 |
| 6 | 消费者证言 | 通过客户或专家向消费者强调产品好处，取得信赖 |
| 7 | 消费者故事 | 通过真实消费者故事情节展示产品和品牌信息 |
| 8 | 托物言志 | 运用象征手法，通过描述客观事物表现品牌价值主张 |
| 9 | 鼓励行动 | 呈现社会现象或问题，激励人们采取行动解决 |
| 10 | 沉浸其中 | 展现用户对产品的特别喜爱并沉浸其中，吸引参与 |
| 11 | 产品就是解药 | 呈现消费者痛点，用产品给出解决方案 |
| 12 | 市井洞见 | 表现普通人平凡生活，描述小人物对产品独特见解 |
| 13 | 消费者独白 | 通过普通消费者内心诉说，引起感同身受 |

**（二）艺术化（20 项）**：用艺术手法美化产品颜值和渲染功能，提升文化内涵

| 编号 | 子类名称 | 说明 |
|------|---------|------|
| 14 | 插画 | 插图形式作为重要视觉传达，突出主题思想 |
| 15 | 中国传统艺术 | 书法绘画、音乐戏曲等传统艺术与产品结合 |
| 16 | 西方当代绘画艺术 | 西方当代绘画风格及元素用于广告创意 |
| 17 | 利用名画 | 世界名画画面元素作为主要创意元素 |
| 18 | 利用舞蹈 | 利用舞蹈动作及韵律串联广告元素 |
| 19 | 利用歌曲 | 将广告讯息编入歌曲或利用节奏旋律加强互动 |
| 20 | 动漫 | 卡通形象作为广告表达核心元素 |
| 21 | 演变 | 以事物长时间变化发展过程为主线贯穿创意 |
| 22 | 错觉 | 利用人眼生理局限或惯性思维产生错觉幻觉 |
| 23 | 浪漫化 | 通过浪漫爱情故事描绘浪漫生活方式 |
| 24 | 创造象征符号 | 建立与产品联想度高的具象化符号 |
| 25 | 利用时尚 | 将时尚文化特征元素融入广告 |
| 26 | 拼贴混搭 | 不同领域文字片语、图片照片混搭重组 |
| 27 | 明星代言 | 利用名人、明星形象提高品牌知名度和喜好度 |
| 28 | IP 形象 | 使用品牌超级符号，快速建立品牌形象感知 |
| 29 | 微缩艺术 | 精细微型模型和场景构建，展现创意细节 |
| 30 | 意象化 | 运用抽象或具象视觉形式传递情感氛围 |
| 31 | 展览 | 结合创意布置和空间设计，呈现艺术展览形式 |
| 32 | 默剧 | 通过肢体语言、面部表情等非语言方式传达信息 |
| 33 | AIGC | 利用人工智能技术生成内容，突破传统创作边界 |

**（三）夸张（14 项）**：集中突出描写商品特征，把事物特征推向极致

| 编号 | 子类名称 | 说明 |
|------|---------|------|
| 34 | 放大好处 | 着重描写产品功能如何解决需求，强化说服效果 |
| 35 | 放大问题 | 放大消费者痛点，引起恐惧心理 |
| 36 | 类比 | 同类或不同类品牌产品比较，宣传某一特点 |
| 37 | 比喻 | 使用相似事物说明品牌产品特征或观点 |
| 38 | 恐吓 | 夸大没有使用产品的危险后果，促使行动 |
| 39 | 制造悬念 | 设置问题或矛盾又不解决，引发关注 |
| 40 | 利用典故 | 借助历史故事、传说、寓言表达品牌概念 |
| 41 | 变快 | 加快过程，描绘超快速变化世界 |
| 42 | 微观世界 | 将正常世界缩小或微小事物放大，独特视角叙事 |
| 43 | 利用动物 | 动物视觉形象拟人化表现，让消费者易接受 |
| 44 | 性感化 | 直接或间接表现与性相关信息，引发关注 |
| 45 | 嫁接 | 将不属于广告的元素拼接，产生融为一体效果 |
| 46 | 极致的夸张 | 抓住典型特征或效果夸张放大，强化冲击力 |
| 47 | 梦幻世界 | 通过色彩画面打造超现实梦境，制造沉浸体验 |

**（四）幽默/有趣（12 项）**：创造荒诞情节、滑稽画面满足娱乐性情感需求

| 编号 | 子类名称 | 说明 |
|------|---------|------|
| 48 | 偷换概念 | 对事物理解换成另一种解释，转移注意力 |
| 49 | 幽默 | 轻松或滑稽有趣画面、文案与产品信息关联 |
| 50 | 增加戏剧性 | 放大产品特点或体验过程，内容跌宕起伏 |
| 51 | 重复 | 多次出现同一文案或画面形象，形成深刻印象 |
| 52 | 讽刺 | 表面意思与本意相反，反讽另一事物表达主张 |
| 53 | 借广告 | 更改其他熟知广告成自家产品或广告语 |
| 54 | 神反转 | 叙事中插入转折剧情，出乎意料又合情合理 |
| 55 | 模式化 | 建立模板，将广告内容套用呈现，形成洗脑效果 |
| 56 | 拆分部件 | 将完整产品或动作拆解成多部分，展现整体特点 |
| 57 | 拟人 | 将产品或品牌人格化，传递价值并表达情感 |
| 58 | 注入情绪 | 将人物情感通过画面中话语、神态等元素表达 |
| 59 | 自嘲 | 通过贬损自我方式达成强化印象或影射对手 |

**（五）理性点（11 项）**：采取理性说服手段，有理有据论证产品优势

| 编号 | 子类名称 | 说明 |
|------|---------|------|
| 60 | 提出问题 | 提出与消费者密切问题，引发思考 |
| 61 | 说理 | 为产品提出购买理由，通过逻辑论据论证 |
| 62 | 从负面看 | 针对产品特点从负面展示，实则说明好处 |
| 63 | 纯文字 | 精炼文案聚焦文字理解，强化说服效果 |
| 64 | 利用名人 | 使用名人背书，拉近距离并建立信任 |
| 65 | 对比 | 与竞争者比较，突显优于或异于对手特征 |
| 66 | 利用热点 | 借势热门事件，获得消费者关注 |
| 67 | 声东击西 | 描绘其他事物，实则重点突出产品特点 |
| 68 | 增加中间环节 | 延长事物步骤和过程，强化卖点 |
| 69 | 只看局部 | 对局部近景特写，增强画面表现力 |
| 70 | 结合媒介 | 利用户外场景表现产品特点 |

#### 二、电影型创意（16 项）

将电影叙事起承转合规律及故事主题融入广告营销视频创意

| 编号 | 子类名称 | 说明 |
|------|---------|------|
| 1 | 初心 | 主人公坚持或找回做某事最初原因、愿望和状态 |
| 2 | 圆梦 | 主人公热爱某事并付出努力，最终把梦想变为现实 |
| 3 | 成就他人 | 主人公发自内心帮助别人，反而成就自己价值 |
| 4 | 寻找答案 | 面对难题，主人公不断尝试发问，最终找到答案 |
| 5 | 探险寻宝 | 获得宝物过程充满艰难险阻，探索过程和收获喜悦更珍贵 |
| 6 | 成长与逆袭 | 坚持做看似愚蠢、不被认可的事情，最后大获成功 |
| 7 | 重新开始 | 因失意或不满，换种生活方式、回到过去、改变轨迹 |
| 8 | 使命必达 | 主人公对任务和目标执着，坚守职责完成使命 |
| 9 | 回家之路 | 千辛万苦的回家之路 |
| 10 | 爱情故事 | 主人公经历浪漫甜美坎坷，最终走到一起 |
| 11 | 感情羁绊 | 和家人或朋友的误会隔阂和遗憾，最后被解开 |
| 12 | 对抗强大 | 主人公化身英雄，对抗比自己强大很多倍的力量 |
| 13 | 解除危机 | 主人公或同伴陷入危机，主角拯救大家逃离危机 |
| 14 | 对抗规则 | 对老旧或不合理规则，勇于打破和对抗 |
| 15 | 人生开挂 | 获得开挂能力，满足观众白日梦 |
| 16 | 觉醒 | 成长低谷中因某些契机带来醒悟后的自我觉醒和蜕变 |

#### 三、新闻型创意（12 项）

将新闻结构和选题范畴融入社会化营销创意创作

| 编号 | 子类名称 | 说明 |
|------|---------|------|
| 1 | 社会问题 | 影响社会成员健康生活和社会协调发展的问题 |
| 2 | 公共议题 | 引发人们讨论的热点性事件或话题 |
| 3 | 普世价值观 | 全人类共同道德认同，真善美、公平、正义、自由等 |
| 4 | 社会主义核心价值观 | 富强、民主、文明、和谐、平等、公正、法治等 |
| 5 | 人性洞察 | 替人们说出想要却无法说出口的心里话 |
| 6 | 消费者洞察 | 洞察"消费者缺什么"，填补"理想与现实之差" |
| 7 | 文化洞察 | 连接用户某种文化或群体，创造精神角落 |
| 8 | 行业痛点 | 揭示或解决某个行业中尚未被满足的广泛渴望需求 |
| 9 | 品牌使命 | 发现用户对品牌需承担责任的期待，做出承诺并行动 |
| 10 | 品牌主张 | 品牌向消费者传达的核心价值观，活化与人格化 |
| 11 | 产品概念 | 彰显产品满足消费者需求的独特优势，区别竞品 |
| 12 | 竞品诉求 | 比对手更了解竞品，突显竞品未满足需求的不良后果 |
