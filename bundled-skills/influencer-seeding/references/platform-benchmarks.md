# 平台指标、预算与效果预估：唯一口径

本文件替代原来缺乏可复核证据的固定 CPM/CPC/CPE、阅读率、报价、爆文率和预算比例。保留原技能“预算＋分层 KPI＋优化决策点”输出；参数来自本次 DSH 检索、有效 TikHub 字段、客户数据或明确假设。

## 指标字典

| 指标 | 定义 | 必须说明 |
|---|---|---|
| 展示 impressions | 平台定义的展示次数 | 自然/付费/混合、版位、统计期；不能用粉丝×阅读率冒充 |
| 阅读/播放 views | 实际打开/阅读/播放字段 | 各平台阈值不同；不按固定比例换算曝光 |
| 去重触达 reach | 在声明范围内去重的人数 | 时间窗、渠道、去重依据；毛展示及粉丝和不能替代 |
| 公开互动 actions | 明确约定的赞、评、藏、分享之和 | 分项存在才相加；次数不是人数；缺项时只报具名的部分和 |
| 互动率 | 指定互动 ÷ 指定曝光/阅读/播放/粉丝 | 把分母写在指标名中；不同分母不可比较 |
| CTR | 同窗口同链路的指定点击 ÷ 展示 | 点击位置、广告目标与版位 |
| CVR | 指定归因转化 ÷ 对应点击或访问 | 事件、归因窗口、去重和退款处理 |
| CPM | 对应成本 ÷ 对应展示 × 1000 | 广告费、达人费或全案费用分开 |
| CPC / CPE | 对应成本 ÷ 指定点击 / 指定互动 | 报价推算、平台估算与账户实测分开 |
| CPA3 | 对应成本 ÷ 平台定义的新增 A3 | 品牌/行业、模型定义、周期、去重与成本范围 |
| 销售投产比 | 归因销售额 ÷ 声明的投入 | 保留原 ROI 板块，写明销售额/投入口径，不称净利润回报 |
| 利润回报 | 明确定义的增量利润与成本公式 | 只有利润、退款等证据足够才计算 |
| 爆文率 | 达到预定阈值的篇数 ÷ 符合观察条件的篇数 | 阈值依据、形式、观察期与分母，不套默认 10%–20% |

未知写“暂无公开数据/待核验/基于假设”。每个率须有分母；每个成本须有含费范围；每个数据须有来源、属性和统计窗口。

## 本次样本基线

优先同品牌/品类、平台产品、目标、形式、近似内容年龄和周期的样本；保留实际样本数、筛选排除方法、中位数和分布。普通内容、商业内容、加热状态未知的内容分别标识。小样本仅作规划参考，不能称行业标准。公开累计表现可能已含加热，未区分流量来源时不能称自然流量基线。

星图的报价、预估播放和预估成本依然是平台估算；小红书普通内容不能默认有阅读/曝光分母，PGY 的商业字段另行验收。接口文档示例不算实际数据。

## 预算闭合

逐项列不重复的达人费、额外制作、额外授权/二创、平台/服务/税费、样品履约、投流、其他成本与预留。不适用不强加；达人报价已含制作则不得重复计费。人数、内容数与预算分列。

```text
单项成本 = 整数交付数量 × 单价
已分配预算 = Σ 单项成本
未分配余额 = 总预算 - 已分配预算，必须 ≥ 0
类别比例 = 类别成本 / 明确的预算分母
```

人数比例不能当预算比例；一位达人可以多篇交付。缺少报价时允许明确的规划假设，不当采购承诺。预算区间不能分别取上限后让总和超过 100%。

## 情景预测

```text
付费展示 = 对应广告预算 / 同口径 CPM × 1000
自然展示 = 合格样本或明确平台估算支持的数量；无数据则未知
毛展示 = 自然展示 + 付费展示
```

最后一式仅在单位/统计期一致且组件未重复包含时使用。同一人多次看见可计毛展示，但不能冒充去重人数。含付费的累计指标不能再加一次广告效果。相同预算可以推导同一漏斗的不同层，但不同层不能相加成“新增人群”。未知 A1–A3 迁移/重叠不能直接相加。

互动、点击、转化只用有依据的对应分母和率；不凭公开互动反推成交。保守/基准/乐观分别列参数和假设，不能称未经校准的统计置信区间。缺项可给局部预测，但保留原分层 KPI 板块和待核条件。

### 50 万示例修正（全部为算术假设，非市场基准）

| 明细 | 数量×单价 | 金额 |
|---|---|---:|
| 头部 | 2×50,000 | 100,000 |
| 腰部 | 10×10,000 | 100,000 |
| 尾部 | 30×3,000 | 90,000 |
| KOC | 100×200 | 20,000 |
| 投流 | 1×150,000 | 150,000 |
| 额外制作 | 假设未包含在达人报价中 | 40,000 |
| 合计 | 142 位达人，假设各 1 条 | 500,000 |

假设 CPM 为 50 元，则 15 万投流对应 3,000,000 次付费展示。自然展示没有可靠数据，故自然与总展示保持未知，不沿用原例粉丝×阅读率得到的 65 万“曝光”。互动、点击与成交同样不串接无依据的固定率。

## 优化与归因

阈值来自品牌目标、同口径历史或首测；先核验数据、履约、样本量和归因延迟，再诊断与调整。无法完整归因不是效果不足的预先豁免，也不能补计未观测销售。无合适对照时只报告相关变化。
