# 达人种草营销 v2.6.1

适用于单/少平台线上达人种草。入口为 `SKILL.md`。保留原输出板块、两段式主题确认、用户要求完整全案的例外、篇幅、引用及交付规范；不自动联系达人、下单、投流、发送消息或启动监测。

## 更新

市场/行业/品牌及竞品公开事实优先用 DSH 客户端联网搜索和原文读取；TikHub 补充内容、评论、趋势与达人证据。指标和预算统一到 `references/platform-benchmarks.md`，删除无依据的默认阈值，修复 50 万预算示例。创意方法与案例参考保留，历史统计不作为当前事实；完整人性需求与创意字典随包分发，创意总数纠正为 98。

## 输出不变

第一段：Brief、检索增强、平台趋势、竞品、本品、人群、3–5 个主题，等待确认。用户明确要求直接完整全案时按原例外跳过等待。第二段：种草策略、媒介策略、种草规划、效果预估一次给完。

默认对话直出，明确要求文件/推送才按原方式交付。内部接口与证据结构不展示；见 [输出合同](references/output-contract.md)。

## 依赖

DSH 客户端工具以当前环境为准。TikHub、inspiration-api 与其他营销技能是可选补充，缺失时按本包独立方法与 DSH 检索执行。业务脚本使用 Python 3.10+；真实 API 请求另需已登录企业插件提供的 Node 网关适配器和已有研究预算。默认 dry-run 无网络、无文件写入；见 [脚本合同](references/script-contract.md)。

本包不含客户数据或密钥，不包含旧 README 指向的错误整合模板。变更记录见 [changelog](references/changelog.md)。
