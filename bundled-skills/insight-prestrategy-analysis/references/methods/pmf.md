# PMF 产品与市场契合

**作用与对象**：判断特定产品版本在特定人群与情境下，其需求契合假设获得了什么支持。适合产品机会、价值验证与增长前提研究；拆解产品功能与市场需求本身不等于达到PMF。

**输入**：目标任务、现有方案、本品价值与版本；结合品类选择使用、重复使用、留存、购买、续费、推荐或用户愿付代价等实际证据。资料不足可做假设与验证设计。

**操作**：
1. 明确谁为何使用，核心价值时刻是什么，替代什么做法。
2. 区分首次兴趣、试用、真正获得价值、持续选择与经济可行性。
3. 按人群、版本、渠道和时间检查行为证据及流失原因，识别某个小群体是否与总体不同。
4. 检查补贴、促销、渠道变化、强制使用等替代解释；结合研究理解机制。
5. 判断哪项契合假设获得支持、还差哪类证据，提出最能区分解释的验证。

**可交付**：契合假设、适用人群与版本、支持和反证、行为证据缺口及验证路径。

**边界**：喜欢概念、曝光增长、正向评论或一次购买不足以独立确证PMF；不对所有品类强套相同留存周期、问卷阈值或指标。低频耐用品要用适用的价值与持续选择证据。

**衔接**：3C/STP帮助定义假设，4P/4C解释供给，AARRR检查适用行为。PMF金字塔只是拆解视角，不作为自动评分器；不沿用未核实的“首次提出”归属。参考[来源校准](../source-calibration.md)。
