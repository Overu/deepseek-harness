# 产品生命周期

**作用与对象**：结合时间与市场背景判断导入、增长、成熟或衰退的阶段假设，帮助讨论行动与时机。先区分品类、产品形态、品牌和单品，不能互相借用阶段。

**输入**：同口径较长时期的销量、收入或使用序列，以及价格、分销、竞争、用户渗透、季节性和供给变化。单品年龄或短期热度不足以判阶段。

**操作**：
1. 定义分析单位、地区、观察期间与变化指标。
2. 判断观察到的是需求、供给覆盖、促销、季节、缺货还是统计口径变化。
3. 以导入、增长、成熟、衰退作为解释候选，检查支持、反证及是否存在不同人群的不同阶段。
4. 讨论阶段假设对教育、供给、差异化、效率、更新或退出研究的含义；不要根据曲线形状机械分配行动。

**可交付**：阶段判断或候选解释、依据、阶段相关问题与行动条件。

**边界与缺口**：销量下降不必然代表品类衰退；成熟品类仍可能有创新和细分机会。曲线不是产品注定走完的预测路径；阶段不自动证明利润率。

**衔接与校准**：PEST和竞争材料帮助解释变化，安索夫比较增长方向，组合方法讨论配置。营销生命周期与国际贸易中的产品周期理论不直接等同，原文历史归属不作为确定分析前提。参考[来源校准](../source-calibration.md)。
