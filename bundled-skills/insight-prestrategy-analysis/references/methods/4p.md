# 4P 营销组合

**作用与对象**：检查具体产品与目标选择所需的供给安排。适合诊断产品、定价、渠道和传播之间的不一致；单独列四项不构成完整战略。

**输入**：目标问题或人群假设，实际产品与服务，价格及交易条件，购买与交付路径，沟通内容，实施约束。比较竞品时明确版本、规格、地区和期间的差异与比较基准；必要时标准化或作条件比较，差异本身也可以是研究对象，不要求资料完全相同。

**操作**：
- Product：功能、质量、设计、包装、服务与凭证能回应什么需求，哪些只是计划。
- Price：标价、折扣、运费、订购门槛及支付条件如何影响总价与价值感；讨论盈利和实施可行性时结合相应成本与目标，资料缺失时仍可探索明示假设的价格情景。
- Place：在哪里能买到、实际覆盖、库存和履约怎样；用户看见内容不等于有货或能便利购买。
- Promotion：向谁沟通什么，以何种证据和触点表达；内容发布频次不代表实际投放额或到达效果。
- 检查四者怎样共同支持或削弱价值主张，比较改变某一项对其他项的影响。

**可交付**：供给事实、组合矛盾、调整备选及验证动作；也可只输出当前需要的一项诊断。

**边界与缺口**：公开价格不自动证明成本领先、利润或支付意愿。转化原因依据研究设计与证据强度判断，现场实验、行为观察或其他适当研究可各有作用，来源不限于后台，后台数据本身也不自动证明因果；支持不足时保留成因假设。缺实施资料时提供条件化选择，避免编预算。

**衔接**：与4C交叉检查用户的价值和总成本；由STP提供选择假设，由5A或适用行为数据检查实际反应。定义参考[来源校准](../source-calibration.md)。
