# STP 细分 选择 定位

**作用与对象**：把差异需求转为目标选择与定位假设。适合需要决定服务谁、回应什么价值的问题；未知下游用途时不自动执行到完整品牌战略。

**输入**：目标市场边界，需求或行为差异，现有替代方案，触达与服务条件，本品凭证及约束。规模、获客成本和支付意愿未知时保留未知。

**操作**：
1. Segmentation：按能影响需求、选择或回应的差异提出候选群体。任务、场景、行为、心理和人口变量按证据选用；每组内部相近、组间有实际差异。
2. Targeting：比较需求强度、可触达性、竞争、可服务性与经济条件。区分机会吸引力和证据充分程度，说明优先与放弃的条件。
3. Positioning：对所选人群与场景，明确竞争参照、价值改善和可信凭证。差异可以来自体验、供给与组合，不要求凭空创造新品类。
4. 用实际供给和竞争方案检查定位是否能兑现，写出最值得验证的假设。

**可交付**：人群差异、候选路线比较、优先选择或定位研究输入。研究任务也可只做到S或T。

**边界**：访谈标签不是已证实市场规模；同平台互动不能决定目标人群排序；外形不同不自动构成购买差异。定位陈述不是消费者已认可的事实。

**缺口与衔接**：证据不足时给候选细分及区分它们的研究。3C提供输入，4P/4C与VRIO检查兑现，PMF或行为研究检查实际反应。参考[来源校准](../source-calibration.md)。
