# 3C 顾客 竞争者 公司

**作用与对象**：把同一需求任务下的顾客、竞争方案和本品能力连接起来。适合机会诊断、定位依据或竞争问题；不替代市场规模、行业利润或心理动机的专项取证。

**触发与输入**：问题涉及“谁需要、别人怎样满足、我们凭什么回应”。需要具体使用情境、现有替代方案、本品产品与能力资料；材料不齐可形成研究问题。

**操作**：
1. Customer：识别谁在什么情境完成什么任务，当前如何解决，困难怎样影响选择。分开用户陈述、实际行为与研究者解释。
2. Competitor：纳入直接竞品、相邻方案、人工做法和暂不购买；用同一任务、价格和可获得性比较，不能只比较传播口号。
3. Company：列已兑现能力及证据、必要约束与待建设部分。公司愿望不计作现有优势。
4. 找到匹配、冲突及候选解释。机会可以是更好满足已有人群，不要求找到“无人竞争”的空白。

**可交付**：需求—替代方案—能力的对应、可讨论机会、矛盾与关键未知。按用途抽取原话、比较或定位输入，不强制三栏报告。

**判断边界**：公开竞品内容不等于完整经营实力；招募访谈不代表总体。三类材料中的同一来源不重复计证。

**缺口与衔接**：缺哪一C，就标出它怎样影响结论并选择最能区分解释的补证。人群选择可交STP，供给匹配可交4P/4C，能力优势可交VRIO，行业结构可交五力。见[关系说明](../method-relations.md)。
