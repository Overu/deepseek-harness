# BCG 增长与相对市场份额

**作用与对象**：比较业务或产品组合在相关市场中的增长与竞争位置，为资源讨论提供起点。行业热度、内容表现和本品销量增长不能直接替代两个坐标。

**运行条件**：对每个单元明确相关市场、地区、期间、销售额或销量口径；取得市场增长率、本品份额及最大竞争者份额，并说明高低分界的来源。不同市场可分别计算，但定义与统计方法要可比。

**操作**：
1. 市场增长率采用相关市场同口径时间序列，区别本品增长。
2. 相对市场份额 = 本品市场份额 ÷ 该市场最大竞争者份额。竞争者不包含本品自身；分母为零或未知时不计算，不虚构无穷值。
3. 使用明确阈值分象限：高增长高相对份额为明星；低增长高份额为金牛；高增长低份额为问题；低增长低份额为瘦狗/低份额成熟业务。相对份额1常用作分界，增长阈值按任务和行业说明，不把10%定为通则。
4. 讨论投资、维持、验证或退出备选，并核对现金流、资本需求、协同和退出成本。

**可交付**：坐标、分界、象限、敏感因素与条件化配置建议。

**缺口与边界**：任一轴无依据时，交付缺口和可推进的比较，保留未知象限。不能用互动率、品牌知名度或自评能力替代相对份额，也不因缺份额就自动换GE打分。象限不证明利润、现金流或必然退出。

**衔接**：生命周期提供阶段背景，VRIO和竞争分析核查潜力，GE在其自身指标有依据时提供另一视角。BCG定义见[来源校准](../source-calibration.md)。
