# PEST 外部环境

**作用与对象**：识别影响特定市场或组织决策的政治政策、经济、社会和技术变化。适合研究环境变化；不要求每类因素平均列举。

**输入条件**：明确地区、行业、对象和时间。使用有日期的原始统计、政策、技术资料或可核查研究。涉及现行法规或指标时查当前来源。

**操作**：
- Political：政策、监管、贸易、补贴和规则如何改变可进入性或经营条件。
- Economic：购买力、收入、融资、成本及价格环境如何影响供需。
- Social：生活方式、人口或任务场景的变化，是否有目标人群证据。
- Technological：技术性能、成本、普及和基础设施怎样改变供给或使用方式。

把相关变化写为“发生了什么→通过什么机制影响谁→可能出现什么机会或压力→还需什么证据”。区分已发生、预测及假设，比较时间尺度。

**可交付**：少量真正影响当前问题的变化、机制与研究方向。只需一项变化时直接回答，不为四栏补泛论。

**边界与缺口**：宏观增长、政策鼓励或某项技术流行，不直接证明目标用户需求、企业收益或本品优势。统计地区、期间或分类不匹配时不直接套用。

**衔接**：必要时检查变化怎样作用于五力结构、3C需求或供给。法律与环境因素可按任务扩展为PESTLE，并说明扩展，不声称PEST本来就是六维。参考[来源校准](../source-calibration.md)。
