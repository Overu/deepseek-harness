# 差距分析

**作用与对象**：围绕明确目标比较现状，识别障碍和行动依赖。适合产品、品牌、组织或执行改善；缺目标时先澄清希望改变的结果，不自动假定增长最大化。

**输入**：目标状态及理由、同口径现状、期限或约束、已有行动与能力。目标由用户给定或作为提案明确标注，不能将模型建议冒充已批准目标。

**操作**：
1. To be：写清结果、对象、时间和怎样观察，定性目标也需可识别的表现。
2. As is：用现有证据描述同一对象和口径；资料缺失不是表现为零。
3. Gap：区分结果差距、能力差距和证据缺口，避免把没有测量当成业务必然不足。
4. Cause：提出并比较可能成因，确认因果尚未识别时保留解释竞争。
5. Act：选择能缩小差距或减少关键未知的行动，说明依赖、责任、资源及检查方式，深度按任务决定。

**可交付**：差距、成因假设、优先行动与验证事项，也可只形成当前所需的诊断。

**边界与缺口**：两项指标增长并存不证明成因；表述“增加曝光”不能自动解释收入差距。没有预算、基线或投入效果时不编金额与达成率。

**衔接**：可承接任一模型中已形成的目标和实际依据；组织协调问题可用7S，产品与路径问题可用4P/4C、5A或AARRR。方法采用通用目标—现状—行动逻辑，不依赖单一历史提出者。
