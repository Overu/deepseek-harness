# GE 麦肯锡九宫格

**作用与对象**：以行业吸引力和业务竞争实力比较多业务组合的投入选择。适合配置讨论；不是缺少BCG数据时可随意自评分的替代品。

**输入与深度**：明确业务单元与相关市场，按任务选择定性比较或定量分析。定性判断说明材料依据或明示的判断理由；量化时采用可解释的尺度与计算规则，实际使用权重时再说明依据。资料不全仍可探索吸引力与能力议题，不以补齐权重作为讨论前提。跨业务比较说明定义和差异。

**操作**：
1. 行业吸引力可根据适用的规模、增长、结构利润、进入条件和风险等判断；避免重复计入高度重叠指标。
2. 竞争实力可根据相对能力、渠道、成本、用户价值、品牌与资源等判断；区分计划能力和实际表现。
3. 直接定性比较可以不打分、不设权重。合成分数时说明尺度、计算方式和缺失项；用到高/中/低分界或权重时解释依据，区分主观评分与测量，不补造精确总分。
4. 位置或排序可能受关键假设、权重或阈值左右时，按任务需要比较情景或检查稳健性；结论不稳定可保留区间与未知，不要求每次展开完整敏感性分析。
5. 提出增长、选择性投入、维持、收获或退出备选，并检查协同、财务和执行约束。

区分两条轴的证据含义：相关市场的需求与结构条件用于行业吸引力；本品供货经验、经销关系与服务经历用于竞争实力。局部合作或需求线索可以引出行业研究，但不自动成为行业整体吸引力的已知结论；资料不足时该轴可以保持未知。

**可交付**：比较依据、位置或区间、敏感因素与配置备选，不强制绘图。

**边界与缺口**：不能把主观评分当客观事实；位置不确定时不硬塞格子。高吸引力不保证本品成功；低吸引力中的强业务可能具有实际价值。

**衔接**：PEST/五力提供外部判断，3C/VRIO提供竞争依据，差距分析检查所需建设。基础定义见[来源校准](../source-calibration.md)。
