# VRIO 资源与能力

**作用与对象**：判断一项具体资源或能力在特定竞争环境中的优势潜力。适合“凭什么赢、优势能否维持”问题；不把公司整体贴成一个永久标签。

**输入**：资源或能力的边界、用户价值或成本贡献、相关竞争者比较、复制条件，以及组织能否使用并获得收益的资料。

**操作**：
- Value：它是否帮助回应机会、缓解威胁或更好创造价值，有什么实际依据。
- Rarity：在相关竞争集合中是否稀缺，比较范围和时点是什么。
- Inimitability：复制或替代需要的时间、成本、历史条件和组合依赖；“有专利”本身不充分。
- Organization：流程、激励、人员、治理和配套资产能否利用该资源并兑现价值。

按相关维度记录已有支持、关键未知与实际发现的反证。缺价值依据时不能仅凭独特宣称优势；有价值但普遍可能只是竞争必要条件；稀缺但易复制可能是暂时优势；组织未配合时识别兑现缺口。

**可交付**：优势依据、条件、时间范围与建设任务。四项证据不完整时，也可讨论有条件的持续优势潜力、补证和建设路径，区分已支持的能力、待验证的条件与需建设部分。认定已具备持续优势的依据时，检查四项是否获得相应支持；任何判断都不保证永久领先。

**缺口与衔接**：内部资料缺失时提出需核实的资源假设，不从公关稿推断组织能力。可向STP和竞争战略提供凭证；差距分析与7S处理建设任务。

**校准**：价值、稀缺、复制难度和组织条件各有作用；不把“1991年资源基础观”与VRIO具体版本简单等同。见[来源校准](../source-calibration.md)。
