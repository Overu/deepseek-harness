# 波特竞争战略

**作用与对象**：讨论一个业务单元以何种优势来源、在多大服务范围竞争。适合战略取舍与活动匹配；不把某条广告或单次低价认定为企业竞争战略。

**输入**：相关市场和客户选择、成本结构或成本驱动、用户重视的差异、竞争供给及实际经营活动。先明确是业务单元还是整个集团。

**操作**：
- 成本领先：核查是否在相关范围内有可持续的成本位置和支持活动；售价低只是价格事实。
- 差异化：核查用户重视的独特价值、可信依据和为此选择或付费的条件。
- 集中化：选择较窄的细分范围，再明确以成本优势或差异化服务该范围的逻辑。

比较候选路线所需的产品、采购、渠道、服务、人员与资源配合，指出相互冲突的要求和放弃项。必要时讨论组合可能，但需要活动之间一致，不能只声称“又便宜又高端”。

**可交付**：优势来源、服务范围、活动要求、路线取舍和待证实条件。

**边界与缺口**：没有成本数据时只能讨论成本驱动假设；高售价不自动代表差异化成功；有某项特色不等于用户重视或愿意支付。

**衔接**：五力提供行业压力，STP帮助界定服务范围，VRIO提供优势依据，4P/4C及7S检查兑现条件。参考[来源校准](../source-calibration.md)。
