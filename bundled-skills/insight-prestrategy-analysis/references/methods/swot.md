# SWOT 内外部发现综合

**作用与对象**：把关于明确对象的已有发现整理成可讨论的战略含义。适合综合与核对；SWOT自身不产生新事实，也不要求每次研究都用它收尾。

**输入**：产品或组织的内部证据、外部环境与需求证据、比较对象和研究目标。信息少时先辨识问题，四栏不必等长。

**操作**：
- Strengths：相对有关竞争方案、能帮助当前目标的内部优势及凭证。
- Weaknesses：内部不足、约束和其影响。
- Opportunities：外部变化或需求条件，说明本品何以可能回应。
- Threats：外部压力及它影响目标的机制。

给关键条目附来源和范围；区分事实、解释和假设。把有意义的组合转为备选动作：用什么优势回应什么机会，补什么弱点才能进入，哪些威胁要求防守或改变范围。

**可交付**：优先问题、相互关系、候选选择和验证重点，而不只是四串形容词。

**边界**：消费者需要某物不是公司优势；计划上线不是已具备资源；同一事实可有双重含义但不能重复计证。模型对同一材料的多次整理不能算独立支持。

**缺口与衔接**：发现无依据的优势、机会或威胁时回到相应来源，必要时用3C、PEST、五力或VRIO补证。形成目标后可交差距分析。历史归属不作为本卡的必要输入，见[来源校准](../source-calibration.md)。
