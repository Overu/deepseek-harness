# 波特五力

**作用与对象**：分析行业结构及经济价值如何在参与者之间分配。适合进入判断、行业吸引力、议价或盈利压力研究；竞品账号排名不等于行业五力分析。

**输入条件**：先界定相关产品或服务、地区、价值链层级和期间。需要现有竞争、进入壁垒、替代方案、购买者与供应商资料；本品与行业的层级分开。

**操作**：
1. 现有竞争：供给集中度、增长、差异化、固定成本、退出壁垒及竞争方式。
2. 新进入威胁：资本、规模、渠道、转换成本、品牌与规则等进入条件。
3. 替代威胁：用不同方式完成相同任务的方案，其价格—性能和转换条件。
4. 购买者议价：集中度、采购占比、差异性、信息和可转换性。
5. 供应商议价：关键投入集中度、不可替代性、转换与整合可能。

对每项重要力量说明“结构事实→影响价格、成本或所需投入的机制→本次问题的含义”。只讨论相关力量，缺少依据时不填高低分数。

**可交付**：主要压力来源、作用机制、相对有利位置和需要核查的结构假设。

**边界**：行业吸引力不直接决定本品胜率；成本领先不等于卖得便宜。相邻行业参与者和替代品的边界应说明。

**缺口与衔接**：公开材料不足时做机制假设，补行业与交易资料。PEST提供可能改变结构的事件，VRIO与竞争战略检查本品应对能力，GE可消费行业吸引力判断。参考[来源校准](../source-calibration.md)。
