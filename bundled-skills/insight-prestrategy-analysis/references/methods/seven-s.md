# 麦肯锡7S

**作用与对象**：分析组织要素之间能否共同支持某项变化。适合能力兑现、跨部门协作或战略实施研究；组织图与公关材料不足以完成组织诊断。

**输入**：要实现的任务、实际流程与决策、岗位与资源、激励、人员和行为证据。涉及内部资料时遵守当前可访问范围，未知不推定为缺陷。

**操作维度**：Strategy战略，Structure结构，Systems系统与流程，Shared values共同价值观，Skills技能，Style领导与管理风格，Staff人员。

围绕当前任务检查要素间的连接：战略要求何种协作，结构与流程是否支持，技能与人员是否匹配，激励和实际管理行为是否鼓励所需行动，价值观是否在取舍中体现。按问题选择相关要素，不要求逐栏泛评。

**可交付**：协调障碍、依赖关系、待核实的解释和建设任务；行动可结合责任与验证方式组织。

**边界与缺口**：不能从员工数量或组织口号推断能力；不把个别人的意见直接升级为整体文化。对内部事实不足时提出访谈、流程观察或记录核查需求，不给组织贴人格标签。

**衔接**：VRIO检查能力优势是否有组织支持，差距分析将障碍转成优先行动，4P等提供承诺兑现的具体任务。7S强调协调与相互作用，参考[来源校准](../source-calibration.md)。
