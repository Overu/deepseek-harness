# 安索夫 产品与市场增长方向

**作用与对象**：比较增长方向需要改变什么产品和市场。适合增长选项与前置条件研究；矩阵位置不自动给出风险概率或投入回报。

**输入**：以当前业务为基准定义“现有产品”“现有市场”，增长目标、目标用户/地区/渠道及供给变化、资源和约束。新旧的判断相对于明确基准，不凭项目名称。

**操作**：
- 市场渗透：现有产品在现有市场增加使用、覆盖或选择，核查仍有何空间。
- 市场开发：现有产品进入新的目标市场，核查需求迁移、触达和服务条件。
- 产品开发：为现有市场引入新产品或实质供给，核查需求、能力和替代关系。
- 多元化：产品与市场均发生实质变化，列出两侧未知及可复用能力。

对有关方向比较价值来源、所需改变、凭证、资源依赖、可能互相蚕食及最关键未知。进入新渠道是否构成新市场，取决于用户、使用任务与商业条件是否变化。

**可交付**：增长方向、路线比较、分阶段学习与条件，不强行提出四条同等成熟的方案。

**边界与缺口**：新市场不能直接沿用旧人群需求和支付意愿；“多元化通常更不确定”不是固定失败率。缺规模或经济数据时做条件分析，不编收益预测。

**衔接**：3C/STP检查新方向的需求和竞争，VRIO检查可迁移能力，PMF检查新组合实际接受情况，组合方法另行讨论资源。基础来源见[来源校准](../source-calibration.md)。
