# 5A 消费者决策路径

**作用与对象**：理解消费者从知道品牌到产生吸引、询问、行动和拥护的经历。适合沟通、内容、购买路径或体验研究；不是完整界面可用性评估。

**输入**：目标人群与任务、触点材料、认知研究、询问与比较行为、适用的购买/使用和推荐证据。先区分消费者意图、实际行动与研究推断。

**操作**：
- Aware认知：怎样接触或记起品牌，曝光不等于实际知晓。
- Appeal吸引：什么使品牌进入考虑，互动不自动代表购买吸引力。
- Ask询问：查什么、向谁问、比较什么，疑问如何被解决。
- Act行动：发生什么购买、试用或使用，任务定义以实际业务为准。
- Advocate拥护：怎样主动推荐或支持品牌，不能只用点赞代替。

连接触点、用户问题、证据和阻碍；考虑回访、跳过、他人影响及不同路径。缺少同口径人群与行为数据时，输出路径假设而非转化漏斗。

**可交付**：决策障碍、内容或服务研究输入、触点问题与验证动作，按任务选择相关阶段。

**边界与缺口**：用户不一定依次经过五阶段；未购买者也可能表达支持。某环节下降不能单独说明成因，先比较价格、信任、渠道和流量等解释。

**衔接**：与4C/4P检查可改变的供给，与Aaker检查认知资产，与AARRR共享适用行为定义但不逐阶段一一替换。5A定义参考《Marketing 4.0》出版资料，见[来源校准](../source-calibration.md)。
