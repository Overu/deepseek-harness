# 方法之间怎样协作

箭头表示可能的信息依赖或检查关系，不表示模型输出自动构成因果证明，也不表示每次必须走完整条链。

## 常见连接及交接条件

|连接|可以传递什么|分析时留意什么|
|PEST → 五力/3C|某项外部变化及潜在影响机制|变化确实影响目标市场；宏观变化不直接证明本品机会|
|五力 → 竞争战略/GE|行业壁垒、议价和竞争结构判断|行业边界一致；本品能否应对还需内部能力证据|
|3C → STP|差异需求、竞争参照、能力与缺口|区分需求分群与想象画像；细分的规模和可达性仍可能未知|
|STP ↔ 4P/4C|目标人群、价值主张与供给约束|定位承诺是否被产品、价格、渠道、沟通和用户总成本支持|
|VRIO → 定位/竞争战略|已验证优势、复制难度和组织短板|比较对象、时间和优势范围明确；计划能力不是当前凭证|
|品牌棱镜/黄金圈 ↔ Aaker|希望建立的意义与实际感知差距|品牌意图、消费者反馈、实际行为分别记录|
|4P/4C ↔ 5A/AARRR|供给或体验阻碍假设、行为观察|阶段、事件、分母可比；下降不自动证明某种原因|
|PMF ↔ STP/4P|哪个客群、场景和版本获得何种使用支持|不能用定位文案或功能清单替代持续使用和购买依据|
|生命周期 ↔ 安索夫/组合分析|阶段假设、增长方向与时机|品牌、单品、产品形态和品类的层级不混用|
|BCG/GE → 资源讨论|组合位置、敏感因素和配置备选|仍需现金流、协同、投入和退出成本；不自动下投资决定|
|SWOT → 选择/差距分析|可追溯的内外部发现和优先问题|SWOT不新增证据；优势相对谁、机会依赖什么条件|
|差距分析 ↔ 7S|能力或组织缺口、行动依赖|目标可验证；成因假设与实际障碍能区分|

## 识别三类冲突

1. **范围冲突**：不同地区、用户、版本、时间或指标造成表面矛盾。先恢复各自范围，再判断能否比较。
2. **解释冲突**：同一行为可能由价格、信任、便利、流量结构等不同机制产生。选择能区分解释的新证据。
3. **真实取舍**：便利与成本、覆盖与服务深度、专业定位与广泛人群等同时受约束。保留取舍，比较路线的成立条件。

同一条材料经过多个模型整理，不因此增加独立来源。区分信息增量与来源独立性：同源新增数据、方法细节、有效复核或揭示新结构的分析，可能增强、削弱或澄清某项判断；重复转述不新增支持。不同模型得到一致表述，也不能单凭一致性当作独立验证。

## 按问题回溯

对关键判断保留来源与前提的关联即可，不要求建图数据库。价格、产品或人群变化时，重新检查受影响的判断及下游建议；仍适用的来源可以复用。重新解释不代表重新采集，已有解释也不因曾获认可而永久有效。

下一项研究可以用于改变解释或选择，也可以用于理解问题、扩大覆盖、发现盲点或检查稳健性。根据当前研究目标、信息增量、用户要求的深度及时间和预算安排取舍；无效重复或与目标无关的栏目可收敛，不把“改变当前决定”作为所有探索的准入条件。
