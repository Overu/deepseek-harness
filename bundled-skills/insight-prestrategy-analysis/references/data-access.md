# 数据来源与可选衔接

## 根据问题选择来源

用户资料适合产品事实、约束、历史研究与经营记录；官网和原始公告适合核对公开主张；行业统计适合明确口径的市场问题；访谈、调查、观察和行为数据适合不同程度的需求验证；平台内容适合公开叙事、情境、疑问与讨论线索。这些是常见用途，实际根据证据内容、研究设计、口径和适用范围判断，允许不同来源互证、补充或在满足同一要求时替代。载体不同不代表研究独立，同一研究的报告和导出不重复计证；相关性信号仍不能冒充所需的实际指标。

先遵守用户对材料、联网、平台、时间和预算的要求。只分析已有文件的任务不启动补采。需要最新事实且允许联网时查询原始来源，记录日期；历史材料仍可在其历史范围内使用。

## 复用取数能力

按当前环境发现可用工具与技能，不依赖某台机器的绝对目录或固定工具名称。优先使用 DSH 已配置的文件、搜索、网页读取及只读连接器，读取其实际定义和接口合同，不臆造端点、参数或权限。需要 TikHub 数据时使用宿主已授权的 `tikhub` 企业网关连接；不新建供应商直连，不要求用户提供 API Key 或额外安装运行环境。

若已安装 `category-competitor-insight`，可复用其 `references/tikhub-endpoints.json`、`references/platform-routing.md` 中的取数合同、平台可比性及净化规则。只有宿主具备其脚本所需运行环境、且确需该入口时，才按其实际帮助使用已适配企业网关的 `scripts/tikhub_readonly.py`；这不是本技能研究分析的前置条件。选用前检查当前可用性和计价依据，不复制硬编码的路由和历史失效状态进本技能。整份六章业务报告不是复用取数的前置条件。

同任务内复用缓存、查询与费用台账。预算包含探测、失败及可能计费的不确定请求，跨平台和下游不重置。采用现有明确授权；下一请求预计超限时说明已有支出、追加用途和新总额，用户明确同意后沿用原任务继续。本技能不额外引入逐次联网查价步骤；优先复用接入能力的可用价格表与任务计价记录，并遵守所选接口已有的计价合同。不假设未知价格为免费，无法确定计价或授权时说明该入口缺口，继续不依赖它的分析。

此技能不保存、索取或读取厂商密钥、Cookie或用户登录状态，不要求用户把凭证放进研究成果，也不从本地配置或进程环境提取供应商凭据。企业插件携带当前登录态，后台管理供应商鉴权；只使用工具返回的已净化业务数据。不得为补足研究自动购买权限、充值、发消息或改变第三方状态。

## 接口结果与失败

分别记录路由可用性与本次业务返回；HTTP成功不保证字段可用。重试要有明确依据和有限次数，计入同一预算，不绕过合同拼接未验证端点。

实际执行搜索、主页和相关作品等任务要求的可用只读接口后，才能声称完成相应账号核验。没有执行、请求失败、有效空结果和身份未确认分别说明。登录或安全验证需要用户处理时停止该入口，继续可独立完成的分析。

可用入口不具备所需能力时，使用已有资料、其他已授权来源或提出补证要求。不得用公开内容热度补造销量、ROI、真实转化、全量情绪或市场份额。资料是否足以支持结论见[研究与证据](research-and-evidence.md)。
