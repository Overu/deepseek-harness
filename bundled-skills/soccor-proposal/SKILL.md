# SOCcoR 提案技能

**技能名称：** SOCcoR 提案策划  
**版本：** v2.0  
**创建时间：** 2026-04-17  
**更新时间：** 2026-04-17（基于专家意见升级）  
**定位：** 基于 SOCcoR+TTI 框架的品牌策略与传播规划技能

---

## 🎯 技能概述

**SOCcoR+TTI** 是一套完整的品牌策略与传播规划框架，结合 **TJS 提案表达技巧**，帮助在有限时间内清晰、有说服力地传递方案，核心是抓注意力、讲价值、促行动。

**专家意见整合（v2.0 升级要点）：**
1. ✅ 每个板块按 TJS 模式归纳整理（T=观点，J=支持点≤5 个，S=小结）
2. ✅ UBO 三角梳理图（产品功能→功能价值→独特利益 UBO）
3. ✅ 消费者洞察公式（我希望...但...；我想...但也想...）
4. ✅ 品牌核心价值主张 = UBO + INSIGHT
5. ✅ 品牌屋整合（UBO+ 洞察 + 价值主张 + 调性）
6. ✅ 创意概念智能化生成（方法化产出供选择）

### 框架结构

| 字母 | 含义 | 英文 | 核心任务 |
|------|------|------|----------|
| **S** | 形势 | Situation | 分析当前市场/品牌现状 |
| **O** | 机会/障碍 | Opportunities/Obstacles | 识别机会点和问题 |
| **C** | 挑战 | Challenge | 明确核心挑战 |
| **c** | 创造性解决方案 | creativity | 创意策略 |
| **o** | 解决方案评估 | evaluation | 方案评估 |
| **R** | 推荐方案/计划 | Recommendation | 最终推荐方案 |

### TJS 提案表达技巧

| 阶段 | 含义 | 核心目标 | 关键动作 |
|------|------|----------|----------|
| **Tell It** | 讲清 | 让听众理解方案 | 清晰陈述、逻辑连贯、数据支撑 |
| **Jell It** | 讲透 | 让听众认同方案 | 深度阐释、情感共鸣、价值连接 |
| **Sell It** | 讲服 | 让听众行动方案 | 行动号召、利益明确、风险可控 |

## 🔍 框架详解

### 准备工作

**必做事项：**
- ✅ 客户访谈（了解品牌历史、过往传播、核心优势）
- ✅ 需求简报分析解读（明确目标、预算、时间、KPI）
- ✅ 内部资料收集（产品资料、品牌资料、过往案例）

---

### 品牌目标（或传播目标）

**双轨制目标设定：**

| 目标类型 | 时间维度 | 核心聚焦 | 示例 |
|----------|----------|----------|------|
| **长期目标** | 展望未来 1-3 年 | 品牌占位和品牌地位打造 | "成为 Z 世代首选的功能性饮料品牌" |
| **短期目标** | 短时间内（如季度/年度） | 营销和市场目的 | "Q3 实现销量增长 30%，品牌认知度提升 15%" |

**输出格式：**
```markdown
## 🎯 品牌目标

**长期目标：** [品牌占位和地位描述]

**短期目标：** [具体营销和市场目标，可量化]
```

### S - Situation 形势分析

**目的：** 让听众快速理解当前局面，建立共识基础（没有争议的观点，客户肯定点头的）

**必含内容（5 个 TJS 观点）：**
1. **行业的现状与发展趋势**（TJS 观点 + 支持点≤5 个）
2. **品类的市场现状和趋势**（TJS 观点 + 支持点≤5 个）
3. **品牌的核心优势**（TJS 观点 + 支持点≤5 个）
4. **产品的核心优势**（TJS 观点 + 支持点≤5 个）
5. **过往传播积累的优势**（TJS 观点 + 支持点≤5 个）

**TJS 表达模式（每个观点）：**
- **T（Tell）：** 清晰陈述观点
- **J（Jell）：** 支持点不超过 5 个（数据、案例、事实）
- **S（Sell）：** 观点小结（一句话总结）

**🔴 强制要求：必须调用 DSH 官方联网检索工具 `web_search` 检索真实数据，禁止凭记忆估算！**

**`web_search` 检索目标：**
```bash
2025 2026 中国 [品类] 市场规模 增长率 行业趋势
```
（用 DSH 的 `web_search` 工具执行，返回真实报告并附带可点击引用 URL，无需外部 API Key。）

**输出格式：**
```markdown

**观点（T）：** [一句话观点]
```

### O - Opportunities/Obstacles 障碍与机会分析

**目的：** 识别关键障碍和机会，为挑战定义铺垫

**必含内容（5 个 TJS 观点）：**
1. **障碍一：市场层面 - 认知的障碍**（TJS 观点 + 支持点≤5 个）
2. **障碍二：竞争层面 - 竞争品牌逐个分析**（TJS 观点 + 支持点≤5 个）
3. **机会一：竞争机会占位图**（十字定位图）
4. **机会二：外在的可利用的机会**（营销节点机会、社会热点机会等）
5. **小结：关键障碍和机会**（TJS 总结）

### R - Recommendation 因赛的解决之道

**目的：** 给出完整的品牌策略与传播规划方案

**必含内容（5 步完整流程）：**
1. **清晰定义品牌和产品的核心价值承诺 (UBO)** - 剥洋葱法三角梳理图
2. **发掘目标消费者的需求和关键洞察 (INSIGHT)** - 四步推导法
3. **提炼品牌核心价值主张** - UBO + INSIGHT = 品牌核心价值主张
4. **构建品牌价值体系 (品牌屋)** - 品牌调性 + 品牌屋 + 品牌形象体系
5. **全方位整合营销传播推广** - 创意概念 + 创意表现 + 传播策略 + 媒介计划

---

#### 1️⃣ 清晰定义品牌和产品的核心价值承诺 (UBO)

**剥洋葱法（三角梳理图）：**
```
         第三层：品牌/产品的独特利益 UBO（一句话）
                /\
              /    \
            /        \
          /            \
        /________________\
       第二层：基于特点提炼的功能价值
      /    /    /    /    /    /
     /____/____/____/____/____/____
    第一层：产品功能特点 1/2/3/4/5/6...
```

**输出格式：**
```markdown
### 1️⃣ 品牌和产品的核心价值承诺 (UBO)

**产品功能特点：**
1. [功能特点 1]
2. [功能特点 2]
3. [功能特点 3]
...

**基于特点提炼的功能价值：**
1. [功能价值 1] ← 对应功能特点 1
2. [功能价值 2] ← 对应功能特点 2
3. [功能价值 3] ← 对应功能特点 3
...

**品牌/产品的独特利益 UBO（一句话）：**
[一句话 UBO]
```

---

#### 2️⃣ 发掘目标消费者的需求和关键洞察 (INSIGHT)

**四步推导法：**
```
基础画像 → 消费需求 → 矛盾与冲突 → 关键洞察
```

**关键洞察公式（专家指定格式）：**
- "我希望......... 但............"
- "我想............ 但也想............"

**输出格式：**
```markdown
### 2️⃣ 目标消费者的需求和关键洞察 (INSIGHT)

**基础画像：**
- 年龄：...
- 性别：...
- 地域：...
- 身份：...
- 兴趣：...

**消费需求：**
- [需求 1]
- [需求 2]
- [需求 3]

**矛盾与冲突（心理矛盾产生的需求）：**
- [矛盾 1：如"想要健康但不想放弃美食"]
- [矛盾 2：如"想要个性但害怕被孤立"]

**关键洞察（一句话，使用指定格式）：**
> "我希望 [渴望]，但 [障碍]"
> 或
> "我想 [想要 A]，但也想 [想要 B]"

**示例：**
> "我希望在职场中展现专业形象，但又不想失去真实的自己"
> "我想追求事业成功，但也想有更多时间陪伴家人"
```

```markdown
- **小结（S）：** 一句话总结主张的价值
```
