# 前策分析报告输出规范

## 报告定位

用户可见报告是一份前策判断，不是研究过程记录。正文直接给出观点、可传播的表达和支撑判断的业务事实。内部采集方法、接口、路由、证据编号、分页过程、样本限制、数据限制与下游交接对象保留在内部结构化文件，不进入正文。

报告只保留以下六个一级章节，顺序和标题固定。前五部分依次使用 `核心观点`、`金句`、`支持点` 三个二级标题；第六部分直接展示数据汇总与参考资料，不使用这三个小标题。不要增加摘要、方法、附录或交接包。

## 一、品类判断

- **核心观点**：用 1–2 句话判断品类处于什么变化中、消费者价值如何迁移、品牌应如何理解这个市场。
- **金句**：一句可直接用于内部提案的凝练表达。金句必须是策略判断，不是数据复述。
- **支持点**：2–4 条最能支撑观点的市场、场景与需求事实。只写与决策相关的发现。

## 二、竞品格局

- **核心观点**：判断竞争围绕什么展开、哪些心智已拥挤、哪里仍有空位。
- **金句**：一句概括竞争格局或空位的策略表达。
- **支持点**：按品牌或产品分别使用三级标题，每个对象固定写三项：
  - `形象占位`：它希望在消费者心中代表什么；
  - `主打卖点/功能`：它持续强调的产品价值；
  - `传播概念/活动`：它用什么内容概念、传播主题或活动放大卖点。

不要按平台罗列竞品帖子，也不要堆砌互动数字。比较的落点是“各自占了什么、还缺什么”。

## 三、本品现状

- **核心观点**：判断本品当前的认知资产、表达优势与关键短板。
- **金句**：一句说清“本品凭什么被相信、为什么被选择”或二者之间的缺口。
- **支持点**：围绕已有形象、产品卖点、传播表达与用户反馈给出 2–4 条事实支撑。避免把品牌介绍改写成结论。

## 四、用户声音

- **核心观点**：归纳声量较大且对策略有启发的共同诉求、矛盾或判断标准。
- **金句**：将用户的共同张力提炼成一句策略语言，但不要冒充用户原话。
- **支持点**：优先选择高频主题中表达完整、诉求清晰的原话。每条固定为 `**人群标签**：“用户原话”`，至少覆盖两个不同人群；默认选择 3–5 条。人群标签来自表达中的场景或需求特征，不推断无法验证的人口属性。

用户原话保持原意，只做必要的错别字修正和隐私脱敏；不得将多条评论拼成一句虚构引语。

## 五、机会点

- **核心观点**：给出品牌最值得进入的机会方向，以及为什么现在可以进入。
- **金句**：一句可用作战略主张、传播母题或机会定义的表达。
- **支持点**：2–4 条说明机会对应的人群、场景、竞争空位、产品支撑与建议动作。机会必须能回扣前四部分，不新增无来源判断。

## 六、数据说明

一级标题下使用一个连续的项目列表，不写“核心观点”“金句”“支持点”。前几项按数据来源类型分别汇总，格式为 `- 数据来源：N 组关键词、N 条资料类型`；资料类型使用实际口径，如“公开资料”“帖子与评论”“视频及评论”。其后写 `- 数据时间：YYYY-MM-DD ～ YYYY-MM-DD`。

最后一项固定为 `- 主要参考资料`，并在其下使用二级项目列表列出少量与正文判断直接相关的链接，格式为 `  - [**资料标题**](公开链接)`。只附稳定、可访问的页面，不罗列完整检索清单。

示例：

```markdown
# 六、数据说明

- 行业媒体与研究报告：24 组关键词、23 条公开资料
- 公开社区与电商讨论：20 组关键词、13 条帖子与 228 条评论
- 数据时间：2024-04-20 ～ 2026-09-22
- 主要参考资料
  - [**“一瓶水卖上百元”，理肤泉陷“智商税”争议背后，市场地位面临挑战**](https://ctdsb.net/c1666_202509/2527712.html)
  - [**国货品牌颐莲的保湿喷雾卖得比雅漾还好**](https://m.jiemian.com/article/12347016.html)
```

## 表达要求

- 使用前策、品牌策略和消费者洞察语言；观点先行，支持点只保留能改变判断的内容。
- 前五部分中，核心观点回答“这意味着什么”，金句回答“如何一句话记住”，支持点回答“为什么这样判断”。三者不重复改写同一句话。
- 不在正文呈现接口、路由、证据 ID、检索词明细、分页、样本量、置信度、限制清单或下游交接对象。第六部分仅呈现直接汇总和少量代表性公开链接。
- 证据不足以形成判断时，不生成强结论；内部继续补数或将该观点从报告中删除，不用技术说明填充篇幅。

交付前运行：

```bash
python3 scripts/validate_business_report.py --input <报告.md>
```
