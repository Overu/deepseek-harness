## 🎯 更新目标

根据用户需求，优化案例检索技能的智能程度，使其能够根据用户意图自动切换输出模式：

1. **"查询/检索"意图** → 简洁模式，直接展示案例详情
2. **"推荐/分析"意图** → 深度模式，包含洞察总结 + 创意建议

---

## ✅ 完成的工作

### 1. 智能意图识别系统

**新增意图识别算法：**
- 支持 8 个查询意图触发词：查询、检索、查找、搜索、找、给我看、列出、展示
- 支持 10 个分析意图触发词：推荐、分析、解读、洞察、总结、借鉴、趋势、怎么写、有什么、有哪些
- 优先级：分析意图 > 查询意图 > 默认（查询）
- 测试覆盖率：15 个测试用例，100% 通过

### 2. 双模式输出规范

#### 模式 A：简洁查询模式

**适用场景：** 用户明确要"查询"、"检索"、"查找"案例

**输出规则：**
- 直接展示案例详情，无需洞察总结报告
- 检索结果 > 10 条 → 展示前 10 条
- 检索结果 ≤ 10 条 → 展示全部
- 每个案例包含完整字段表：
  - 品牌、产品、创意概念、核心卖点、目标人群
  - **消费者洞察（必填！）**
  - 人性需求、创意手法、案例类型
  - 素材链接（可点击文字标签）
- **禁止输出：** 洞察总结、创意手法分布表、创意借鉴建议

**输出模板：**
```markdown
## 🔍 [关键词] 案例检索结果

**总计：** X 条 | **展示：** Y 条

---

### 📹 案例 1：案例名称

| 字段 | 详情 |
|------|------|
| **品牌** | 品牌名 |
| **产品** | 产品名 |
| **创意概念** | 创意概念文字 |
| **核心卖点** | 卖点描述 |
| **目标人群** | 人群描述 |
| **消费者洞察** | 洞察文字（必填！） |
| **人性需求** | 需求类型 |
| **创意手法** | 手法列表 |
| **案例类型** | IMAGE/VIDEO/MIX |
| **📎 素材链接** | [📹 观看完整视频](URL) |

---
```

---

#### 模式 B：深度分析模式

**适用场景：** 用户请求"推荐"、"分析"、"解读"、"总结"、"借鉴"

**输出规则：**
- 完整报告格式：洞察总结 + 典型案例 + 创意建议
- 检索结果 > 5 条 → 展示前 5 条典型案例
- 检索结果 ≤ 5 条 → 展示全部
- **洞察统计基数：全部检索结果**（先获取完整列表用于统计分析）

**输出结构：**
1. 报告标题（含检索条件 + 总计案例数）
2. 案例洞察总结（前置）
   - 创意手法分布表
   - 人性需求分布表
   - 常见创意概念模式表
   - 核心消费者洞察
3. 典型案例详情（后置）
4. 创意借鉴建议（可选）

---

### 3. 数据真实性规范（新增）

**核心原则：** 所有输出必须基于 API 真实返回数据

**禁止事项：**
- ❌ 禁止自行拓展标签内容、素材地址、案例字段
- ❌ 禁止编造 API 未返回的奖项、标签、链接等信息
- ❌ 禁止直接暴露原始 URL 地址

**字段缺失处理：**
- 如 API 未返回某字段（如无奖项），直接省略该字段
- 不显示"暂无"、"无"等占位文字

**素材链接规范：**
- 必须使用可点击文字标签格式：`[📹 观看完整视频](URL)`
- 视频用📹图标，图片用🖼️图标
- 多个素材必须完整展示所有链接，不可省略

---

### 4. 消费者洞察字段规范

**重要性：** 消费者洞察是理解案例创意逻辑的核心

**规范：**
- ✅ **必填字段**，不可省略
- 来源：API 返回的 `insight` 字段
- 如 API 未返回，需通过 `parseCase` 接口获取
- 极端情况下可标注"暂无洞察数据"

## ⚠️ 注意事项

1. **意图识别优先级：** 分析意图关键词优先匹配（因为更具体）
2. **默认模式：** 无法识别时默认使用简洁查询模式
3. **展示数量：** 简洁模式最多 10 条，深度模式最多 5 条典型案例
4. **数据真实性：** 所有输出必须基于 API 真实返回，禁止编造
5. **消费者洞察：** 必填字段，不可省略
6. **素材链接：** 必须使用可点击文字标签，禁止直接暴露 URL
