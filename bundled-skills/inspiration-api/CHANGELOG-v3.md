# Inspiration API 技能更新日志

## v3.0 (2026-03-16) - 智能意图识别

### 🎯 核心变更

新增**智能意图识别**功能，根据用户请求的措辞自动切换输出模式，提供更精准的服务。

---

### ✨ 新增功能

#### 1. 双模式输出

**模式 A：简洁查询模式**
- **触发词：** "查询"、"检索"、"查找"、"搜索"、"找"、"给我看"、"列出"、"展示"
- **输出规则：**
  - 直接展示案例详情，无需洞察总结报告
  - 检索结果 > 10 条 → 展示前 10 条案例详情
  - 检索结果 ≤ 10 条 → 展示全部案例详情
  - 每个案例包含完整字段（品牌、产品、创意概念、消费者洞察等）
  - **禁止输出：** 洞察总结、创意手法分布表、创意借鉴建议

**模式 B：深度分析模式**
- **触发词：** "推荐"、"分析"、"解读"、"洞察"、"总结"、"借鉴"、"趋势"、"怎么写"、"有什么"、"有哪些"
- **输出规则：**
  - 完整报告格式：洞察总结 + 典型案例 + 创意建议
  - 检索结果 > 5 条 → 展示前 5 条典型案例详情
  - 检索结果 ≤ 5 条 → 展示全部案例详情
  - 洞察统计基于全部检索结果（而非仅典型案例）

#### 2. 意图识别算法

```javascript
function detectIntent(userInput) {
  const queryKeywords = ['查询', '检索', '查找', '搜索', '找', '给我看', '列出', '展示'];
  const analysisKeywords = ['推荐', '分析', '解读', '洞察', '总结', '借鉴', '趋势', '怎么写', '有什么', '有哪些'];
  
  // 优先匹配分析意图（更具体）
  for (const keyword of analysisKeywords) {
    if (input.includes(keyword)) return 'analysis';
  }
  
  // 其次匹配查询意图
  for (const keyword of queryKeywords) {
    if (input.includes(keyword)) return 'query';
  }
  
  // 默认返回简洁查询模式
  return 'query';
}
```

**测试覆盖率：** 15 个测试用例，100% 通过率

### 📋 规范更新

#### 1. 素材链接展示规则

- **单个素材** → 展示 1 个链接
- **多个素材** → **必须完整展示所有素材链接**，不可省略
- **格式：** `[📹 观看完整视频](URL)` 或 `[🖼️ 查看图片素材](URL)`
- **图标：** 视频用📹，图片用🖼️
- **禁止：** 直接暴露原始 URL 地址

#### 2. 数据真实性规范（新增）

- **所有数据必须基于 API 真实返回**
- **禁止自行拓展：** 标签内容、素材地址、案例字段等必须严格使用 API 返回数据
- **禁止无中生有：** 不得编造 API 未返回的奖项、标签、链接等信息
- **字段缺失处理：** 如 API 未返回某字段，直接省略该字段，不显示"暂无"等占位文字

#### 3. 消费者洞察字段规范

- **消费者洞察（insight）是必填字段**，不可省略
- 这是理解案例创意逻辑的核心
- 如 API 未返回该字段，需通过 parseCase 接口获取或标注"暂无洞察数据"

### 📝 注意事项

1. **意图识别优先级：** 分析意图关键词优先匹配（因为更具体）
2. **默认模式：** 无法识别时默认使用简洁查询模式
3. **展示数量：** 简洁模式最多 10 条，深度模式最多 5 条典型案例
4. **数据真实性：** 所有输出必须基于 API 真实返回，禁止编造
