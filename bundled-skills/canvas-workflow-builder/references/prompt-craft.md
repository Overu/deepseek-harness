# 图像 / 视频节点提示词工程

这份文档解决「生成节点的 prompt 到底写什么」：素材怎么指代、主体怎么锁、画面怎么描述、不许出现什么、图/视频模板怎么套。**只讲怎么写**；写完之后跑不跑得动、参数合不合法，看 `references/models-and-params.md`。

> 实测口径：81 条模板、208 个「有入边的生成节点」→ 去掉空 prompt 后 **128 条图提示词 + 46 条视频提示词**。
> 长度：图 **中位 55 字**（10–905），视频 **中位 482 字**（26–2562）。这是两类完全不同的文体，不要写成一种。

高频词统计（出现**次数**，按节点类型分列；图/视频两列为 128/46 条提示词的子集，全量列为 208 条非空生成节点提示词）：

| 词 | 图（128 条） | 视频（46 条） | 全量（208 条） |
|---|---|---|---|
| 保持 | 88 | 70 | 168 |
| 图1 | 94 | 35 | 146 |
| 参考图 | 46 | 28 | 95 |
| 不变 | 54 | 3 | 60 |
| 细节 | 51 | 43 | 112 |
| 背景 | 37 | 50 | 116 |
| 镜头 | 8 | 219 | 260 |
| 不要 | 67 | 51 | 140 |
| 禁止 | 10 | 26 | 45 |

一句话结论：**图提示词是「一句锁定 + 一句变化」的短指令**（`保持…不变` + `生成…画面`）；**视频提示词是一篇带时间轴的分镜脚本**（`镜头` 在视频侧出现 219 次，图侧只有 8 次）。

## 1. 素材引用语法：两代写法

| 写法 | 语义 | 实测分布 | 怎么用 |
|---|---|---|---|
| `图N` / `图1` | 第 N 路**图片**入边（1-based，按 `canvas_edges` 里 `image_source` 入边的顺序） | 图提示词 94 次命中 `图1`；视频 35 次 | **图片侧默认用这个** |
| `参考图N` | 同上，措辞更明确 | 图 46 次、视频 28 次 | 与 `图N` 可换用，同一模板内保持一致即可 |
| `{{@图片N}}` | 画布原生变量语法，显式指向第 N 路图片入边 | **仅视频侧 32 次**，分布在 `tpl_99/120/121/123/124/126/128/129/130/133/134`（id 120–137 这一代）；**图提示词 0/128 次** | 只在视频节点上用；与新代模板保持一致 |
| `{{@视频N}}` | 指向第 N 路**视频**入边 | `tpl_121`（`将{{@视频1}} 视频内的模特替换成{{@图片1}} 图片中模特`） | 视频输入驱动（A10 原型）专用 |

**编号规律（实测核对 94 条带编号的生成节点提示词）**：

- 编号是**按图片入边序号**，与节点连线顺序一致。`tpl_129` 的入边顺序是「产品图2 → 产品图1 → 模特图」三条 `image_source`，提示词里写 `产品图{{@图片1}} {{@图片2}} 、主播模特图{{@图片3}}`——即**按连线先后编号，与源节点标题里的数字无关**。
- `{{@图片N}}` 与 `{{@视频N}}` **各自独立计数**：`tpl_121` 的入边是「参考视频-1 → 模特图-1」，提示词里同时出现 `{{@视频1}}` 和 `{{@图片1}}`，图片序号不因前面有一条视频入边而变成 2。
- `tpl_130` 六图入边（模特图 + 服饰图1–5），提示词写 `参考{{@图片1}} 里模特的五官长相及发型特征。模特分别穿着{{@图片2}} {{@图片3}} {{@图片4}} {{@图片5}} {{@图片6}}`——**六路全部逐一编号**，这是保证「不串图」的关键写法。

**选用建议**：

1. 图节点：写 `图1` / `图2`（或统一写 `参考图1` / `参考图2`），不要用 `{{@图片N}}`——128 条图提示词里一次都没用过。
2. 视频节点：新画布统一用 `{{@图片N}}`（显式，指向清晰）；若沿用旧代模板风格写 `图N` 也可以，但**同一节点内不要混用**。
3. 无论用哪种，**先写「N 号是什么」再写要求**：`图1作为模特参考，图2作为服装参考`（`tpl_116`）、`图1为【模特1】，图2为【模特2】，图3为【模特3】`（`tpl_127`）、`【产品】: 参考产品图1，【人物】: 参考人物图1`（`tpl_104`）。只写「保持图2不变」而不交代图2是什么，模型只能猜。
4. **混用风险**：`图N` 与 `{{@图片N}}` 在同一段里并存时，模型可能把两者当成不同素材；同理，`【套图N描述】`这类**文本锚点**里的数字与图片编号毫无关系（`tpl_10` 的 `图1` 是参考图，`【套图2描述】` 是第 2 段文本），两类数字同屏时要在文字上区分开（如 `图1` vs `套图2`）。

## 2. 主体锁定句式库（图生图必带）

`保持` 在 128 条图提示词里出现 88 次——这是图生图的**第一句话**。按强度分三档：

### 2.1 最短可用句（一句话，模板里最常见）

| 句式 | 出处 |
|---|---|
| `保持产品的外形不变` | `tpl_23` |
| `保持产品（图1）外形不变` | `tpl_12` |
| `保持产品外观特征不变` | `tpl_26` |
| `保持产品造型、大小比例、材质与文字细节不变` | `tpl_61` |
| `保持模特样貌服饰不变` | `tpl_61` |
| `保持图1结构特征不变` | `tpl_33` |
| `参考图2，保持产品外观一致` | `tpl_100`（视频侧最短形态） |

### 2.2 标准锁定句（推荐默认，覆盖五个维度）

> `基于图1参考（保持模特和产品特征、产品文字细节及大小比例不变），结合【套图1描述】描述 prompt，生成新的画面`
> —— `tpl_10` / `tpl_60`（57 字，模板库里复用度最高的一句）

维度拆解：**特征**（是谁）+ **文字细节**（logo/标签不能糊）+ **大小比例**（商品图硬要求）。`tpl_15` 在此基础上加 `画面风格色调不变`。

### 2.3 强锁定句（一致性要求高的商品/服装类）

> `图1作为模特参考，图2作为服装参考。保持图1模特的脸部特征、发型、身材比例、人物气质、基础体态特征稳定不变，让图1中的模特真实自然地穿上图2中的服装。服装必须高度还原图2的服装类别、款式、版型、剪裁结构、领口、袖型、衣长、裙长或裤长、面料质感、颜色、图案、装饰细节与整体穿着效果，不要随意改款，不要替换服装类别，不要额外添加无关配饰。`
> —— `tpl_116`（节选）

要点：**逐项枚举**要锁的东西（类别/款式/版型/剪裁/领口/袖型/衣长/面料/颜色/图案/装饰/穿着效果），然后紧跟 `不要…` 三连（不改款、不换类别、不加配饰）。枚举 + 禁止，比一句「保持一致」稳得多。

### 2.4 主体锁定的三条补充规则

1. **锁「不变」的同时给出「变」的清单**：`tpl_35` 的做法是「4 个场景必须使用**完全一致**的光影描述词，一个字都不能改」+「唯一能改变的是模特的动作姿态、背景、镜头」。只锁不变会得到 4 张一样的图。
2. **禁止凭空添加**：`tpl_118`——`图1中不存在的元素不得凭空添加，仅使用图1已有主体、元素及场景进行合理延展`；`tpl_89`——`严禁推断、脑补、扩图（Outpainting）或自动补全任何输入图片中不可见的内容`、`若输入图片为半身，则输出必须保持半身；若输入图片未展示鞋子，则禁止生成鞋子`。这两条是「套图/拆解类」防幻觉的核心。
3. **冲突时以输入图为准**：`tpl_89`——`当模板需求与输入图片内容发生冲突时，始终以输入图片为唯一依据`。把优先级写死，能避免模型为了让画面「好看」而改产品。

## 3. 画面描述维度清单

按「1 主体 → 2 构图 → 3 镜头 → 4 光影 → 5 材质 → 6 背景 → 7 色调 → 8 文字排版 → 9 留白/安全区」顺序写，缺项按需省略（图提示词中位才 55 字，不必全上）。

| # | 维度 | 可用词（模板实测用语） | 出现密度（图/视频） |
|---|---|---|---|
| 1 | 主体 | `产品`/`模特`/`【产品】`/`【人物】`/`【模特1】`；固定姿势：`正面`/`侧面`/`半身`/`全身`/`手持`/`佩戴` | 模特 76/36、产品 108/163 |
| 2 | 构图/版式 | `主体居中偏上`/`高低错落`/`中心对称`/`对角线`/`三角构图`/`环绕式`/`前景遮挡构图`/`框架式构图`/`大面积留白`/`黄金分割点` | `tpl_23` 列了 9 种构图策略 |
| 3 | 镜头与景别 | `特写`/`微距`/`近景`/`中景`/`全景`/`低角度仰拍`/`俯拍`/`45度`/`荷兰倾斜镜头`/`85mm镜头`/`浅景深(Bokeh)`/`广角畸变`/`长焦压缩` | 镜头 8/219（图侧很少写镜头，视频侧必写） |
| 4 | 光影 | `高键柔光`/`蝴蝶光`/`侧逆光`/`轮廓光`/`柔和棚拍主光`/`大面积漫射主光`/`焦散光效(Caustics)`/`百叶窗光栅`/`光束` | 光影 5/18 |
| 5 | 材质质感 | `磨砂`/`镜面抛光`/`拉丝`/`玻璃通透`/`高光反射`/`金属边缘`/`织物纹理`/`纱线结构`/`哑光` | 质感 25/43 |
| 6 | 背景/场景 | `纯净高亮白色无缝背景`/`浅灰渐变`/`极简反光镜面桌面`/`摄影棚`/`生活化场景`；一致性句：`保持场景不变`（`tpl_65` 5 个节点全带） | 背景 37/50 |
| 7 | 色调 | `低饱和`/`冷调`/`暖性色调`/`高调纯白`/`蓝粉渐变`/`与产品色调相匹配的极简背景` | 氛围 7/16 |
| 8 | 文字与排版 | `文字必须拼写正确、清晰、极简`/`中英双语标注`/`现代无衬线字体（类似 Helvetica / Inter）`/`LOGO不变形`/`保持完美的中文和英语`(`tpl_19`) | 文字 34/15 |
| 9 | 留白与安全区 | `大量留白`/`画面干净克制`/`信息清晰但保持高级感，不要杂乱`（`tpl_89`）/`产品处于画面黄金分割点` | — |

**写法建议**：

- **图侧**：3–6 个维度就够（中位 55 字）。带字的营销图必须有第 8 项；商品套图必须有第 1、5、6 项。
- **视频侧**：第 3 项（镜头）几乎必写，且要和运镜动词搭配：`推、拉、横移、环绕、跟随`（`tpl_62`）、`跟随挥剑轨迹做动态推拉摇移，从近景特写拉至全景`（`tpl_72`）。
- **专有名词可夹英文**：`tpl_113` 用 `Hero Shot`、`tpl_116` 用 `tactile fabric texture / couture-level material rendering`；实测中英混排 9 条里全是「中文叙述 + 英文术语」，**不要写成英文风格词堆叠**。

## 4. 负面约束清单

图侧禁止项密度 16%（23/142），视频侧 50%。视频约束更多，是因为视频更容易出现手部畸形、字幕乱入、口型不对。

| 类别 | 原文句式 | 出处 |
|---|---|---|
| **不改款/不替换** | `不要随意改款，不要替换服装类别，不要额外添加无关配饰` | `tpl_116` |
| **不脑补/不扩图** | `严禁推断、脑补、扩图（Outpainting）或自动补全任何输入图片中不可见的内容` | `tpl_89` |
| **不新增人物** | `若参考图无模特，输出内容严禁凭空增加模特，仅对产品进行静物构图变换` | `tpl_15` |
| **不新增模特（描述层）** | `参考图中主体，如无模特则不要做新增模特的描述` | `tpl_10` |
| **视角红线** | `严禁使用90度垂直拍摄` | `tpl_15` |
| **画面无文字** | `不允许出现任何文字元素（标题、文案、贴纸、英文单词等）` / `严禁文字、水印、复杂背景` | `tpl_20` / `tpl_32` |
| **视频：无字幕** | `全程画面不出现字幕，配上背景音乐` / `全程不得生成任何字幕。9：16竖屏…` | `tpl_100` / `tpl_101` |
| **视频：手/腿畸形** | `全程禁止有多余的手、腿，禁止动作不自然，禁止有任何字幕、特效` | `tpl_102` |
| **视频：口型** | `全程口型和台词100%对上` | `tpl_102` |
| **视频：禁 AI 播音腔** | `禁止AI播音腔、客服腔、字正腔圆、逐字朗读、固定节拍和每句话相同语调` | `tpl_129` |
| **视频：不要机械背稿** | `像真实分享而不是背稿` / `避免刻意表演，保持轻松、亲和、有镜头交流感` | `tpl_129` |
| **视频：无乱码文字** | `视频内文字必须拼写正确、清晰、极简，不生成乱码，不出现额外文字，不出现真实品牌 Logo 或商标` | `tpl_113` |
| **视频：不插特效音** | `全程不添加与画面动作、环境相匹配的特效音（SFX），仅生成音量较大的背景音乐` | `tpl_123` |
| **工具类：防畸形** | `确保接物手部结构绝对正确（无多指/畸形）` | `tpl_137` |

**写法要点**：负面约束要**具体到对象**（多指 / 字幕 / 乱码 / 改款），不要写「不要出错」。另外注意一个反直觉的实测：**`100%` / `唯一` / `绝对` / `顶级` 在高分模板里大量出现在提示词中且是好事**——`保证衣服B和原图100%一致`（`tpl_44`）、`以{{@图片1}} 产品图为唯一主体`（`tpl_120`）、`人物与服装为绝对视觉主体`（`tpl_116`）。这些是**画面锁定语**，不是电商宣称（电商宣称问题见 §7）。

## 5. 三个可直接改用的模板

### 5.1 模板 A：商品海报（图 + 文字，`gpt-image-2` / `quality=high`）

```
图1为产品参考，图2为视觉风格参考。保持图1产品的外形、颜色、材质、文字细节与大小比例不变，
保持图2的版式结构与视觉调性，不要改款、不要替换产品类别。
画面：[主体位置与姿态] + [背景氛围] + [光影] + [色调]。
文字：主标题「____」居中偏上，副标题「____」，价格「____」置于右下角；
中文字体为现代无衬线，文字必须拼写正确、清晰、不出现乱码、不出现错别字，
不添加任何未指定的文字、贴纸或水印。
版式：主体占画面约 [60]%，四周留出安全边距，画面干净克制。
```

对应实测骨架：`tpl_12` 的 `参照参考图（图2）视觉风格，保持产品（图1）外形不变，生成一张促销海报，背景要和产品相融合，要有高级感，版式大气规整`；文字层参照 `tpl_14` 的字段级约定（`logo / 产品名称 / 副标题 / 卖点 / 价格`，无对应文案则直接省略、不虚构）。

### 5.2 模板 B：场景套图单张（4 节点 fan-out 用，`gemini-3-pro-image-preview` / 3:4）

```
图1为产品参考。保持产品外观、材质、文字细节及大小比例不变，保持画面风格色调不变，
结合【套图N描述】描述 prompt，生成新的画面。
```

这就是 §1 与 `references/text-node-prompting.md` §4.2 的下游节点原文（`tpl_10` / `tpl_60` / `tpl_15` 同源）。**T2 场景**（不用 LLM 节点）时把锚点段替换成自己写死的描述：

```
图1为产品参考。保持产品外观、材质、文字细节及大小比例不变。画面：微距特写，产品正面 45° 立于哑光石台，
纯净渐变背景，侧逆光勾出边缘高光，视觉焦点在瓶身磨砂质感与 Logo 清晰度。3:4 竖构图，画面干净克制。
```

### 5.3 模板 C：带货短视频分镜（`seedance-2.5-vip-r2v` / 9:16 / 480p）

槽位式开头（**视频侧 41% 的提示词用【】槽位，是最稳的开法**）：

```
【产品】: 参考产品图1，保持产品外观一致。
【人物】: 参考人物图1，保持人物面部特征、发型与服饰一致。
【背景】: 参考图2，现代简约家居氛围，暖色木地板 + 白墙，生活化场景。
【台词】: 姐妹们，____！（一句话卖点 + 一句行动号召，口语化，不夸张宣称）
【字幕】: 全程画面不出现字幕，全程口型和台词100%对上。
【音频】: 配上轻快背景音乐，禁止AI播音腔、逐字朗读。
```

时间轴分镜（`tpl_104` 的 `[0-3s…]` 写法，段落标题用中括号标时间段）：

```
[0-3s 开篇] 中景，人物手持产品从画面右侧入镜，镜头缓推，产品位于画面黄金分割点。
[3-8s 展示] 特写切产品细节，手指轻触产品表面，浅景深虚化背景，高光扫过材质纹理。
[8-12s 使用] 中景生活化使用场景，人物自然动作与产品互动，镜头横移跟随。
[12-15s 收尾] 产品单独定格在画面中心，柔和顶光，镜头缓慢拉远，画面渐暗结束。
```

节奏与运镜可选词：`推、拉、横移、环绕、跟随`（`tpl_62`）、`360°环绕运镜`（`tpl_104`）、`丝滑快速运镜`（`tpl_113`）、`节奏有变化`（`tpl_62`）。

**参数配套提醒**：`seedance-2.5-vip-r2v` 快照 `maxPrompt` 为 5000 字，分镜脚本 500–900 字很安全；若换 `veo-3.1*`（1000 字）或 `MiniMax-Hailuo-*`（2000 字），必须压缩到槽位 + 短分镜。

## 6. 自包含原则（必须遵守）

**生成节点的提示词必须能独立跑通，即使上游连着文本节点。**

理由：文本节点是 LLM 节点，**agent 不能运行它**（`canvas_run` → `UNSUPPORTED_NODE`）。用户没点生成、或点了但结果为空时，下游图像节点拿不到任何描述文本。实测依据：`tpl_19` 有一个 `入度>0 但 prompt 为空` 的文本节点，`value` 里存的是已生成产物——说明文本节点的内容完全依赖它被运行过。

落地做法：

| 情形 | 写法 |
|---|---|
| 上游是 T1（LLM）节点 | 提示词里保留 `结合【套图N描述】描述 prompt`，**但同时把该路的画面要点也写进提示词**（如 `…结合【套图1描述】；若无可参考描述，则按：微距特写、产品正面 45°、纯净渐变背景生成`） |
| 上游是 T2（agent 写死正文） | 锚点引用是安全的，正文一定存在 |
| 上游是文本输入节点（用户填素材） | 不要把「用户填了什么」当成必然；提示词里给出缺省值 |
| 上游是图片节点但用户可能没传 | 给 `tpl_26`/`tpl_44` 式「上传或生成」双用途节点（`prompt` 非空、入度 0），用户传了就用传的 |

另外：**图/视频提示词不要依赖「上游文本会带着格式信息过来」**。`tpl_11` 的实测产物里带着 `**加粗**` 和 emoji，若下游要引用这段文本，应在下游提示词里补一句「忽略上游文本中的任何标记符号，只取内容」。

## 7. 电商合规红线（写文案与带字海报前必读）

以下三条是硬约束。**注意区分**：§4 里的 `100%` / `唯一` / `绝对` 出现在**画面锁定语**里是允许甚至推荐的；同样的词出现在**面向消费者的商品文案**里就是违规风险。

| 红线 | 判定 | 反例（模板库里真实出现过的素材，写新画布时要避开或改写） |
|---|---|---|
| **绝对化用语** | 商品文案中不得出现「最」「第一」「唯一」「100%」「绝对」「顶级」「世界级」「彻底」等极限词 | `tpl_11` 文案产物里的 `简直就是我午后独处时的最佳搭档`、`那这只杯子绝对值得拥有`；`tpl_25` 的 `采用顶级商业布光系统`（技术描述可留，商品卖点不可） |
| **功效宣称** | 化妆品/食品/保健品不得宣称医疗作用；功效表述需有依据、不得绝对化 | `tpl_129` 的 `提供深层补水与保湿功效`、`渗透肌底长效保湿`；`tpl_22` 的 `美白亮肤`、`美白有保障`、`两周提亮淡印`（含时限承诺，风险最高）；`tpl_19` 的 `抗氧抗糖、紧致弹润`、`逆龄属性` |
| **品牌 logo 授权** | 不得生成真实第三方品牌商标；LOGO 需为已授权素材 | `tpl_113` 的收尾约束是最好的写法范本：`不出现真实品牌 Logo 或商标`。替换品牌名（如 `tpl_26` 的 `把耳机上的品牌改为"DYNSIGHT"`）只在**客户自有品牌且已授权**时可用 |

**落地四条**：

1. 涉及功效的文案，一律用**体验描述替代功效承诺**：写「用起来很清爽」而不是「深层补水修护」。
2. 带字海报的文字层，把「不得出现绝对化用语」写进提示词的负面约束：`不添加任何未指定的文字；文字内容不含绝对化用语（最/第一/唯一/100%/绝对）`。
3. 品牌标识：优先用客户提供的授权图；生成画面里只描述「LOGO 不变形、清晰」，不要描述具体品牌名。
4. 交付时如实提示：**画布生成的是视觉素材，文案合规由用户/客户终审**——技能不代替合规审核。

## 8. 分镜 / 漫画类：单幅约束（2026-10-21 实测，画布 103582）

**一句话：分镜图的提示词里不要只写「分镜N」。** 实测把 `竖屏 9:16 国漫电影感插画分镜…` 这种写法连发 4 个节点，`gemini-3-pro-image-preview` **每个节点都返回一整页四格漫画**，并且自己加上了中文小标题（"凌晨一点""街角的热气""最后一颗鱼丸""一起回家"）——4 张图全部是同样的四格页，没法当 4 个独立镜头用。

可用的单幅写法（四个要素缺一不可）：

```
单幅插画（关键要求：整张画面只有一个连续场景，占满 9:16 竖幅；
不要分格、不要分栏、不要排成多格页面、不要边框、不要任何文字、标题或序号）。
[画风句] [场景与人物句] [镜头与构图句] [色彩/光线句]
角色造型、服装、配色保持与剧本设定一致；画面内不出现任何字幕、文字、对白框、水印与品牌标识。
```

要点：

- **把"不要分格"写成第一句**，比放在句尾有效；"漫画页/分镜"这类词会直接触发多格排版，能不用就不用（用「插画」「画面」替代）。
- **"不出现文字"要单独说**，并同时禁"标题/序号"：只写"无字幕"时模型仍会在每格左上角加小标题。
- 每格的角色锚点（发型/服装/围巾/包）要**逐字重复**，四格之间才不漂移；视频节点再写一次同样的锁定句。
- 人物一致性靠"同一段描述 + 相同的画风句"，不要靠"和上一张一样"（模型看不到上一张）。

对应视频侧：接同一条图像入边、写 `画面参考图1…保持人物造型/服装/画风完全一致`，并在 prompt 里给到动作、运镜、时长与"无字幕"。

## 9. 视频节点引用上游音频（必写，2026-10-22 用户实测指出）

`audio_source → audio_target` 只是「边合法」。**模型用不用这条音轨，由视频节点的 prompt 决定**——不写清就是静音成片，
配音节点变成空转的死节点。

### 9.1 唯一推荐写法：第一段就声明素材用途

```
使用连入的图片1和音频1生成这条视频：
图片1是画面底本（人物、服装、场景、画风都按图1），
音频1是这条视频的音轨（旁白/台词原样使用、逐字对齐）。
不要重新配音、不要改写或省略台词、
不要用环境声或背景音乐盖过人声、不要另生成旁白。

9:16 竖屏，电影感。
[0-2s] …
[2-4s] …
[4-6s] …
```

要点：

1. **先说「用哪两样素材、各自干什么」，再说画面**。顺序反过来，模型会先按文字自由发挥。
2. **台词归属写清**：`音频1是医生的台词` / `音频1是旁白`——同一镜头里既有旁白又有对白时尤其重要。
3. **用肯定句**："原样使用""逐字对齐""人声靠前"；不要拿单独成立的否定句当主句。
4. Seedance 2.0 原生支持 `@Audio1` 引用（≤3 段、总时长 ≤15s），必要时补一句「音轨使用 @音频1」加强。

### 9.2 反例（本机踩过）

| 写法 | 后果 |
|---|---|
| 只写「音频轨道使用连入的旁白音频」 | 太含糊，模型理解为"帮我生成一条带旁白的音轨" |
| 再加「环境雨声与雨刮声垫底」 | 模型转去生成环境声，真人声被忽略 |
| 再加「撞击只用一声闷响，不添加多余音效」 | 纯否定句，模型干脆自行合成整条音轨 |
| 视频节点没提音频，只在连线上挂了 audio | 输出静音视频；配音节点看起来"生成了但没人用" |

### 9.3 验证方式

视频跑完不要只看回执：`ffprobe -v error -show_streams -select_streams a output.mp4` 看有没有音频流、
`ffmpeg -i output.mp4 -af volumedetect -f null -` 看均值音量是否非静音；有音频流但没人声，说明 prompt 仍未生效，
换更强的声明句（或补 `@音频1`）再试一条。
