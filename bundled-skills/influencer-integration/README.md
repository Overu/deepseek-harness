# 达人营销 - 整合类技能 🌱

专业的达人营销整合类全案策划技能，输出完整的 **6 大模块**方案。

## 6 大模块输出框架

```
一、洞察 → 二、人群分析 → 三、社媒传播主题 → 
四、核心玩法 → 五、传播部分 → 六、传播效果
```

## 触发词

```
达人种草 | 种草方案 | KOL 投放 | KOC 种草 | 达人矩阵
媒介策略 | 投流规划 | 种草全案 | 小红书投放 | 抖音达人
达人营销整合 | 整合营销方案
```

## 模块说明

### 一、洞察
- Brief 解读（营销目标及任务）
- 行业洞察/场景洞察（行业趋势总结）
- 竞品社媒平台投放分析
- 本品社媒平台投放分析
- 总结：产品卖点、机会点、差异点

### 二、人群分析
- 人群画像描述（年龄、兴趣、地域）
- 用户消费行为习惯
- 用户社媒偏好
- 总结：用户喜欢的内容及调性

### 三、社媒传播主题
- Core Idea
- 传播主题/Slogan（3-5 个供选择）⏸️ **需用户确认**
- 传播调性/人设

### 四、核心玩法
- 视觉创意（KV、视觉符号等）
- 互动机制
- 创意落地

### 五、传播部分
- 话题方向
- 媒介策略
- 投放矩阵
- 传播节奏

### 六、传播效果
- 预算划分
- 效果预估

## ⚠️ 避免低级错误

### 联网检索（DSH web_search）
- 统一通过 DSH 官方 `web_search` 工具检索，无需外部 API Key

### Media Generator 调用
- 所有业务参数**必须**嵌套在 `data` 对象内

### 数据引用
- 每个数据点必须标注引用来源 `[1]` `[2]`
- 禁止编造数据
