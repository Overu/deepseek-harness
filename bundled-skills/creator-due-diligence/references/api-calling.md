# DSH 接口调用说明

本技能的执行单元是一次已授权 API 查询，不是本地采集脚本。Agent 负责选路线、填写参数、翻页、理解结果及组织报告；DSH 提供工具调用和已有鉴权。预算或任务存储由宿主提供时直接使用；未提供的部分按下述规则在任务记录中维护，不搭建新服务。

## 1. 直接调用宿主工具

先读取当前可用工具的实际定义，将路线映射到其参数格式。若是通用请求工具，传连接、方法、路径及 query/body；若是专用平台工具，按其声明字段调用。不要把下例当成真实工具名称或声称宿主一定支持某个参数。

通用请求内容示例（仅展示结构，不代表已执行）：

```json
{
  "connection": "tikhub",
  "method": "POST",
  "path": "/api/v1/douyin/search/fetch_user_search_v2",
  "body": {"keyword": "蓝战非", "cursor": 0}
}
```

依据 [目录](public-endpoints.json) 的 `method / path / parameter_location / required / parameters` 选字段；GET参数进入 query，查询型POST参数进入 body，不因为是POST就视作写入授权。目录之外的路线先核对官方文档、价格及工具允许范围，不猜参数、不绕过网关权限。

直接使用已配置的连接。没有某条路线时换已核对的可用入口；没有可用取数工具时指出具体连接缺口，继续已可完成的部分，不要求安装脚本、不寻找本地Key。登录或权限问题交由宿主正常连接流程处理，不自动充值、购买权限或联系供应商。

## 2. 每次返回检查

按实际工具定义区分工具包装层与供应商响应，再读取API合同指定的路径，不机械多剥或少剥一层。依次核对：

1. 请求是否实际发出、工具/网关状态及供应商状态是否可区分；保留实际请求标识。
2. 业务码和返回对象是否正确，稳定ID与目标是否匹配。
3. 目标列表、字段、发布时间、游标、排序和有效条数；缺字段不当作零。

保留查询词、路线及版本、参数、请求时点、原始条数/去重数、游标和停止原因。认证头、Cookie、临时签名链接、无关个人资料不进入报告或交付附件。

稳定ID使用字符串。超过安全整数范围的ID若已被工具解析为可能舍入的数字，不把它转字符串冒充正确ID；优先取得原始文本或宿主保真字符串，不能恢复则记录该对象缺口。

### 评论

- 抖音 `app/v3/fetch_video_comments`：供应商响应 `data.comments`。
- 小红书 `app_v2/get_note_comments`：供应商响应 `data.data.comments`。
- 其他路线按平台路由及实际响应核对；蒲公英精选Top5与公开评论分页分开。

有效评论需有非空字符串ID及正文，排除明确标记不可用的条目；跨页用平台＋评论ID去重。列表为空、结构不符、没有可用评论分别记录。只返回1条有效评论就记1条；若目标5条，差额4条，不能写无评论或目标达成。评论总量字段不是实际取得数量。数量达标也不等于证据充分。

### 分页和错误

后续请求只使用真实返回的下一页参数，保留游标原值；重复游标/重复页且没有新内容时停止该链。只支持默认排序时记默认，不伪造热门/时间排序。

HTTP200不自动代表业务成功；403只说明被拒，原因按实际信息核对。超时、断连、网关失败而结果不确定时保留可能计费额，先核对调用状态，不自动重发。已确认未发出的请求不虚构扣费。确认是瞬时错误且费用已计入时，同路线最多一次有依据的复查；否则改用一个文档已核对的替代入口或记录缺口。单接口失败不扩大为整平台无数据。

## 任务预算与续跑

使用同一个任务标识，记录 `budget_usd / prior_spend_usd / cumulative_reserved_usd / approval_ref` 以及每次请求、估算、结果。字段是任务记录约定，不是强加给DSH工具的新参数。

- 默认总额1美元，显式更低额度优先。请求前，已有支出＋累计预留＋下一笔估算不得超过有效总额。
- 依据目录 `price_usd / price_checked_at / price_source` 估算，不把快照价格称为实时核价或账单；未知价格先核对，历史查价失败不当作业务接口已失败。
- 发送前先记预留，失败或结果不确定但可能计费的请求保留该预留。实际扣费无账单依据时为 null；有依据的账单核对另记，不双重累加同一请求。
- 宿主有统一预算工具时使用它；没有时由单一主代理维护可跨轮次保留的任务记录，付费请求顺序执行。没有本地磁盘不影响记录；可存宿主任务状态或任务附件。若续跑时无法恢复累计值，先恢复记录，不以新账本或零费用继续。
- 下一笔预计超额或宿主提示额度不足时停止；告知当前累计估算、新增工作的必要性及建议新总额，只有明确批准才更新原记录并继续。追加1美元与总额改成2美元需分清。原支出、失败记录保留，不重置路线复查次数。

这套记录不要求特定账本文件、文件锁、终端、运行时或环境变量，也不要求用户逐次审批预算内的正常取数。

## 结果与留存

用实际响应中的字段输出账号资料、作品、评论、品牌关系和证据。接口未提供的授权指标不编造；不要把未知播放量写成0。系统性结论的采样和判断要求见 [跨平台采样](cross-platform-sampling.md) 与 [调查规则](investigation-method.md)。

业务报告、证据册、结构化JSON按 [报告规范](report-contract.md) 保存为DSH支持的文档、附件或任务记录；没有文件输出工具时先返回精炼报告与必要公开来源，并保留可恢复的结构化任务记录。不虚构本地路径、附件或下载链接。
