# 调查与证据规则

按任务读取并执行所需模块。完整合作背调先按 [跨平台采样规则](cross-platform-sampling.md) 逐一盘点八个基准平台，在已确认账号与第三方公开内容中分层采样；用户限定范围时按其范围执行。受预算、权限或可见性限制时保留缺口，账号盘点完成不等于所有平台都已完成深采样。

## 身份、时间与来源

- 每个平台保留稳定账号 ID、昵称、已核验别名及身份依据。姓名相同只能生成待核身份线索，不能计入该达人的风险。
- 分开保存事件发生时间、内容发布时间、数据抓取时间、平台统计窗口；没有的字段为空，并说明影响。翻炒旧事不能按转发日期当成新事件。
- 来源分级：`primary_official` 原始官方材料、`primary_party` 当事人原文、`independent_report` 可追溯独立报道、`user_account` 用户经历或意见、`repost_unverified` 搬运/匿名材料。级别不自动决定真假；当事人自述不证明其全部主张。
- 同一截图、原帖或通稿的转发共用 `origin_cluster_id`，分别统计传播量与独立来源数。
- 原始来源数、不同发布主体数与经核实的独立来源数分开；独立性未知时不填独立来源数量。每个关键观点填写 `evidence_adequacy`，不以单平台大量评论代替跨平台支持。
- 标记“已核实”应限定到具体主张：确认某账号确实说过一句话，不等于确认那句话指控的事情发生过。
- 来源互相矛盾时保留双方最强证据，说明尚缺哪项验证；严重负面定性或排除建议交由人审复核，模型不能代签 `human_review=completed`。

## A. 公开争议事件

从中性检索进入，再补风险词和回应词：昵称/别名＋评价/合作；＋与业务相关的投诉/虚假宣传/争议等；＋回应/澄清/后续。关键词只用于检索，不是行为发生的标签。

将命中内容整理成事件，而不是堆砌帖子。每个事件记录：具体指控、归属对象、发生/发布时点、最初来源、独立补证、反证/回应、当前状态、传播范围、合作相关性。

状态采用 `verified / disputed / unverified / refuted / insufficient`：

- `verified`：现有直接或权威证据支撑该**具体事实**，写清确认范围。
- `disputed`：实质争议或相互冲突证据尚未解决。
- `unverified`：有指控线索但未核验；不能通过转发数升级。
- `refuted`：有足够证据否定该具体指控；仅有“澄清”标题不够。
- `insufficient`：身份、原文或关键上下文不足，无法判断。

不得围绕无关私生活、家庭成员、住址、健康信息或受保护属性调查；不推测人格、犯罪倾向。实际商业相关的公开行为按可验证事实描述，避免“失德达人”这类全人定性。

## B. 竞品合作与排他

在达人作品、正式商业记录、品牌官方内容中交叉搜索品牌全称、简称、产品型号。时间窗口由项目给定；未指定可建议近一年作为首轮目标，记录实际覆盖，不宣称完整。

关系标签：

| 类型 | 最低支撑 |
|---|---|
| `endorsement` 正式代言 | 官方原文明确代言身份；仅确认证据所述期间/区域/品类 |
| `paid_promotion` 商业推广 | 正式合作标识、已验证平台合作记录或明确商业声明 |
| `affiliate` 带货关联 | 可验证商品关联/佣金披露；不扩成代言 |
| `gifted` 赠品体验 | 明确赠品披露；不推断付费 |
| `suspected_promotion` 疑似推广 | 存在营销特征但无法证实商业关系 |
| `organic_mention` 自然提及 | 仅自然讨论证据；“未见标识”本身不足以确定非商业 |
| `unknown` 未知 | 单次露出、证据冲突或信息不足 |

同一条商业合作与代言可分开记录，不能用合作篇数充当代言数量。是否仍处排他期必须有合同或明确官方条款证据；过去合作不自动构成当前冲突。

合作记录至少包含品牌/产品、关系类型、发布及有效期间（未知为 null）、证据、身份匹配、排他状态 `confirmed_active / confirmed_inactive / unknown`。用已知竞品合作时间和投放计划提示可能冲突，但不声称违反合同。

## C. 本品相关言论与对比

采集原文、完整对话或可核验视频片段，保存说话者、目标品牌/型号、原话、前后文、视频时间点和商业背景。用 `title_only / excerpt / full_text / full_media_review` 标记理解范围。

观点分类可为正面、负面、混合、中性、不确定；表达性质另记具体体验、参数比较、个人偏好、事实指控、侮辱性表达或转述。不要把负面观点与恶意同义。

需要识别口播/字幕/图片时调用宿主已获准的 ASR/OCR/媒体理解工具，保留低置信识别段落并人工复核。没有这些工具时将相关内容标为未审阅，不因只分析标题而宣布视频无风险。

例如“B 避障强，但清岚清洁更好”是混合比较线索；缺完整实测过程时不能断言其恶意贬损。只有与原文匹配的证据才可提出“疑似贬损/误导表达，需复核”，不能推测受谁指使或恶意动机。

查看相关更正和后续观点；同一人前后不一致可能来自产品更新、不同型号或体验变化，不自动等于收钱改口。

## D. 历史作品、标签与内容热词

按跨平台采样规则为每个已确认本人账号保存目标、实际数量、时间分层与差额原因。主要活跃平台首轮以30–50篇作品元数据为目标；旧合作、关键事件与本品对比另做定向回溯，不只取最新若干条。

先定义**作品抽样框**：账号、平台、目标时间窗、可取得的作品总量或未知、抓取入口和排序。优先覆盖时间分布及内容差异：近期与较早期、普通与商业内容、相关品类与其他主要主题、高互动与常规作品、争议前后（确有事件时）。可全取则全取；否则写明入样规则和各层实际篇数，不把“最近若干条”称为历史全貌。作品链接/ID、发布时间、标题、文案、平台原生话题标签、商业标识及可见表现字段逐篇保留；播放/互动口径与统计时点分开。

内容归类包含长期主题、表达方式、品牌/竞品露出、销售导向、价值观或言论风险等**与本次合作相关**的维度。标题与文案不能代替视频口播、画面和评论；只取得元数据时，内容审阅范围标为 `metadata_only`，不判断视频中没有某句话或某品牌。高风险内容应回到原作品及前后文，不因标题或剪辑片段直接定性。

分别整理三种词：`native_hashtag`（作者/平台显示的原生话题标签）、`creator_term`（标题/文案/经审阅的口播或画面文字）、`audience_term`（评论与回复）。保留原词、规范化词、来源层、时间窗、出现的**不同作品或评论数**及分母、代表证据；同义归并和停用词规则需记录。高频不等于平台热榜；只有外部趋势源支持时才使用“平台热词/趋势”称谓。词频不证明受众身份、购买意向或事件真伪；异常刷屏、营销模板和争议期间激增需单独标记。

比较不同时间段或内容层的主题与标签变化时，维持相同取样口径；无法比较则只描述该样本。商业内容占比的分母是**分类明确的已取作品**，未知合作属性单列，不能从“未见广告标识”推断为非商业。

## E. 作品评论与用户反馈

主要活跃平台首轮以10–20篇不同作品、每篇50–100条去重主评论为工作量目标，实际以可见量、去重增量和剩余预算为准；目标不是总体统计代表性门槛。同步纳入第三方原帖和合作品牌评论，各层分别统计，缺口按真实原因标注。

先以上述作品抽样框选择评论对象，不只挑争议帖或高赞帖；再按实际可取得的来源区分：本人普通作品、本人商业作品、第三方评价、争议讨论。每层分别记录作品数、评论可见范围、时间窗、选帖依据、排序、分页、采集及去重数量。最新评论与高赞评论分开标记，精选评论单列；主评论与回复保留线程关系，以平台+评论 ID 去重。相同文本重复传播另标，不能自动认定水军。

先判断评价对象：达人、产品、品牌、其他人或不明；再判断情绪、主题与经历类型。粉丝身份/购买者身份不能从语气自动确认，用户自述购买也需标为自述。

主题可包括专业可信度、商业诚信、推荐体验、购买/使用后的自述反馈、购买意向、价格/品质异议、广告疲劳、沟通态度、纠错反应、内容喜好；仅选有材料的主题，引用必要的去标识短摘录。把“问哪里买”“买过不好用”“觉得贵”分别标为咨询、自述体验、观点，不折算为成交、退货或真实买家比例。对达人本人的评价与对合作品牌/产品的评价分别展示。

若计算针对达人的样本负面占比：

`negative_share = negative / (positive + neutral + negative)`

分母仅含**同一层、去重后、对象明确为该达人、情绪可判定**的评论。多义、反讽无法判断或混合情绪记 `uncertain`，另报数量和排除原因；分母为零输出 null。同时展示采集总数、去重数、对象相关数、可判定数和四类计数。多主题可重叠，不把主题比例相加当情绪比例。

同时保存**定性主题**与必要的去重计数：主题命中多少条、涉及多少篇作品、时间分布、代表性原话及反例。精选 Top5 只支持对这5条的描述，不用于整体风评或趋势。单次快照不能产生“风评正在恶化”的趋势；趋势需可比时间窗和抽样口径。跨平台不简单汇总成一个全网负面率；点赞加权仅为传播信号，不能解释为人数或总体意见。若评论不可见或只取到少数精选评论，在结构化记录中注明未完成系统评估，不以媒体报道替代；主报告只写有事实支持的具体反馈。若因此无法判断关键诚信争议，直接写明需核实的争议及签约处置，不加通用免责声明。

## 合作建议

风险分开描述事件严重性、证据置信度、传播影响、时效/解决状态、品牌相关性；不压成一个人品分。阈值来自品牌已确认规则，无规则时给出理由和待核建议，不发明统一否决标准。

- `proceed`：在已说明范围内证据足以支持推进，没有发现适用硬冲突；不等于零风险认证。
- `conditional`：可推进沟通，但签约/上线前须满足明确条件。
- `hold`：存在需先核实的重要事件或关键冲突；说明是缺证还是已确认事实。
- `exclude`：已核实事实触及明确品牌规则，附事实证据与规则 ID；严重指控依赖人审，未复核时用 hold。
- `insufficient`：覆盖或身份证据不足，无法给合作结论。

证据不足与风险高是两个维度。没有评论数据时不能给“风评良好”；只有同名负面帖时不能给“风险高”。排他状态未知时列入签约待核，不一律判定冲突。
