## 服装/时尚类

### 1. 优衣库 × 牛仔裤 (24h JEANS)

| 字段 | 内容 |
|------|------|
| **品牌** | UNIQLO（优衣库） |
| **产品** | 牛仔裤（24h Jeans） |
| **核心卖点** | 24 小时全天候舒适、高弹力、自由伸展、百搭时尚 |
| **目标人群** | 追求舒适体验与时尚穿搭的年轻都市人群、上班族、活跃的生活方式追求者 |
| **人性需求** | 生理需求：舒适、运动；审美需求：时尚美 |
| **消费者洞察** | 现代都市人生活节奏快且场景多变，我渴望拥有一条既具备牛仔裤的时尚外观，又能像运动裤一样舒适，能够适应从工作、运动到睡眠全天候各种场景的裤子。 |
| **创意概念** | "24h JEANS"（全天候舒适，时刻相伴） |
| **创意手法** | 广告型创意——>消费者投射——>生活片段；广告型创意——>艺术化——>利用舞蹈 |

**关键学习：**
- 用"24h"这一时间概念强化"全天候"卖点
- 通过舞蹈、运动等极限动作展示产品弹力
- 红色时间圆环视觉符号贯穿全片

### 2. 优衣库 × Bratop（带杯背心）

| 字段 | 内容 |
|------|------|
| **品牌** | UNIQLO（优衣库） |
| **产品** | Bratop（带杯背心） |
| **核心卖点** | 内置胸垫、无钢圈、舒适自在、多场景适用 |
| **目标人群** | 追求舒适与自在的现代女性 |
| **人性需求** | 生理需求：舒适；情感需求：亲人理解；自我实现：追寻自我、个性 |
| **消费者洞察** | 现代女性在一天中需要在不同角色之间频繁切换，不仅需要外在的得体，更需要内在的舒适支撑，以从容接纳并享受每一个不同侧面的"我"。 |
| **创意概念** | "いろんなわたしが、わたしです"（不同的我，都是我） |
| **创意手法** | 广告型创意——>消费者投射——>生活片段；情感共鸣 |

**关键学习：**
- 用"不同的我"呼应女性多角色身份
- "都是我"传递自我接纳的品牌态度
- 日语原案更有情感韵味

### 3. 优衣库 × 轻羽绒 (Ultra Light Down)

| 字段 | 内容 |
|------|------|
| **品牌** | UNIQLO（优衣库） |
| **产品** | 轻羽绒（Ultra Light Down） |

| **人性需求** | 生理需求：保暖、出行；自我实现：自由 |

| **创意概念** | "OUTDOORS x ULTRA LIGHT DOWN"（户外 × 超轻羽绒） |
| **创意手法** | 广告型创意——>消费者投射——>产品体验；意象化 |

**关键学习：**
- "轻"是核心差异化卖点
- 用"×"符号表达跨界合作感
- 户外场景强化产品使用情境

### 5. 优衣库 × 空气感口罩 (AIRism Mask)

| 字段 | 内容 |
|------|------|
| **品牌** | UNIQLO（优衣库） |
| **产品** | 空气感口罩（AIRism Mask） |
| **核心卖点** | 透气、舒适、三层防护、可重复使用 |
| **目标人群** | 日常需要佩戴口罩的都市人群 |
| **人性需求** | 生理需求：舒适、健康 |
| **消费者洞察** | 长期佩戴口罩让我感到闷热不适，我渴望一款既透气舒适又能提供有效防护的口罩，让日常防护不再是负担。 |
| **创意概念** | "あつく、こもる、むれる。"（热、闷、潮）→ "AIRism Mask" |
| **创意手法** | 广告型创意——>消费者投射——>痛点呈现；问题解决型 |

**关键学习：**
- 先呈现痛点（热、闷、潮）再给出解决方案
- 三个词精准概括口罩佩戴痛点
- 产品名"AIRism"直接传达透气特性

| **产品** | Mac 电脑 |

## 案例使用指南

### 分析新 Brief 时

1. **找相似案例** - 根据品类/人性需求查找相似案例
2. **参考洞察结构** - 学习消费者洞察的表述方式
3. **借鉴创意概念** - 参考创意概念的命名和阐释方式
4. **避免雷同** - 确保创意概念有差异化

### 创意发想时

1. **需求匹配** - 根据目标人性需求找对应案例
2. **手法参考** - 学习案例使用的创意手法
3. **概念变形** - 基于经典概念进行创新变形
4. **跨品类借鉴** - 不同品类的创意可跨界参考

### 学习提升时

1. **对比分析** - 对比同一品类不同品牌的创意差异
2. **需求映射** - 分析不同创意触达的人性需求
3. **手法总结** - 归纳常用的创意手法类型
4. **概念库积累** - 建立自己的创意概念库
