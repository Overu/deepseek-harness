## 字段说明

### 基础信息

| 字段 | 说明 | 示例 |
|------|------|------|
| 行业/品类 | 广告所属的行业和品类 | 服装/时尚、食品饮料/碳酸饮料、科技/智能手机 |
| 品牌 | 品牌名称，可包含中英文 | UNIQLO（优衣库）、Coca-Cola（可口可乐） |
| 产品 | 具体产品或产品线 | 牛仔裤（24h Jeans）、Bratop（带杯背心） |
| 核心卖点 | 产品的主要功能/情感利益点，1-3 个 | 24 小时全天候舒适、高弹力、自由伸展 |
| 目标人群 | 广告针对的核心消费人群 | 追求舒适体验与时尚穿搭的年轻都市人群 |

### 核心分析

| 字段 | 说明 | 格式要求 |
|------|------|---------|
| 人性需求 | 广告触达的人性需求类别 | `[需求类别]：[具体需求]`，多个用分号分隔 |
| 消费者洞察 | 消费者的深层动机与痛点 | 一句话，50-100 字，包含痛点 + 渴望 |
| 创意概念 | 广告的核心创意主题 | `[主题语]（中文阐释）` |
| 创意手法 | 创意的表现手法和技巧 | `广告型创意——>[具体手法]`，多个用分号分隔 |

### 创意内容解读

| 字段 | 说明 |
|------|------|
| 内容概述 | 100-200 字概括广告整体内容和核心表达 |
| 内容详情 | 按时间顺序详细描述各分镜内容，包含关键画面、文案、时长等 |

### 标注格式

```
[需求类别]：[具体需求 1]、[具体需求 2]；[需求类别]：[具体需求]
```

**示例：**
- `生理需求：舒适、运动；情感需求：亲人理解`
- `自我实现：追寻自我、个性`
- `生理需求：保暖、舒适；审美需求：时尚美`
- `安全需求：身体健康、金钱安全`
- `认知需求：好奇、效率`

### 注意事项

1. **严格使用标准子类别名称** - 不得使用近义词或自创名称
2. **每个广告标注 2-4 个子类别** - 聚焦核心需求，避免罗列
3. **区分主次需求** - 第一个标注的为主要需求

## 消费者洞察撰写规范

### 标准结构

```
[目标人群/场景描述] + [痛点/现状] + [渴望/期待]
```

### 人称选择

- **第一人称**："我渴望..."、"我想要..."（更有代入感）
- **第三人称**："现代都市人..."、"职场女性..."（更客观）

### 优秀案例

```
✅ "现代都市人生活节奏快且场景多变，我渴望拥有一条既具备牛仔裤的时尚外观，又能像运动裤一样舒适，能够适应从工作、运动到睡眠全天候各种场景的裤子。"

✅ "现代女性在一天中需要在不同角色之间频繁切换，不仅需要外在的得体，更需要内在的舒适支撑，以从容接纳并享受每一个不同侧面的'我'。"

✅ "我向往户外的自然与自由，但不想被沉重的装备所束缚，因此，我渴望轻盈保暖且不占收纳空间的衣物，以便更轻松地享受户外生活。"

❌ "人们想要舒适的衣服。"（过于简单，无洞察深度）

❌ "消费者追求高品质生活，希望产品能满足他们的各种需求。"（空洞，无法指导创意）
```

## 创意概念标注规范

### 命名格式

```
[核心主题语]（中文阐释/副标题）
```

### 创意概念类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 产品功能型 | 直接传达核心卖点 | "24h JEANS"、"Ultra Light Down" |
| 情感共鸣型 | 触动情感需求 | "不同的我，都是我"、"年年有你" |
| 意象隐喻型 | 用意象表达感受 | "漫步云端"、"DENIM MOVES FORWARD" |
| 对比冲突型 | 制造反差记忆点 | "COMPACT, IMPACT" |
| 拟人趣味型 | 增加趣味性 | "再见，肉肉酱" |

### 优秀案例

```
✅ "いろんなわたしが、わたしです"（不同的我，都是我）
✅ "24h JEANS"（全天候舒适，时刻相伴）
✅ "DENIM MOVES FORWARD."（丹宁，不断进化）
✅ "COMPACT, IMPACT"（小巧，震撼）
✅ "漫步云端"（Walking on Clouds）
```

## 标注流程

1. **观看广告** - 完整观看 2-3 遍，记录关键画面和文案
2. **提取基础信息** - 品牌、产品、卖点、目标人群
3. **识别人性需求** - 分析广告触达的需求类别
4. **提炼消费者洞察** - 用一句话表达深层动机
5. **总结创意概念** - 提炼核心创意主题
6. **标注创意手法** - 记录使用的创意技巧
7. **撰写内容解读** - 详细描述广告内容
