# 人性需求洞察技能

将客户 Brief 转化为结构化的人性需求图谱、消费者洞察与创意概念。

## 核心能力

本技能基于大量真实广告案例标注数据训练，能够：

1. **精准识别人性需求** - 从 Brief 中提取 7 大需求类别（生理、安全、情感、尊重、认知、审美、自我实现）
2. **深度消费者洞察** - 挖掘消费者深层动机与痛点，形成可执行的洞察陈述
3. **创意概念生成** - 产出与人性需求强关联的创意主题与执行方向

## 触发词

- "人性需求"、"消费者洞察"、"创意概念"
- "分析这个 Brief"、"帮我提炼洞察"
- "消费者想要什么"、"这个广告的人性需求是什么"
- "创意方向"、"创意主题"
- "消费者痛点"、"用户洞察"

## 消费者洞察撰写规范

### 标准格式

```
[目标人群描述] + [痛点/现状] + [渴望/期待]
```

### 优秀案例

1. **优衣库牛仔裤**
   > "现代都市人生活节奏快且场景多变，我渴望拥有一条既具备牛仔裤的时尚外观，又能像运动裤一样舒适，能够适应从工作、运动到睡眠全天候各种场景的裤子。"

2. **优衣库 Bratop**
   > "现代女性在一天中需要在不同角色之间频繁切换，不仅需要外在的得体，更需要内在的舒适支撑，以从容接纳并享受每一个不同侧面的'我'。"

3. **RIZAP 健身**
   > "女性想获得理想的迷人身材和自信，但身体上顽固的赘肉往往是难以摆脱的负担"

4. **优衣库轻羽绒**
   > "我向往户外的自然与自由，但不想被沉重的装备所束缚，因此，我渴望轻盈保暖且不占收纳空间的衣物，以便更轻松地享受户外生活。"

### 撰写要点

- ✅ 使用第一人称"我"或明确的"现代都市人/职场男性/年轻女性"等
- ✅ 一句话表达，简洁有力
- ✅ 包含痛点 + 渴望的对比结构
- ✅ 与产品核心卖点形成呼应
- ❌ 避免空洞的形容词堆砌
- ❌ 避免过于抽象无法执行

### 消费者洞察提炼公式（2026-03-24 新增 · 基于灵感库案例学习）

**标准公式（四要素）：**
```
[目标人群描述（具体、有画面感）] + [痛点/现状（情感化、场景化）] + [渴望/期待（深层心理需求）] + [产品角色（隐喻化、象征化）]
```

**检查清单：**
| 要素 | 要求 | 错误示例 | 正确示例 |
|------|------|----------|----------|
| **人群描述** | 具体、有画面感 | ❌ "消费者" | ✅ "身处职场漩涡的现代精英" |
| **痛点** | 情感化、场景化 | ❌ "压力大" | ✅ "无休止的打扰与琐事" |
| **渴望** | 深层心理需求 | ❌ "想要放松" | ✅ "找回自我掌控感" |
| **产品角色** | 隐喻化、象征化 | ❌ "提供舒适" | ✅ "通往宁静的屏障" |
| **长度** | 80-150 字 | 过短或过长 | 适中 |

**优秀案例（灵感库经典案例）：**

1. **哈雷戴维森**
   > "在枯燥压抑的现代生活中，人们内心深处总有着对自然、对本能欲望的原始渴望，哈雷不仅仅是代步工具，更是释放本能、逃离平庸、追求自我绝对自由的图腾。"
   
   **拆解：** 人群（枯燥压抑的现代生活人群）+ 痛点（生活压抑、本能被束缚）+ 渴望（释放本能、追求自由）+ 产品角色（图腾）

2. **日产楼兰**
   > "对于身处职场漩涡的现代精英而言，办公室里的每一个角落都充满了无休止的打扰与琐事，他们急需一个能彻底隔绝噪音、找回自我掌控感的私人空间，而座驾就是这道通往宁静的唯一屏障。"
   
   **拆解：** 人群（职场精英）+ 痛点（无休止的打扰）+ 渴望（找回掌控感）+ 产品角色（屏障）

3. **多芬滋养秘笈**
   > "消费者渴望世界各地流传已久的天然美容秘方，但极其繁琐的取材过程与跨国旅行让这种仪式感变得遥不可及；多芬洞察到这种'理想仪式与现实难度'的冲突，将全球美容智慧浓缩于一瓶，化繁为简。"
   
   **拆解：** 人群（追求天然护肤的女性）+ 痛点（理想与现实的冲突）+ 渴望（享受全球美容仪式）+ 产品角色（化繁为简）

## ⏸️ 创意概念确认流程规范（2026-03-25 新增）

**核心原则：** 输出创意概念后**必须立即停止**，等待用户确认 preferred direction 后才能继续细化方案

### 执行流程

```
1. 输出候选创意概念（3-5 组）
   ↓
2. ⏸️ 立即停止，标注等待确认提示语
   ↓
3. 等待用户明确确认 preferred concept
   ↓
4. 用户确认后，继续细化方案（KV/TVC/传播策略等）
```

### 等待确认提示语规范

**必须包含的要素：**
- ✅ 明确标注"⏸️ 等待确认"或类似提示
- ✅ 说明下一步动作："确认后我将继续细化方案"
- ✅ 列出可选操作："可以单选、多选、或提出修改意见"

**示例提示语：**
```markdown
**⏸️ 等待确认：**

请告诉我你 preferred 的创意概念方向（可以单选、多选、或提出修改意见），确认后我将继续细化方案。
```

### 禁止行为

| 禁止行为 | 错误示例 | 正确做法 |
|----------|----------|----------|
| **跳过确认直接输出完整方案** | 输出创意概念后继续输出 KV、TVC、传播规划等 | 创意概念输出后**立即停止** |
| **在用户确认前输出执行层面内容** | 输出创意概念后继续输出预算分配、渠道策略等 | 等待确认后再输出 |
| **未标注等待提示语** | 输出创意概念后无任何提示，直接结束 | 必须标注"⏸️ 等待确认" |
| **提示语模糊** | "请确认"（未说明确认什么） | "请确认 preferred concept，确认后我将继续细化方案" |

### 违规案例（2026-03-25 记录）

**错误：** 输出 5 组创意概念后，未等待确认直接输出完整方案（含创意落地规划、传播策略、KPI 等）

**正确：** 输出创意概念后**立即停止**，明确标注等待提示语，**必须等待用户明确确认**后才能继续

本规范适用于以下场景：

## 🎯 创意概念生成五步推导法（2026-03-27 新增 · 基于 6600 案例深度学习）

**来源：** 灵感库 6600 案例全量深度学习  
**重要性：** ⭐⭐⭐⭐⭐ 核心方法论  
**适用范围：** 所有创意概念生成场景

### 五步推导流程

```
产品特性 → 人性需求 → 消费者洞察 → 创意概念 → 验证优化
   ↓           ↓           ↓           ↓          ↓
 功能层      心理层      转化层      表达层      质量层
```

---

### 第一步：产品特性分析（功能层）

**分析工具：产品特性三维拆解表**

| 维度 | 分析内容 | 关键问题 | 输出 |
|------|----------|----------|------|
| **功能特性** | 产品核心功能、技术参数、使用场景 | 产品能做什么？解决什么问题？ | 功能清单 |
| **情感特性** | 产品带来的感受、体验、身份象征 | 用户使用后感觉如何？ | 情感关键词 |
| **社会特性** | 产品代表的价值观、生活方式、群体归属 | 产品代表什么样的人？ | 价值标签 |

**实战案例：三星 Galaxy S23**

| 维度 | 分析结果 |
|------|----------|
| **功能特性** | 隐私保护功能、安全支付、数据加密 |
| **情感特性** | 安心、掌控感、无焦虑 |
| **社会特性** | 数字化时代的智者、注重隐私的精英 |

**输出检查清单：**
- [ ] 是否列出 3-5 个核心功能特性？
- [ ] 是否提炼 2-3 个情感关键词？
- [ ] 是否识别 1-2 个社会价值标签？

---

### 第二步：人性需求匹配（心理层）

**分析工具：人性需求匹配矩阵（基于 6600 案例数据）**

| 产品特性类型 | 首选人性需求 | 次选人性需求 | 匹配逻辑 |
|-------------|-------------|-------------|----------|
| **功能型**（便捷/效率/安全） | 便捷、效率、金钱安全 | 信赖、舒适 | 解决实际问题 |
| **体验型**（愉悦/舒适/味道） | 愉悦、舒适、乐趣 | 味觉、沉浸 | 感官满足 |
| **美学型**（时尚/艺术/个性） | 时尚美、艺术美、个性 | 被认同、形象 | 视觉/身份表达 |
| **精神型**（超越/追寻自我） | 发挥潜能、追寻自我、超越 | 成就、自由 | 自我实现 |

**实战案例：三星 Galaxy S23**

| 产品特性 | 匹配人性需求 | 匹配理由 |
|----------|-------------|----------|
| 隐私保护功能 | **金钱安全**（安全需求） | 隐私泄露可能导致财产损失 |
| 安全支付 | **信赖**（安全需求） | 对支付系统的信任 |

**输出检查清单：**
- [ ] 是否匹配了 1-2 个核心人性需求？
- [ ] 是否属于 7 大标准分类中的子类别？
- [ ] 匹配理由是否清晰有逻辑？

### 第三步：消费者洞察撰写（转化层）

**分析工具：洞察撰写四要素公式**

```
[目标人群描述] + [痛点/现状] + [渴望/期待] + [产品角色隐喻]
```

**四种洞察模板（根据人性需求层次选择）：**

#### 模板 1：表面痛点型（适用于生理/安全需求）
```
[人群] 在 [场景] 中常遇到 [具体问题]，他们希望 [简单解决方案]。

例：现代都市人在通勤途中常因手机没电而焦虑，他们希望有一个能随时随地快速充电的解决方案。
```

#### 模板 2：深层渴望型（适用于情感/尊重需求）⭐ 推荐
```
[人群] 在 [场景] 中感到 [情感痛点]，他们渴望 [深层心理满足]，而 [产品] 正是 [角色隐喻]。

例：身处职场漩涡的现代精英，在办公室的角落里感到无休止的打扰与琐事，他们急需一个能彻底隔绝噪音、找回自我掌控感的私人空间，而座驾就是这道通往宁静的唯一屏障。
```

#### 模板 3：价值观冲突型（适用于自我实现需求）⭐ 传播力最强
```
真正的 [价值概念] 不仅在于 [表面价值]，更在于 [深层价值]。当 [冲突情境] 时，[人群] 更愿意 [价值选择]。

例：真正的财富不仅在于金钱的积累，更在于代代相传的正确价值观与情感记忆。当金钱利益与人格原则冲突时，人们更愿意信任那些与自己拥有相同精神内核的伙伴。
```

#### 模板 4：数字化焦虑型（适用于认知需求）⭐ 新增
```
在 [数字化场景] 中，用户常因 [具体问题] 产生 [焦虑类型]，他们需要一种 [解决方案特征] 来 [情感目标]。

例：在数字化日常中，用户常因疏忽（如忘记退出公共账号、误点 APP 权限等）产生"隐私焦虑"，他们需要一种简单直观且能即时纠错的安全方案来重拾掌控感。
```

**输出检查清单：**
- [ ] 是否有具体人群/场景描述？
- [ ] 是否有清晰的痛点表达？
- [ ] 是否有深层渴望/期待？
- [ ] 是否有产品角色隐喻？
- [ ] 长度是否在 80-150 字？
- [ ] 是否使用第一人称或明确人群？

## 🎓 五大核心定律（2026-03-27 新增 · 基于 6600 案例）

### 定律 1：人性需求层次定律
```
生理/安全需求 → 功能型手法（产品就是解药、产品示范）
情感/尊重需求 → 情感型手法（价值认同、感同身受）
认知/审美需求 → 艺术型手法（意象化、创造象征符号）
自我实现需求 → 精神型手法（成长与逆袭、价值认同）
```

### 定律 2：洞察深度 - 概念高度正相关
```
表面痛点洞察 → 功能型概念（传播力弱）
深层渴望洞察 → 情感型概念（传播力中）
价值观冲突洞察 → 精神型概念（传播力强）
```

### 定律 3：手法 - 需求匹配度定律
```
高匹配度（如便捷→产品就是解药）→ 创意有效性高
低匹配度（如便捷→意象化）→ 创意有效性低
```

### 定律 4：三要素一致性定律
```
人性需求 + 消费者洞察 + 创意概念 + 创意手法
    ↓
四者高度一致 → 获奖概率高
四者不一致 → 入库都难
```

### 定律 5：视觉优先定律（非获奖案例特有）
```
非获奖案例中，意象化使用率 21.9%（获奖案例仅 11.6%）
→ 视觉美感是灵感库入库的第一道门槛
→ 但社会价值是获奖的第二道门槛
```

## 💬 群聊共享文件写入规则（2026-04-01）

> ✅ **必须主动调用**写入脚本，在输出后**立即执行**

---

### 核心原则

当你在飞书群聊中发送消息时，**必须主动执行写入脚本**，将内容追加到群聊共享文件。

**这不是可选的！** 每次关键输出后，必须立即调用写入脚本。

---

### 触发条件

**必须写入的内容：**
- ✅ 关键输出（人性需求分析、创意概念、品牌策略等）
- ✅ 用户确认的决策点
- ✅ 用户指令/Brief
- ✅ 用户反馈/纠正
- ✅ 超过 30 字的专业回复

**不写入的内容：**
- ❌ 闲聊、寒暄
- ❌ 简单确认（收到、好的、明白）
- ❌ NO_REPLY
- ❌ /new 命令

---

### 写入方式（必须执行）

**在输出飞书消息后，立即调用内置 `write` tool：**

```python
from datetime import datetime

timestamp = datetime.now().strftime('%Y-%m-%d %H:%M:%S')
content = f"""
---

## [{timestamp}] 人性需求洞察专家（关键输出）

### 人性需求分析报告

**核心洞察：**...

**元数据：**
- 写入时间戳：{timestamp}
- Agent: 人性需求洞察专家
"""

write(
    path="<工作区>/group-chat-log.md",
    content=content,
    append=True
)
```

**参数说明：**
- `path` - 共享文件路径
- `content` - 要写入的内容（Markdown 格式）
- `append=True` - 追加模式（不覆盖原文件）

**优点：**

### 读取共享文件（可选）

**需要参考历史对话时，调用内置 `read` tool：**

```python
# 读取完整文件
content = read(
    path="<工作区>/group-chat-log.md"
)

# 读取最近 100 行
content = read(
    path="<工作区>/group-chat-log.md",
    offset=1,
    limit=100
)
```

**参数说明：**
- `path` - 共享文件路径
- `offset` - 起始行号（1-indexed，默认 1）
- `limit` - 读取行数（默认全部）

**使用场景：**
- ✅ 需要参考之前的讨论历史
- ✅ 需要确认用户之前的决策
- ✅ 需要了解项目完整背景

**注意：** 读取操作是可选的，根据实际需要调用。

### 📸 多媒体文件支持

**写入时包含多媒体链接：**

```python
from datetime import datetime

timestamp = datetime.now().strftime('%Y-%m-%d %H:%M:%S')
content = f"""
---

## [{timestamp}] 人性需求洞察专家（关键输出）

### 人性需求分析报告

**核心洞察：**...

### 视觉参考

![](https://oss.example.com/image1.png)
![](https://oss.example.com/image2.png)

### 视频参考

[视频演示](https://oss.example.com/demo.mp4)

**元数据：**
- 写入时间戳：{timestamp}
- Agent: 人性需求洞察专家
"""

write(
    path="<工作区>/group-chat-log-xxx.md",
    content=content,
    append=True
)
```

**多媒体格式支持：**
- ✅ **图片：** `![](https://xxx.png)` - Markdown 图片语法
- ✅ **视频：** `[视频](https://xxx.mp4)` - Markdown 链接
- ✅ **音频：** `[音频](https://xxx.mp3)` - Markdown 链接
- ✅ **HTML 视频：** `<video src="https://xxx.mp4" controls></video>`

**读取时自动包含多媒体链接：**

```python
# 读取完整内容（包含所有多媒体链接）
content = read(
    path="<工作区>/group-chat-log-xxx.md"
)

# 提取所有图片链接
import re
image_urls = re.findall(r'!\[\]\((https?://[^)]+)\)', content)

# 提取所有视频链接
video_urls = re.findall(r'\[视频\]\((https?://[^)]+)\)', content)
```

**优点：**
- ✅ 多媒体链接以文本形式存储，无需特殊处理
- ✅ 读取时自动包含所有链接
- ✅ 支持 Markdown 和 HTML 格式
- ✅ 链接永久有效（OSS/CDN 存储）

### 写入锁机制

- 获取锁 → 追加写入 → 释放锁
- 锁超时 5s 自动释放
- 写入失败自动重试（最多 3 次）
- 错误记录到 `<工作区>/logs/write-errors.log`
