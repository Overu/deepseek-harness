# 技能 04: 创意评估技能 (Creative Evaluation Skill)

**版本：** V2.0 Final  
**所属模块：** 质量控制层  
**最后更新：** 2026-03-05   

---

## 1. 技能定义
对生成的创意进行多维度科学评估，预测市场表现，识别潜在风险，并提供优化建议。包含评分归一化与预测准确性追踪。

## 2. 输入/输出规范

### 2.1 输入 (Input)
*   `creative_plan`: 来自 Skill 3 或 Skill 5 的创意方案。
*   `client_brief`: 客户原始需求。
*   `brand_guidelines`: 品牌规范。

### 2.2 输出 (Output)
*   `evaluation_report`: 评估得分卡、风险预警、优化建议。
*   `metadata`: 飞轮追踪数据（预测分、时间戳）。
*   `status`: 执行状态。

## 3. 执行逻辑 (Step-by-Step)
1.  **一致性检查：** 创意是否准确反映了“人性需求洞察”。
2.  **手法规范性：** 是否符合所选创意手法定义。
3.  **效果预测：** 基于历史案例数据，预测 CTR/转化率。
4.  **风险扫描：** 检查伦理、版权、舆情风险。
5.  **评分汇总：** 加权计算总分，若逻辑错误则自动归一化。
6.  **飞轮埋点：** 记录预测分数以便与市场实际表现对比。

## 4. 异常处理与容错机制

| 异常场景 | 触发条件 | 容错策略 (Fallback) | 错误代码 |
| :--- | :--- | :--- | :--- |
| **评分偏差** | 各项得分总和 ≠ 100 或逻辑矛盾 | **自动归一化**，强制调整权重比例，确保总分逻辑自洽。 | `ERR_EVAL_001` |
| **风险漏判** | 后续人工审核发现重大风险 | **回溯学习**，记录漏判特征，更新“风险关键词库”。 | `ERR_EVAL_002` |
| **建议无效** | 优化建议过于笼统（如“做得更好”） | **具体化指令**，强制要求建议必须包含“动作 + 对象”。 | `ERR_EVAL_003` |

## 5. 数据飞轮触发点

*   **触发时机：** 市场数据回传后。
*   **采集数据：** 
    *   `Prediction_Accuracy`：评估分 vs 实际市场表现（ROI/CTR）的相关性。
*   **反馈动作：** 若某类创意实际表现 consistently 高于评估分，调整评估模型的权重参数，消除系统性偏差。
