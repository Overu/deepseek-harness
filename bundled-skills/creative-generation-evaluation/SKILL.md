## 🧠 案例学习核心洞察（2026-03-24 新增）

### 消费者洞察提炼公式

**标准公式：**
```
[目标人群描述（具体、有画面感）] + [痛点/现状（情感化、场景化）] + [渴望/期待（深层心理需求）] + [产品角色（隐喻化、象征化）]
```

**优秀案例：**
> "在枯燥压抑的现代生活中，人们内心深处总有着对自然、对本能欲望的原始渴望，哈雷不仅仅是代步工具，更是释放本能、逃离平庸、追求自我绝对自由的图腾。"

**拆解：**
- 人群：枯燥压抑的现代生活人群
- 痛点：生活压抑、本能被束缚
- 渴望：释放本能、逃离平庸、追求自由
- 产品角色：图腾/响应方式

### 创意概念 4 类型

| 类型 | 特征 | 案例 | 适用场景 |
|------|------|------|----------|
| **态度型** | 品牌价值观表达 | "BE YOUR OWN BOSS" | 奢侈品、高端品牌 |
| **情感型** | 情感共鸣点 | "舒服，只有自己知道" | 女性品牌、生活方式 |
| **功能型** | 产品核心卖点 | "DONATE STUFF. CREATE JOBS." | 公益、功能导向产品 |
| **文化型** | 文化符号/仪式感 | "THE DANISH WAY" | 有历史积淀的品牌 |

### 创意手法选择决策树

```
产品功能明确？
  ├─ YES → 广告型 - 消费者投射（产品示范/产品就是解药）
  └─ NO → 情感导向？
           ├─ YES → 电影型 - 感情羁绊/成长与逆袭
           └─ NO → 品牌升级？
                    ├─ YES → 广告型 - 艺术化（意象化）
                    └─ NO → 差异化竞争？
                             ├─ YES → 广告型 - 夸张（极致的夸张/比喻）
                             └─ NO → 新闻型 - 品牌主张/人性洞察
```

### 创意阐述三段式结构

```
1. 核心策略说明（1-2 句）- 给手法起专业名称
2. 视觉/叙事手法描述（2-3 句）- 具体执行细节
3. 人性需求连接（1-2 句）- 如何满足深层需求
```

**优秀案例（哈雷戴维森）：**
> "这组作品采用了典型的'心理地图'式表现手法。它没有直接展示驾驶的快感，而是将'渴望'视觉化。插画中充满了拟人化的生物、变异的景观和丰富的色彩，营造出一种摇滚式的、迷幻的氛围，精准契合了哈雷品牌狂放不羁、挑战常规的文化内核。它传达出：当内心某种渴望萌发时，哈雷是唯一的响应方式。"

### 视觉表现手法库

| 手法 | 案例 | 执行要点 |
|------|------|----------|
| **微缩艺术** | Goodwill"捐赠物品，创造职业" | 巨大物品 + 微型人物，比例反差 |
| **超现实主义插画** | 哈雷戴维森"当召唤来临时" | 拟人化生物、变异景观、迷幻色彩 |
| **视觉蒙太奇** | PencilWings"铅笔 + 桥梁/灯塔/巨轮" | 核心符号与宏大意象融合 |
| **场景错位** | 日产楼兰"办公室搬到高速公路" | 将日常场景置于异常环境 |
| **长条插画叙事** | 多芬滋养秘笈"全球远征" | 装饰感插画，讲述完整故事 |

### 叙事结构库

| 结构 | 案例 | 适用场景 |
|------|------|----------|
| **多线叙事汇聚** | 7or9"舒服的答案"（三位女性） | 展现不同人群的共同体验 |
| **时间跨度蒙太奇** | Abante 财富管理"从古至今" | 展现品牌历史厚度 |
| **问题→解决** | The Entertainer"优惠=庆祝" | 功能导向产品 |
| **情感递进** | Bourbon Alfort"温情传递" | 情感导向品牌 |

## 🔧 执行流程

```
1️⃣ 加载输入 → 2️⃣ 创意生成 → 3️⃣ 合规自查 → 
4️⃣ 质量评估 → 5️⃣ 输出报告
```

### 步骤详解

#### 1️⃣ 风格锁定
- 根据 `creativeType` 加载对应创意手法模板
- **Advertising (广告型):** 强调产品卖点、CTA 明确、节奏快
- **Cinematic (电影型):** 注重情感叙事、视觉美学、故事性
- **News (新闻型):** 信息密度高、权威感、数据支撑

#### 2️⃣ 创意生成
- 将人性需求洞察转化为具体情节/场景
- 参考案例风格但不抄袭
- 生成完整脚本/文案 + 视觉 Prompt

#### 3️⃣ 合规自查
- 检测违禁词 (最、第一、国家级、100% 等)
- 检查敏感内容 (政治、宗教、色情、暴力)
- 验证品牌调性一致性
- **触发风险时:** 自动重写，最多重试 3 次

#### 4️⃣ 质量评估
- **需求匹配度 (30%):** 创意是否准确反映人性洞察
- **手法规范性 (30%):** 是否符合所选创意手法定义
- **创新性 (20%):** 创意新颖度、差异化程度
- **合规性 (20%):** 法律风险、品牌安全风险
- 总分低于 80 分必须给出重构建议

#### 5️⃣ 非典型创新 (可选)
- 当 `generateNonTypical=true` 时触发
- 应用扰动规则 (错位匹配/语调逆向/逻辑反转/视角切换)
- 品牌安全红线检查
- 提供 A/B 测试建议

## ⚠️ 异常处理

| 异常场景 | 触发条件 | 容错策略 | 错误代码 |
|----------|----------|----------|----------|
| **合规风险** | 检测到违禁词/敏感内容 | 自动重写，安全模式替换高风险词汇，最多 3 次 | `ERR_GEN_001` |
| **内容空洞** | 生成内容长度低于阈值 | 增强指令，追加"细节扩充"要求 | `ERR_GEN_003` |
| **评分偏差** | 各项得分逻辑矛盾 | 自动归一化，调整权重比例 | `ERR_EVAL_001` |
| **品牌风险** | 非典型创意违背品牌核心价值 | 软性扰动，仅调整语调/视角 | `ERR_INNO_001` |

```markdown
**核心洞察：** 每个女性都在用双脚寻找属于自己的"舒服"答案

**创意主张：** "舒服，只有自己知道"

**人性需求连接：** 
- 生理需求：舒适、愉悦
- 自我实现：追寻自我、自由
```

### 消费者洞察撰写规范（2026-03-24 新增 · 基于 50 案例验证）

**标准公式（三模式灵活选择）：**

**模式 A：四要素完整（36% 案例使用）**
- **适用：** 高端品牌、复杂产品
- **长度：** 90-100 字
- **公式：** `[目标人群描述] + [痛点/现状] + [渴望/期待] + [产品角色]`
- **示例：** "消费者在享受高端餐厅、酒吧或 SPA 服务后，买单时的昂贵消费往往会冲淡先前的愉悦。The Entertainer 洞察到'省钱'本身就是一种极大的情绪价值，通过将优惠与庆祝活动挂钩，将沉重的账单转化为狂欢的惊喜。"（98 字）

**模式 B：三要素（44% 案例使用）**
- **适用：** 大多数情况
- **长度：** 70-80 字
- **公式：** `[目标人群] 渴望 [渴望/期待]，但 [痛点/现状] 让他们无法实现`
- **示例：** "人们常常会被一些微不足道、甚至有些荒诞的琐事困扰并陷入过度思考。通过咀嚼具有韧性的 Twizzlers，能给大脑一个缓冲空间，在'嚼一嚼'中化解那些无谓的内心冲突。"（75 字）

**模式 C：场景驱动（20% 案例使用）**
- **适用：** 快消品、情感导向
- **长度：** 55-65 字
- **公式：** `在 [具体场景] 中，[人群行为]，他们真正需要的是 [情感需求]`
- **示例：** "在极具压抑感的职场社交中，人们往往因为担忧社交距离和礼仪而不敢表达真实想法。口气清新不仅是生理舒适，更是卸下伪装、坦诚沟通的勇气来源。"（62 字）

**检查清单：**
- [ ] 人群描述是否具体？（❌ "消费者"→✅"身处职场漩涡的现代精英"）
- [ ] 痛点是否场景化？（❌ "压力大"→✅"无休止的打扰与琐事"）
- [ ] 渴望是否深层？（❌ "想要放松"→✅"找回自我掌控感"）
- [ ] 产品角色是否隐喻化？（❌ "提供舒适"→✅"通往宁静的屏障"）
- [ ] 长度是否在 55-100 字之间？（基于 50 案例验证）
- [ ] 是否选择了适合的模式（A/B/C）？

**优秀示例（四要素完整）：**
> "对于身处职场漩涡的现代精英而言，办公室里的每一个角落都充满了无休止的打扰与琐事，他们急需一个能彻底隔绝噪音、找回自我掌控感的私人空间，而座驾就是这道通往宁静的唯一屏障。"（88 字）

## ⏸️ 创意概念确认流程规范（2026-03-25 新增）

**核心原则：** 输出创意概念后**必须立即停止**，等待用户确认 preferred direction 后才能继续细化方案

### 执行流程

```
1. 输出候选创意概念（3-5 组）
   ↓
2. ⏸️ 立即停止，标注等待确认提示语
   ↓
3. 等待用户明确确认 preferred concept
   ↓
4. 用户确认后，继续细化方案（视觉表现/叙事结构/TVC 脚本等）
```

### 等待确认提示语规范

**必须包含的要素：**
- ✅ 明确标注"⏸️ 等待确认"或类似提示
- ✅ 说明下一步动作："确认后我将继续细化视觉表现和叙事结构"
- ✅ 列出可选操作："可以单选、多选、或提出修改意见"

**示例提示语：**
```markdown
**⏸️ 等待确认：**

请告诉我你 preferred 的创意概念方向（可以单选、多选、或提出修改意见），确认后我将继续细化视觉表现和叙事结构。
```

### 禁止行为

| 禁止行为 | 错误示例 | 正确做法 |
|----------|----------|----------|
| **跳过确认直接输出完整方案** | 输出创意概念后继续输出视觉 Prompt、TVC 脚本等 | 创意概念输出后**立即停止** |
| **在用户确认前输出执行层面内容** | 输出创意概念后继续输出分镜、KV 设计等 | 等待确认后再输出 |
| **未标注等待提示语** | 输出创意概念后无任何提示，直接结束 | 必须标注"⏸️ 等待确认" |
| **提示语模糊** | "请确认"（未说明确认什么） | "请确认 preferred concept，确认后我将继续细化" |

### 违规案例（2026-03-25 记录）

**错误：** 输出 5 组创意概念后，未等待确认直接输出完整方案（含视觉表现、叙事结构、TVC 脚本等）

**正确：** 输出创意概念后**立即停止**，明确标注等待提示语，**必须等待用户明确确认**后才能继续

## 🎓 五大核心定律（2026-03-27 新增）

### 定律 1：人性需求层次定律
```

情感/尊重需求 → 情感型手法
```

```
表面痛点洞察 → 功能型概念（传播力弱）
```

```
高匹配度 → 创意有效性高
```

### 定律 4：三要素一致性定律

```
人性需求 + 消费者洞察 + 创意概念 + 创意手法
```

```
意象化使用率 21.9%（非获奖案例）
```

## 💬 群聊共享文件写入规则（2026-04-01）

> ✅ **必须主动调用**写入脚本，在输出后**立即执行**

---

### 核心原则

当你在飞书群聊中发送消息时，**必须主动执行写入脚本**，将内容追加到群聊共享文件。

**这不是可选的！** 每次关键输出后，必须立即调用写入脚本。

---

### 触发条件

**必须写入的内容：**
- ✅ 关键输出（创意概念方案、TVC 脚本、Slogan 等）
- ✅ 用户确认的决策点
- ✅ 用户指令/Brief
- ✅ 用户反馈/纠正
- ✅ 超过 30 字的专业回复

**不写入的内容：**
- ❌ 闲聊、寒暄
- ❌ 简单确认（收到、好的、明白）
- ❌ NO_REPLY
- ❌ /new 命令

---

### 写入方式（必须执行）

**在输出飞书消息后，立即调用内置 `write` tool：**

```python
from datetime import datetime

timestamp = datetime.now().strftime('%Y-%m-%d %H:%M:%S')
content = f"""
---

## [{timestamp}] 创意内容专家（关键输出）

### 创意概念方案

**方向 A：**...

**元数据：**
- 写入时间戳：{timestamp}
- Agent: 创意内容专家
"""

write(
    path="<工作区>/group-chat-log.md",
    content=content,
    append=True
)
```

**参数说明：**
- `path` - 共享文件路径
- `content` - 要写入的内容（Markdown 格式）
- `append=True` - 追加模式（不覆盖原文件）

**优点：**
- ✅ 无需审批（内置 tool）
- ✅ 立即可用
- ✅ 支持追加写入
