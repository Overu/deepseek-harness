# 品牌 / 创意展示：可选设计参考

本参考帮助 SOL 作设计选择，不规定图片数量、图片面积、版式种类、字数、色彩数量或章节页配额。用户品牌规范、业务表达和共享质量合同优先；不能因为未采用某种风格技巧就判废、重排或追加调用。

## 主题与受众

从已有品牌标识、包装、材质、人物、空间和用户参考中识别视觉语言。保留明确要求的品牌资产，不以审美判断擅自替换。现有资料足够时无需追加搜索；确需补图时由 SOL 说明该图承担的阅读任务。

受众决定表达方式：管理层强调结论与行动，消费者强调体验与记忆，研究读者强调证据和解释。无需为证明差异额外制作多稿。

## 可选风格家族

| 家族 | 适用气质 | 色彩、字形与影像参考 |
|---|---|---|
| F1 纸墨东方 | 文化、器物、空间、东方文旅 | 纸灰米白、炭墨、木棕与苔绿；衬线字；晨雾、材料细节、自然光 |
| F2 深空精密 | 科技、汽车、硬件、能源 | 深灰或明亮技术底；无衬线、等宽指标；结构、尺度、工艺光线 |
| F3 暖土手作 | 茶咖、零售、自然人文 | 暖米白、深棕、食材色；触感纹理；手部动作、蒸汽与静物 |
| F4 澄澈商务 | 企业、平台、路演 | 明亮底色、品牌色、干净网格；判断句标题与清晰业务数据 |
| F5 高张力表达 | 时尚、创意消费、潮流文化 | 高对比、胶片颗粒、鲜明字形；直闪、街头与动作场景 |

可以混合适用手法，不必固定选一种。高饱和、渐变、卡片、均分构图、彩色标题不是禁用项；使用理由是帮助阅读或符合品牌，而不是填充装饰。统一参数与视觉语言优先于逐页求异。

## 页面构图工具箱

按内容选择，不设使用次数：
- hero-full / hero-object：需要核心视觉时用大画幅产品或场景。
- manifesto-type / metric-poster：文字或业务数字可以成为主视觉，无须强加图片。
- split-evidence / comparison-stage / matrix-with-proof：结论、证据、对照或矩阵；系列对照页可以连续使用相同网格。
- timeline-ribbon / process-strip / decision-roadmap：时间、流程、决策关系；只画真实存在的阶段与关系。
- material-board / object-catalog / detail-zoom：多图确有信息价值时展示材质、目录或细节。
- portrait-quote / collage-field：人物观点或编辑拼贴，保留引用含义与主体可识别性。
- chapter-index：仅在叙事需要时设置分节；字号、配图和编号不设固定模式。

可按底色、图形、影像、文字、页码等层次组织，但不是每页必须包含所有层。纯色底与无图页都可成立；不要求固定装饰件数。

## 文字、数字和版式

- 文案通顺、准确、完整；不为了留白或密度目标删除条件、扩写或凑字。
- 层级通过位置、字号、字重与间距建立，不规定 1.8 倍字号比例。使用预检解析出的字体，不强求不同字族。
- 幽灵巨字、旋转文字和双语微标签是可选技巧；业务 KPI 不是装饰，不能只因数字很大就缩小。
- 必须让有效文字可读，避免实质遮挡和裁切。不能靠缩小文本框隐藏未解决的字高问题。
- 没有真实双语内容就不添加英文。章节序号和页码按实际需要安排。
- 留白、底部基线和间距服务于整稿秩序，没有统一百分比门槛。

## 图片策略

图片数量可以为零。优先现有素材；核心产品图、Logo 和证据图可按需重复，重复提醒不强迫换图或生图。展示同图的不同裁切时，在蓝图中用不同实例 id 表明计划，保留同一 src/asset_id 身份。

图片存在的理由是解释、证明、识别或营造必要情境。决定新增图时写清具体用途和画面，不因页数或面积配额生成。关键产品信息与图中文字不应被裁掉；实际裁切由 SOL 规划。

拼贴可借用主次比例与共同对齐轴，但不固定张数和面积比。色彩、光线与摄影语言可保持一致；并非所有图都需要加工或转黑白。

## 检查与交付

在既有规划/渲染调用内检查标题叙事、信息完整、阅读顺序与全稿一致性，不新增独立审查调用。
设计偏好与低置信风险记录为 warning，不单独触发修复、审批或占位；实质缺陷按共享规则处理。
视觉质检环节已移除，不生成截图、PDF 或另行视觉通读；交付声明“未进行视觉验收”，不虚称看过成片。
