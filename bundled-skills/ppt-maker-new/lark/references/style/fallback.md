# 兜底设计参考

不匹配具体场景时，按读者任务与用户资料设计。以下都是可选参考，不是图片、卡片、色彩、字数或版式配额；用户要求和共享质量合同优先。

- 可用卡片、开放网格、图表或文字主导布局。按语义分组；同排卡片不必凑相近字数。
- 无图内容页、文字封面或形状封面均可。现有图片足够时不新增图片；不能以“多数页面必须有图”为由生图。
- 产品图与品牌资产可复用；多实例使用唯一 id 并保持素材身份。不同视角或新图需要具体信息价值。
- 数据适合图表时采用原生图表/表格；简单事实也可以文字呈现。不要为了组件化增加无意义结构。
- 文案以通顺、准确、完整为准，不为填满版面扩写，不机械压缩关键事实与条件。
- 网格、留白、层级、对齐和间距保持清晰。均分与不等宽都可用；优先适配内容。
- 字体使用预检解析的可用字族，不强制思源宋体或某个品牌字体。不能把名称别名当作缺字证据。
- 正文通常从 15pt、注释从 11pt 起规划，按阅读场景安排；轻微差异是提示，极小字号或实际不可读仍须处理。
- 配色以用户品牌为先，色彩数量没有固定上限；每种颜色有稳定用途，文字背景有清楚区分。
- 视觉质检环节已移除，不做截图/PDF/视觉模型检查，交付如实注明。只按共享 blocking/warning 分级处理，不按风格偏好阻断。
