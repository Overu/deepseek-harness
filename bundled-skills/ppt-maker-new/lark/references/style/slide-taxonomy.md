# 场景路由与设计参考

用户品牌规范与阅读任务优先。所有风格文件只是可选设计参考，不构成图片数量/面积、版式次数、卡片形状、颜色数量或字数门禁。共享质量合同决定 blocking 与 warning；不能从参考文档增加质量门禁、重试、图片需求或审批。事实、授权、安全与文件完整性约束仍保留。

| 场景 | 阅读任务 | 参考 |
|---|---|---|
| 分析决策 | 比较选项、支撑判断 | [strategy-and-analysis.md](strategy-and-analysis.md) |
| 商业提案 | 理解价值、采取行动 | [business-pitch.md](business-pitch.md) |
| 管理汇报 | 掌握现状、确认行动 | [business-review.md](business-review.md) |
| 学术研究 | 评估方法、证据与贡献 | [academic-research.md](academic-research.md) |
| 教育培训 | 理解、记住、正确应用 | [learning-and-training.md](learning-and-training.md) |
| 技术工程 | 看清结构、依赖与取舍 | [technical-presentation.md](technical-presentation.md) |
| 品牌创意 | 建立认知、记忆与认同 | [brand-storytelling.md](brand-storytelling.md) |
| 其他 | 按实际阅读任务决定 | [fallback.md](fallback.md) |

选择适合的主场景，可结合辅助场景，不强迫套模板。
系列对照页可保持相同网格。卡片、开放网格、图表、文字主导和图片主导均可用，无须证明逐页不同。
图片按价值安排，优先现有资产；无图页合理，产品图片可按需重复。
保留用户提供的来源与限定，不编造出处，也不额外给用户事实添加待核验正文。
自然文案不为密度和留白目标凑字。已解析的可用字体优先，不要求额外搜索 Logo 或安装字体。
用户明确要求逐页保留时保持对应关系；仅参考模板时不自动照搬模板业务文案。
视觉质检环节已移除，不生成截图或PDF；结构检查不等于视觉验收。
