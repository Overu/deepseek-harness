# 商业提案

> 适用口径：本文件指导实际构图与信息表达，不能用“结构合法”代替用户要求的精美设计。数量、行数、填充率等示例不是硬配额；合理系列页与品牌母题可保留，机械文字卡片长段应在规划时改善。资产按表达适配度使用，缺少有用图像时可按用户授权生成；不因已有KV/视频帧多而放弃必要视觉，也不为凑数生图。共享 quality-policy 与 design-quality.md 规定有界改善及非阻断交付。使用常见系统字体，用户 VI/品牌要求优先。用户材料按已确认输入使用，仅真实矛盾需确认；不编造数据、不添加制作或核验免责声明。视觉质检环节已移除；不调用截图、PDF或LibreOffice，设计规划不等于视觉验收。

**路由条件**：商业计划书（BP）、投资路演（VC pitch）、招商加盟说明、创业融资演示、品牌提案、产品发布演示、品牌发布会、主题演讲式发布。

## 场景分型

同属"对外提案 / 发布"性质，但目的与观众不同。生成时先判断分型，再套用差异化指导。

| 维度 | **A · 说服型**（BP / VC / 招商 / 融资 / 提案） | **B · 发布型**（产品发布 / 品牌发布 / 主题演讲） |
|---|---|---|
| 目的 / 观众 | 说服投资人 / 合作方 / 加盟商投入资源 | 向用户 / 媒体 / 公众传递愿景与共鸣 |
| 情绪路径 | 不安 → 希望 → 笃信 → 催动（理性） | 期待 → 惊喜 → 认同 → 向往（感性） |
| 内容密度 | 中高，数据 / 案例 / 对比密集 | 极低，一页一想法 |
| 页面主力 | 结构图、图表、对比表、案例页 | 满版图、巨字宣言、大留白 |
| 竞品对比 / 案例 | 必备且讲透 | 慎用；案例改为"用户故事"叙事 |
| 生图作用 | 章节 / 情绪页使用 | **主力手段**，按信息需要选择，不设逐页配图配额 |

## 核心叙事框架

- **A 型（三段式）**：痛点 → 方案与优势 → 价值。每个优势必须配证据（数据 / 案例 / 对比其一），不许空口宣称。推荐顺序：封面 → 行业现状 → 痛点聚焦 → 方案 overview → 优势拆解 → **竞品对比** → **典型案例** → 合作价值 → 行动号召 → 结尾。
- **B 型（TED 式）**：钩子 → 冲突 → 揭示 → 意义。一页一想法，靠停顿制造张力。推荐顺序：宣言封面 → 场景引入 → 冲突 → **产品揭示（满版视觉）** → 核心特性（每特性独占一页）→ 使用场景 → 愿景 → 结尾。

## 叙事原则

- 叙事线索清晰，情绪有曲线不是平线；核心主张享有"标记"的视觉特权——最重要的一句话页面上必须最突出。
- **A 型**：每个主张必须有证据；数据须真实并注明来源或口径。
- **B 型**：突出一个核心想法；正文行数服从完整语义和可读性，列表、图表与图片均可按内容选择。

## 竞品对比页设计

**A 型必备，B 型慎用**（B 型若用则做极简处理）。

- **先分析我方优势维度**：从价格、效率、技术、服务、覆盖度、交付周期中选出明显领先的 3–5 项作为对比轴。
- **对比具体可解释**：使用素材中已有的数字、案例或明确的定性差异；不为凑量化指标编造数据或要求额外检索。保留来源与原有适用范围。
- **视觉**：并列双栏 / 特性勾选表 / 雷达图 / 评分矩阵；主题色高亮我方，行业平均用中性灰。

## 典型案例页设计

**A 型必备且讲透，B 型改为一张人像大图 + 一句话的用户故事**。

- **一页一案例**，聚焦讲透，不做 logo 拼盘。
- 要素（按重要度排版）：客户身份（logo + 行业 + 规模一行）→ 客户痛点（1 句）→ 我方方案（1–2 句或小流程图）→ **Before/After 成果数据（大数字主视觉）** → 可选客户引言。
- 数量建议 3 页；只有一个强案例时拆成"背景—方案—成果"整节深度案例。

## 用户原声页设计

独立页型，集中呈现真实用户反馈，增加可信度与温度。A / B 两型均可用。

- **气质**：简约、高级、克制，大留白。重心在气泡质感与人像真实感。
- **人像**：生图生成自然光真实感人像（**避免 AI 塑料脸 / 卡通感**），裁**圆形头像**，直径约页面高度 10%–15%；多样化（性别 / 年龄 / 职业气质），A 型 3–5 个组合，B 型 1–2 个特写。
- **气泡**：紧邻头像左或右，**细描边或极淡填充**（绝不用聊天软件默认高饱和蓝绿气泡），气泡尾指向头像，内文不超过 3 行；下方一行小字标身份（姓名 / 职位 / 公司，12pt 浅灰）。
- **错落构图**：多条原声时，头像大小 / 气泡宽度 / 水平位置全部错开，左右交替，文字长短不等长；主题色只在气泡描边、引号或高亮词上做点缀。
- **禁忌**：不用手机 UI 截图当气泡；不做九宫格头像墙；一页不超过 5 条。

## 背景生图引导

**A 型**用于封面 / 章节 / 宣言 / 痛点 / 价值等情绪页；**B 型为主力**，宣言 / 揭示 / 特性页大量满版使用。

- **风格**：高端、克制，电影级摄影感或极简抽象感；B 型可更极致——单一主体、大面积负空间、材质微距、光影戏剧化。
- **色调**：必须与主题色系一致，prompt 明确"以 #XXXXXX 为主色调"或用同色系描述词。
- **叠色**：A 型叠 40%–70% 品牌色或黑色渐变确保标题可读；B 型可让图纯净，允许巨字压图。
- **母题一致**：全篇背景图共用 1–2 种视觉语言，不要每页画风漂移。

## SmartArt 结构图

**主要服务 A 型**（B 型极少用）。从信息关系拆解结构（顺序 / 对比 / 循环 / 因果），优先用结构图呈现而非文字。线条止于节点边缘，禁止文字穿线。纯文字罗列作为兜底。

## 视觉要求

- **字体**：展示型与正文型通过字号、字重、间距分工，默认共用已安装的微软雅黑/苹方，英文 Arial。可用大字和不对称排版，但不以巨字或额外字族作为品质条件。
- **页面节奏**：按叙事需要变化；系列对照页可连续同版式，停顿页与大数字是可选手法。
- **版式**：有美感、有灵魂，不只是文字排列；B 型强调大留白与单一焦点。
- **装饰母题**：全篇建立 2–5 个反复出现的视觉母题（装饰 / 图标 / 插画共用一套语言），形成艺术签名。
- **图表与表格**：颜色取自品牌配色；数据标签只标关键点；表格仅用细横线分隔（不用粗边框 / 不用斑马纹）；多图例需有区分度。**B 型慎用图表，只保留最关键的数字**。
- **品质纪律**：像素级对齐；字间距经得起放大推敲；质感靠排版、对齐、色块、线条的克制来实现，任何地方都不用默认。
- **目录**（A 型常用，B 型可省）：主题色编号 + 章节标题 22pt + 一行 12pt 浅灰说明，左对齐，章节间 0.5pt 浅灰细横线分隔；超过五个可左右对称布局。

## 用户附件模板参考处理

用户要求"参考"某 pptx 风格或用其作模板时，**不是逐页复用**：

1. **模板证据**：由 DSH 抽取用户模板已有的主题、字体、配色和版式信息，交给 SOL 使用；不启动截图转换或视觉质检，也不把结构解析称为视觉验收。
2. **提炼可迁移要点**：版式手法（网格 / 配色 / 导航 / 分区）、风格基调（克制 / 亲和 / 严谨 / 现场感）、图形语法（并列 / 时间轴 / 嵌套 / 取景框）。
3. **不能修改**：主要字体、背景图（尺寸与 ppt 一致的视为背景）、品牌标识、真实人物照片、原始文案、专属色值、装饰纹样。
4. **对应页面类型使用**，不把局部经验放大为整套通用规则；没有可直接使用的页面时按当前设计系统搭建。

## 配色

**品牌主色**：优先采用用户 VI 和已有 logo 的色彩；缺失时可选择适合内容的临时色板，不强制搜索或下载。仅在任务确需且获授权时补充外部品牌资料，不伪称已获得官方确认。
- **气质**：**大胆、别致、高级**。敢用非典型主色（酒红、深墨绿、锈橙、葡萄紫、古铜金、雾青、赭石…），避开被用滥的行业色。一套配色 = 一个戏剧性主角色 + 1–2 个克制支撑色 + 中性底色（暖白 / 米白 / 象牙白，或炭黑 / 墨黑作深底），避免平均分布式多彩堆叠。
- **五角色全指定**：主题色、辅助色、背景色、标题色、正文色都要显式给十六进制值，不许留默认。
- **结尾页收束**：最后一页（结尾 / 行动号召 / Thank You）可选择深色背景（深墨黑、深墨绿、深酒红、深蓝灰、深炭黑等），主题色作点缀，与前文明亮底色形成落幕对比。
- **避雷**：科技蓝紫渐变、医院蓝白、喜庆大红配金、地产金棕色、绿叶环保风、纯灰商务风。

## 禁止项

**通用**：
- 可用卡片、线段、留白或字体层级组织结构，按信息关系选择，不设卡片禁令。
- 均分构图适合并列比较；非对称构图适合强调主次，两者均可使用。
- **严禁**套路化配色（同上"避雷"清单）。
- **严禁**廉价商务插画（西装握手、齿轮地球、上升箭头小人）和 AI 塑料光泽背景图。
- 相邻页面可保持相同骨架，尤其是系列对照；不为差异配额而返工。
- **严禁**任何默认设置——排版、字体、图表颜色、对齐方式均须逐一重新指定。

**A 型特有**：
- **严禁**优势主张无证据；每个优势必配数据 / 案例 / 对比其一。
- **严禁**竞品对比使用无数字支撑的模糊形容词。
- **严禁**案例页做成 logo 拼盘——一页只讲 1–2 个案例并讲透。

**B 型特有**：
- **严禁**一页塞多个想法（特殊多点展示除外）。
- **严禁**生图背景喧宾夺主导致主标题不可读（除非文字有意压图作为设计手法）。
