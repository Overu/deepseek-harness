# RAGFlow retrieval 接口备忘

## 接口

客户端不直连 RAGFlow。在线请求通过企业插件本地桥接器发送到后台连接：

```
connection: activity-search
method: POST
path: /api/v1/retrieval
```

后台使用 `RAGFLOW_BASE_URL` 和 `RAGFLOW_API_KEY` 组成上游请求并注入鉴权；这些值不得进入技能包、客户端环境、命令行、日志或报告。连接必须只允许上述只读检索路径，禁止任意 URL 转发。

请求体：

```json
{
  "question": "雀巢",
  "dataset_ids": ["be388896c48211f19f5ded9d5b020479"],
  "page": 1,
  "page_size": 5,
  "similarity_threshold": 0.6,
  "vector_similarity_weight": 0.75
}
```

- `similarity_threshold`：最终相似度低于此值的切片被过滤。
- `vector_similarity_weight`：向量部分权重，`1 - 该值` 给关键词部分。
  最终 `similarity = weight * vector_similarity + (1-weight) * term_similarity`。

## 响应包装的两种形态

实测同一接口对同一 dataset 会返回不同包装（疑似版本差异或网关分支）：

**形态 A（多数情况）**
```json
{ "code": 0, "data": { "chunks": [...], "doc_aggs": [...], "total": 4 } }
```

**形态 B（曾观察到）**
```json
{ "chunks": [...], "doc_aggs": [...], "total": 4 }
```

解析必须兼容两者。业务成功判据是 `code == 0`（形态 B 无此字段），**HTTP 200 不代表业务成功**。

鉴权失效可能表现为网关或上游 `HTTP 401`。客户端只输出脱敏错误码，不回显上游响应、请求头或凭据；网关超时和断连结果不确定时不得自动重试。

## chunk 字段

| 字段 | 说明 |
|---|---|
| `content` | **字符串**，内含活动档案 JSON（可能带 ```json 围栏） |
| `content_ltks` | 分词结果，无语义价值，展示时忽略 |
| `similarity` | 最终相似度 |
| `term_similarity` | 关键词部分相似度 |
| `vector_similarity` | 向量部分相似度 |
| `document_keyword` | 来源文件名（可对用户展示） |
| `document_id` / `dataset_id` / `id` | 内部标识，默认不展示 |
| `important_keywords` / `tag_kwd` / `positions` | 多为空数组 |

## content 的三种形态

1. **单份档案 dict** —— 顶层含 `活动名称` 等 13 个字段。
2. **多份档案 list** —— 数组元素各是一份档案（一个切片打包了多个活动）。实测出现过 3 份档案同切片。
3. **纯文本** —— 无法解析为 JSON 时按原文处理（脚本截断展示）。

## 活动档案字段表

| 字段 | 类型 | 备注 |
|---|---|---|
| 原始链接 | str / list / null | 小红书笔记原帖 URL（含 `xsec_token`），**默认报告必须展示** |
| 平台 | str | 实测为 `xiaohongshu` |
| 活动名称 | str / null | 可能为 null，展示时兜底为「（未命名）品牌 · 场所」 |
| 活动时间 | list | 每项含 `阶段名`、`开始日期`、`结束日期`；可能为空数组 |
| 地理位置 | list | `场所名称`、`城市`、`详细地址`、`具体位置` |
| 场地属性 | list | `场地类型`/`室内外属性`/`空间使用属性` 均为数组，另有 `补充说明` |
| 品牌 | list | `名称`、`角色`（如"发起品牌"） |
| 行业 | list | `名称`、`判断类型`、`依据` |
| 活动标的 | list | `类型`（主推产品/IP/产品系列…）、`名称`、`所属品牌`、`核心卖点` |
| 活动目标 | list | `目标`、`判断类型`、`依据` |
| 目标群体 | list | `维度`、`描述`、`判断类型`、`依据` |
| 布景搭建 | list | `名称`、`主题或风格`、`视觉与结构特征`(数组)、`材料与尺寸`、`品牌元素`、`呈现状态` |
| 空间分区 | dict | `区域`(数组：`区域名称`/`功能`/`位置关系`)、`参观动线` |
| 互动玩法 | list | `玩法名称`、`参与流程`(数组)、`参与门槛`、`完成条件`、`奖励`、`限制条件` |
| 活动图片 | list | `图片画面描述`、`图片文案`（每份档案可达 14 张） |

### `判断类型` 的含义

取值 `确定事实`（原文明确写出）或 `合理推断`（由模型推断）。
**向用户转述时必须保留此标注**，避免把推断当事实。

## 实测样本

| question | total | top1 相似度 | term | vector | 备注 |
|---|---|---|---|---|---|
| 雀巢 | 1 | 0.8052 | 0.5714 | 0.8831 | 品牌本体命中，相关性高 |
| 华伦天奴 | 4 | 0.7494 | 0.3333 | 0.8881 | 命中真实 Valentino 活动，但含字面噪声 |

「华伦天奴」第 4 条（0.7135）内容其实是广州白鹅潭万象城活动，
因文本含"些华伦士楼"被召回 —— **term 相似度高不代表语义正确，需人工判相关性**。

## 默认报告（`--style report`）约定

- 档案按「活动名称 + 档期 + 城市」归并；同活动多篇笔记合并展示、链接并列。
- 相关性分层：关键词只出现在图片文案/道具/风味描述里的档案进「附：仅被提及」，
  判定依据是 `_core_mentions()` 只统计 `活动名称 / 品牌名 / 行业名 / 标的类型与名称`。
  可用 `--mentions 0` 关闭分层。
- 链接来自 `原始链接` 字段；该字段可能是字符串也可能是数组，`xsec_token` 会过期，
  失效时按 note_id 在小红书搜索。
